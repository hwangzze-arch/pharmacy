## 0. 도입 — 사구체 사진과 항상성 (00:03 ~ 07:33) — 슬라이드 1–3
- 배설계는 앞 단원들과 좀 떨어진 느낌이라 **새로운 개념이 많음** → 처음이면 주의 깊게.
- SEM 사진: **사구체(glomerulus, 복수 glomeruli)** = **모세혈관 덩어리**(꼬여 있는 모세혈관). 혈장이 여기서 걸러져 **보먼 주머니(Bowman's capsule)**로 여과(filtration).
- 들세동맥(afferent) → 사구체 → 날세동맥(efferent). 보먼 주머니 구조는 사진에서 제거된 상태.
- ⭐ **들세동맥이 날세동맥보다 굵음** → 들어가는 액체 > 나오는 액체(일부가 보먼 주머니로 빠짐).
- 왜 중요한가: 대변(소화계)과 달리, **혈액 속 노폐물**과 **용질(solute)**을 액체로 내보냄 → pH·물·노폐물 농도를 일정 범위로 유지.
- 세포 생존을 위해 염·산(H⁺)·전해질과 체액(세포 안·간질액)의 **양**이 일정해야 함. 독성 대사 노폐물이 쌓이면 안 됨.
- 콩팥 = **전해질·물 농도 유지 + 대사 노폐물 제거**. 단, 대사의 주요 노폐물 **CO₂는 호흡(날숨)**으로 나감.
- 여과된 액체가 그대로 나가지 않고, 필요한 것은 **지키고** 노폐물만 **선택적으로** 소변으로 → 선택성(selectivity).
- 조절 대상 = 체액의 **부피와 삼투농도**: 고장액이면 세포가 물을 잃고 **쪼그라들고**, 저장액이면 물을 빨아들여 **터짐**.
- Na⁺·Ca²⁺·K⁺가 너무 높으면 **활동전위** 형성에도 영향 → 염·물 균형. **pH**는 단백질 구조 유지에 중요(중성 범위).

## 1. 네프론 개요 — 영상 후 정리 (17:24 ~ 22:35) — 슬라이드 6
- 네프론 = **혈관 성분**(세동맥, 사구체, 모세혈관) + **세뇨관 성분**(보먼 주머니, 근위세뇨관, 헨레 고리, 원위세뇨관).
- 날세동맥을 나간 뒤 **한 번 더 모세혈관**(세뇨관을 둘러쌈)을 만남.
- ⭐ **소변 = ① 여과 − ② 재흡수 + ③ 분비** → ④ 배설.
  - ② 재흡수: 여과액 → 주변 모세혈관. ③ 분비: 모세혈관 → 세뇨관.
- 재흡수되는 것: 포도당·아미노산·단백질(소변에 나오면 **당뇨·단백뇨**), 비타민, Na⁺, K⁺, 물 — 처음 여과량이 엄청나서 **대부분 재흡수**.
- 세뇨관 안으로 들어오는 것(→ 위 확인 표: 분비): 요소, 요산, H⁺, 암모니아.
- **헨레 고리**: 하행지(descending)와 상행지(ascending)의 **막 투과성이 다름**
  - 하행지: **아쿠아포린** → **물** 재흡수
  - 상행지: 아쿠아포린 없음, 이온 수송체 → **NaCl** 재흡수
  - → 피질(cortex, 위) → 수질(medulla, 아래)로 갈수록 **농도 기울기**가 커짐.
- 원위 쪽: NaCl·물 재흡수, **H⁺·K⁺ 분비**, 마지막에 **알도스테론·바소프레신**이 물·Na⁺ 재흡수 정도를 조절 → 이 장의 전체 개요.

## 2. 콩팥의 기능 (22:35 ~ 27:36) — 슬라이드 7–8
- 독성 물질을 **고농도로 농축**해 배설. 호르몬·신경과 함께 체액량·전해질·삼투압(특히 간질액) 조절.
- 섭취에 맞춰 조절: 물을 많이 마시면 물을 많이 내보내고, 짜게 먹으면 물을 붙잡고 염을 내보냄 → ECF의 **완충(buffer)** 역할.
- ⭐ 독성 대사 노폐물 + **외래 화합물(약물)** 배설 → "**약동학적인 관점**에서도 중요".
- 하루 약 **500 mL**(슬라이드 표기). 물이 부족해도 **농축된 소변으로라도** 계속 내보냄. 얼마나 더/덜 내보낼지가 조절 대상.
- 기능 목록: 물 양 → 삼투압(주로 물 조절로) → 이온(Na⁺, K⁺, Cl⁻, Ca²⁺, HCO₃⁻, **PO₄³⁻**(pH 조절에 중요), SO₄²⁻, Mg²⁺) → **혈장량 = 혈압의 장기 조절**(바소프레신 등, 즉각적이지 않음) → 산–염기 → 대사산물·외래 물질 배설 → **레닌**(Na⁺ 보존) · **EPO**(적혈구 생성) — 내분비 기능 → **비타민 D 활성화**.

## 3. 비뇨계 해부와 네프론 종류 (27:36 ~ 30:42) — 슬라이드 9, 14
- 콩팥 = 소변 생성 / 요관(ureter) → 방광(bladder) → 요도(urethra) = 운반. ⭐ "이 강의에는 주로 키드니에 대해서 볼 거고 이 뒤쪽 나가는 경로는 **다루지 않을 예정**".
- 방광에 저장 → 반사가 오면 배뇨.
- **신피질(cortex)** = 바깥 과립 모양 / **신수질(medulla)** = 안쪽 줄무늬 / **신우(renal pelvis)** = 소변을 모으는 곳(네프론 아님). 네프론·사구체·보먼 주머니는 대부분 **피질**.
- **겉질 네프론** vs **속질곁 네프론**(juxta = 옆) — 교수님은 85% : 15%라고 했지만 **슬라이드 14는 80% : 20%**.
- 네프론 = 가장 작은 **기능 단위**, 콩팥 하나에 약 **100만 개**.

## 4. 네프론의 혈관 성분 (30:42 ~ 36:39) — 슬라이드 10–11
- 들어오는 곳 = 동맥, 나가는 곳 = 정맥. **들세동맥** → 사구체 → **날세동맥** → **세뇨관 주위 모세혈관** → 정맥. 이 피는 콩팥 조직에 에너지도 공급하고 CO₂를 받아 옴.
- 사구체: 단백질은 대부분 걸러지지 않음(보먼 주머니로 안 넘어감).
- **세뇨관 주위 모세혈관**: 근위·헨레 고리·원위 모두를 둘러쌈. 날세동맥이 다시 갈라진 것. 콩팥 조직에 혈액 공급 + **재흡수·분비** 교환 장소(여과액 → 소변).
- ⭐ **곧은혈관(vasa recta)**: 날세동맥 가지가 **헨레 고리와 평행**하게 내려감 → 수질의 **삼투 기울기**(안쪽으로 갈수록 높음)에 맞춰 교환해 주는 짝(counterpart).

## 5. 네프론의 세뇨관 성분과 사구체옆장치 (36:39 ~ 40:36) — 슬라이드 12–13
- **보먼 주머니**: 사구체를 감싸 여과액을 받음.
- **근위세뇨관**: **피질**. 재흡수가 상대적으로 **조절되지 않음(uncontrolled)** — 대량(bulk) 재흡수 + 일부 선택적 분비. ⭐ **가장 많은 재흡수**가 일어나는 곳, 그 뒤는 **미세 조정**.
- **헨레 고리**: U자, 수질 깊이 들어가 **수질 삼투 기울기** 형성.
- **원위세뇨관**: 다시 **피질**. **호르몬으로 조절**(variable) — 물·Na⁺ 재흡수, **H⁺·K⁺ 분비**.
- **집합관**: 여러 네프론의 액체를 받아 수질 → 신우로. 여기서도 물 재흡수.
- **사구체옆장치(JGA)**: **들세동맥**과 **원위세뇨관**이 사구체 옆에서 잠깐 만나는 곳 → **레닌** 분비(→ 위 확인 표: 레닌은 혈액으로).

## 6. 네프론 두 종류 · 기본 과정 4가지 (40:36 ~ 46:34) — 슬라이드 14–16
- **겉질 네프론**: 바깥층, 헨레 고리 **아주 짧음**, 곧은혈관 거의 없음.
- **속질곁 네프론**: 비율은 적지만 안쪽층, 헨레 고리가 **아래까지 길게**, **곧은혈관**이 따라 내려가 **역류 교환(countercurrent exchange)** → 수질 안쪽이 더 짠 농도 기울기. ⭐ **곧은혈관은 속질곁 네프론에서만**.
- **사구체 여과**: 들어온 혈장의 **20%만 여과**, **80%는 날세동맥**으로. 압력 차로 여과, 혈구·단백질은 못 나오고 이온·아미노산·포도당·요소·물 같은 **작은 물질**만.
- **재흡수**: 세뇨관 → 세뇨관 주위 모세혈관(물·전해질·영양분).
- **분비**: 세뇨관 주위 모세혈관 → 세뇨관 내강(여과되지 않은 노폐물·불필요 이온).
- 혈액에서 세뇨관으로 들어가는 길 = **여과 + 분비** 두 번의 기회. 슬라이드 15 "rental" → "**renal**" 오타("아, 오타가 있네요").
- 여과는 **비선택적**, 재흡수·분비는 **선택적**.
- 비유: 보먼 주머니 → 신우까지 **컨베이어 벨트** — 가면서 필요한 건 빼서 돌려주고, 빠뜨린 건 다시 넣음.

## 7. 사구체막과 여과의 힘 (46:34 ~ 53:43) — 슬라이드 18–19
- ⭐ **사구체막 3층**
  1. 모세혈관 **내피세포** — **창(fenestration, 작은 구멍)**이 있어 느슨함. 혈구는 정상적으론 못 나옴(나오면 **혈뇨**).
  2. **기저막(basement membrane)** — 세포 없음.
  3. **보먼 주머니 안쪽층** = **발세포(podocyte)**, 발 같은 돌기 사이 **틈새(slit)**.
- ⭐ "우리 몸 **어디에 있는 모세혈관보다도 투과성이 높아서** 웬만한 건 다 빠져나옴" — 어차피 다시 재흡수·분비하면 되니까 일단 최대한 통과.
- **여과를 미는 힘 = 모세혈관 혈압 55 mmHg** — 세동맥을 지나도 꽤 높게 남음(심장 박동 + 혈류 저항).
- 반대 방향: **혈장 교질 삼투압 30**(알부민 등 혈장 단백질이 물을 당김), **보먼 주머니 정수압 15**(세뇨관 속 액체가 만드는 압력).
- ⭐ **순여과압 = 55 − 30 − 15 = 10 mmHg** → 항상 여과 방향.
- **GFR(사구체 여과율)**: 1분에 사구체에서 여과되는 양(혈압·심박출량처럼 **분 단위**). ⭐ "**GFR이라는 말이 뒤에서 많이 나올 예정**".

## 8. GFR의 조절 — 자가조절과 교감 (53:43 ~ 1:04:21) — 슬라이드 20–23
- GFR = 콩팥 기능 평가 척도, 노폐물·수분을 얼마나 잘 배출하는지 아는 **가장 정확한 단일 지표**.
- ⭐ 조절할 수 있는 것은 **사구체 모세혈관 혈압**뿐. 교질 삼투압·보먼 정수압은 조절 대상이 아님.
- **들세동맥** 저항 ↑(지름 ↓) → 혈류 ↓ → **GFR ↓** / 저항 ↓ → GFR ↑.
- **외인성 교감 조절**: 교감 활성 → 콩팥 세동맥 수축 → GFR ↓ → **소변 ↓**.
- **내인성 자가조절(autoregulation)**: MAP가 변해도 콩팥이 스스로 들세동맥 지름을 조절해 **GFR을 일정하게**(혈압이 높으면 들세동맥을 좁힘).
- **혈압의 단기 조절** = 압력수용기 반사(음성 되먹임): MAP ↓ → **대동맥궁·경동맥동** 압력수용기 → 뇌간 **심혈관 중추** → 교감 ↑ → CO(SV·HR) ↑ + 세동맥 수축(TPR ↑) → **몇 분 안에** 혈압 ↑. 예: 땀을 많이 흘려 혈장량이 줄 때.
- **장기 조절**: 같은 교감 신호가 **들세동맥**도 수축 → 사구체 혈압 ↓ → GFR ↓ → 소변 ↓ → 체액·염분 보존 → 혈장량 ↑ → 혈압 ↑(**몇 시간~며칠**).
- 평상시엔 자가조절로 GFR 일정, 혈압이 크게 떨어지는 **위급 상황에서는 GFR을 희생**하고 전신 혈압 우선(자가조절을 **override**). 재흡수 ↑, 갈증 ↑ → 혈장량·혈압 회복.
- **여과계수(Kf)**: GFR = Kf × 순여과압. Kf는 사구체 **표면적·투과성**으로 정해지며 정상에선 일정, **질병**에서 변함 → 사구체 손상 시 **여과 ↓**(당뇨병성 신증, 사구체신염).
- 콩팥은 **심박출량의 20–25%**를 받음 — 소화기관·뇌와 비슷하게 많음 → 많은 혈장을 걸러 체내 환경을 일정하게 하려고.

## 9. 세뇨관 재흡수 — 규모와 상피 통과 수송 (1:04:21 ~ 1:12:31) — 슬라이드 25–27
- 혈장 단백질 빼고 거의 다 여과 → 영양분·전해질 등 소변으로 버리면 비효율적인 것을 **재흡수**.
- 재흡수는 **많고, 선택적이고, 가변적**.
- ⭐ 1분에 **125 mL 여과, 124 mL 재흡수**. 125 mL가 다 나가면 탈수로 금방 죽음. 하루 500~700 mL면 1분에 약 0.5 mL → 약 124.5 mL 재흡수.
- 과잉 전해질만 배출, 물·염·당은 대부분 재흡수. 노폐물은 재흡수 안 되게 하지만 **요소는 일부 재흡수**. 소변은 매우 농축됨.
- **상피 통과 수송(transepithelial transport)** = **5개 장벽**: ① 내강막 ② 세포질 ③ 기저외측막 ④ 간질액 ⑤ 모세혈관 벽(내피).
- 세포 사이는 **치밀이음부(tight junction)**로 막혀 있어 **세포를 꼭 통과**해야 함 → 막의 수송체·통로로 **선택적**.
- **수동**: 물, Cl⁻, 요소(농도가 높은 쪽 → 낮은 쪽). "요소도 어느 정도 다시 혈장으로 들어온다는 거를 집중하면 좋겠네요. 아, 뭐 엄청 중요한 건 아닌데요."
- **능동**: 포도당·아미노산(1단계, 농도를 거슬러 수송체로) / Na⁺·K⁺(3단계, **Na⁺-K⁺ 펌프**).
- ⭐ **SGLT2 억제제**(엠파글리플로진, 다파글리플로진): SGLT2를 막아 포도당 재흡수 차단 → 포도당을 소변으로 → **2형 당뇨** 혈당 ↓.

## 10. Na⁺ 재흡수와 Na⁺-K⁺ 펌프 (1:12:31 ~ 1:20:46) — 슬라이드 28–29
- ⭐ 콩팥 에너지의 **80%가 Na⁺ 수송** — "Na⁺의 재흡수가 굉장히 중요".
- ⭐ 재흡수되는 Na⁺: **근위 67%**, **헨레 고리 25%**, **원위·집합관 8%** → 소변으로는 **1% 미만**.
- 근위: Na⁺ 재흡수가 **포도당·아미노산**(SGLT 등)과 함께, 그리고 **H⁺·중탄산·암모늄 분비**와 역수송체로 짝지어짐 → Na⁺는 다른 물질의 재흡수·분비와 얽혀 있음.
- 헨레 고리: 하행지는 이온 통로가 없어 **물만**, 상행지는 **Na⁺-K⁺-2Cl⁻ 공동수송체**로 **NaCl만**(물 X) → 올라가며 세뇨관액이 **묽어짐** → ⭐ **수질 삼투 기울기** → **소변 농축**에 중요.
- 원위·집합관: **알도스테론** → Na⁺ 한 번 더 재흡수, **K⁺ 분비**(Na⁺-K⁺ 펌프 촉진) / **ADH(항이뇨호르몬)** → 물 재흡수 → ECF 부피 유지.
- **기저외측(basolateral) Na⁺-K⁺ 펌프**: 에너지를 써서 Na⁺를 세포 밖(간질)으로 → 세포 안 Na⁺를 낮게 유지 → 내강의 Na⁺가 **Na⁺ 통로로 수동으로** 계속 들어옴 → 근위세뇨관 67% 재흡수의 **원동력**. K⁺는 세포 안에 쌓임.
- ⭐ 에너지는 **한 곳(펌프)에서만** 쓰면, 나머지는 초록 화살표처럼 **수동 이동** → 효율적.
- ⭐ **근위 = 양적(얼마나 많이) 재흡수, 항상 작동** / **원위·집합관 = 질적 조절, 호르몬으로 가변** — 근위만 있으면 짜게 먹든 물을 마시든 늘 같은 양이 나가 버림. "여기서 **중요하게 기능하는 것은 알도스테론**".

## 11. RAAS — 레닌–안지오텐신–알도스테론계 (1:20:46 ~ 1:31:54) — 슬라이드 30–33
- ⭐ "**신장이 혈압과 체액의 양을 조절하는 가장 중요한 호르몬 시스템**" — 원위에서 Na⁺·물을 가변적으로 조절. 교수님은 "RAS"라고 부름(슬라이드: RAAS).
- 활성화 조건: **Na⁺ ↓, 물(ECF) ↓, 혈압 ↓**.
- **레닌 분비 자극 3가지**: ① **콩팥 안 압력수용기**가 혈압 ↓ 감지 ② **사구체옆장치**가 여과액 **NaCl ↓** 감지 ③ **교감신경** 활성(압력수용기 반사).
- ⭐ 순서: **레닌(콩팥)** → **안지오텐시노겐(간)** → **안지오텐신 I** → **ACE(폐 모세혈관)** → **안지오텐신 II** → **부신피질** → **알도스테론** → 원위·집합관 **Na⁺-K⁺ 펌프 ↑** → Na⁺ 재흡수 ↑, K⁺ 분비 ↑.
- Na⁺가 이동하면 **Cl⁻**가 전기적으로 따라감("K⁺가 따라갑니다… 아니 클로라이드") → 소금이 들어오니 **물도 삼투로** 따라감 → 혈장량 ↑ → 혈압 장기적으로 ↑.
- **안지오텐신 II의 추가 작용**: 세동맥 직접 **수축**(TPR ↑ → 혈압 빠르게 ↑), **갈증**(행동), **바소프레신 분비**(원위·집합관 물 재흡수 ↑).
- 13장 연결: 폐 모세혈관 **내피세포**가 ACE를 만듦(호흡계의 비호흡 기능).
- ⭐ "중요한 거는 **레닌**, 폐의 **ACE**, **안지오텐신 II**".
- **알도스테론의 이중 조절**: ① RAAS(Na⁺ ↓ 등) ② **혈장 K⁺ ↑**도 직접 알도스테론 분비 촉진 → K⁺ 분비 ↑(소변 K⁺ ↑), Na⁺ 배설 ↓.

## 12. Na⁺가 끌고 가는 Cl⁻·물·요소 (1:31:54 ~ 1:34:37) — 슬라이드 34
- 알도스테론 = RAAS의 **마지막**, Na⁺-K⁺ 펌프를 직접 촉진.
- Na⁺ 재흡수 → **Cl⁻**는 전기 기울기로 따라옴 → **물**은 삼투로(바깥이 NaCl이 많음) **아쿠아포린**을 통과.
- 근위에서 물이 많이 빠지면 세뇨관 안 **요소 농도 ↑** → 요소도 수동 확산 → 여과된 요소의 **50% 재흡수**. 요산·**크레아티닌**은 재흡수 안 됨.
- 정리: "키드니는 구조가 특이하고 새로운 개념이 많아 저도 볼 때마다 새로운 편" — 구조 → 여과 → 재흡수 → 조절 호르몬(특히 RAAS). ⭐ "**알도스테론과 안지오텐신 II에 대해서는 기능을 잘 알아두시고**", 혈압 증가에도 비뇨계가 많이 활용된다.

## 13. 강의 끝 요약 문제 (1:35:34 ~ 1:38:27)
1. **콩팥의 기능이 아닌 것 → ④ 백혈구 생성 조절**: 산–염기 균형 ○, 최종 산물 배설 ○, **EPO 생성** ○(적혈구 생성 자체는 골수, EPO를 만드는 곳이 콩팥). 백혈구가 아니라 **적혈구** 생성을 조절.
2. **GFR을 증가시키는 것 → ② 들세동맥 확장**: ① 교감 자극 → 들세동맥 수축 → GFR ↓ / ② 들세동맥 확장 → 혈류 ↑ → **GFR ↑** / ③ 사구체 정수압(= 사구체 혈압) ↓ → GFR ↓ / ④ 순여과압은 GFR을 직접 결정하므로 **감소하면 GFR ↓**.
3. **레닌 방출을 증가시키는 요인이 아닌 것 → ① 동맥압(MAP) 증가**: 레닌은 NaCl ↓, ECF ↓, 탈수, 혈압 ↓일 때 올리려고 나옴 → MAP ↑이면 레닌 ↓.

> "저는 개인적으로 이 단원이 어렵다고 생각을 하는데, 네, 공부하시느라 수고하셨고" [1:37:41]
