- `강의녹취록_2026-10-29_근육계(Ch8).pdf` (정리본, 표지+7쪽, 마지막 쪽에 기말 출제 후보) / `.md` (텍스트 원본) — 8장 근육(골격근 구조, 활주 필라멘트, 교차결합 주기, 흥분-수축 연결, 이완·SERCA, 기시점/정지점, 직렬탄성요소, 가중·강축)
  - 강조점: A대는 수축해도 길이 불변(H대·I대만 짧아짐), 액틴에서 떨어질 때 새 ATP 필요(사후경직), 이완에도 ATP 소모(SERCA)

- 기말 마스터 요약·개념문제·모의고사를 만들 때 녹취록에서 교수님이 강조한 내용을 우선 반영할 것.

## 기말고사 준비 시 반드시 반영할 것 (중간고사 응시 후 피드백, 2026-10-19)
- 중간고사 실제 문제는 **스타일은 우리 자료와 같았지만 문장이 더 길었음**.
- 기말 자료에서는 **마스터 요약의 개념문제**와 **통합모의고사 문제**를 **문장 단위로 더 길게** 만들 것
  (지문·보기를 실제 시험처럼 여러 절로 된 긴 영어 문장으로).
- **객관식 보기는 단어가 아니라 문장 단위**로 나옴 → 보기 ①~⑤를 모두 완전한 영어 문장으로 만들 것.
- **객관식은 '2개 고르기(Choose two)'만 출제** → 1개 고르기 객관식은 만들지 말고 전부 2개 고르기로.
- 출제 범위는 **강의자료(슬라이드) 범위에서만** 나옴 → 테스트뱅크 보강편 불필요.

## 실제 중간고사 출제 형식 (2026-10-20 확인) — 기말 모의고사는 이 구성 그대로
| 유형 | 내용 |
|---|---|
| O/X | 문장의 참·거짓 판단 |
| 객관식 | 5지선다 중 **2개 고르기만**, 보기는 **긴 문장** |
| 그림 각주 | 그림(사진)에 A, B, C… 표시 → 각각이 무엇인지 쓰기 |
| 단어 박스 빈칸 | 단어 **약 12개**를 주고, 어떤 **과정**(예: 활동전위, 신경근 접합부 순서)의 빈칸에 들어갈 단어 고르기 |
| 서술형 | **2문제** |
- 서술형 2문제를 빼면 나머지는 모두 객관식형으로 **약 50문항**.
- 기말 모의고사·개념문제도 위 5가지 유형과 비율로 만들 것 (단답형 대신 그림 각주·단어 박스 빈칸).
  - 그림 각주 문제는 강의 슬라이드 그림을 잘라 A/B/C 라벨을 붙여서 출제.

## 형식 규칙 (중간고사 자료에서 확정된 것)
- 시험: 문제는 영어, 답은 **한글**로 작성. 유형은 위 '실제 중간고사 출제 형식' 표를 따름.
- 레이아웃: 삼성노트 가로형(297×186 mm), 신약개발개론 `_상세요약문제.pdf` 형식.
  요약 페이지 → 개념문제 페이지 번갈아, 장 끝 암기카드, 표지는 **남색 그라데이션**(파스텔 단풍 표지는 거절됨).
- 요약 페이지: 영어 용어는 **나올 때마다** 한글 병기 (예: Chemical(화학물질), Tissue(조직), Organ(장기)).
- 문서 작성 절대 규칙
  1. 약어는 처음 등장 시 Full name + 직관적 뜻
  2. 영어 이름·개념에 한글 발음/번역 병기
  3. 어려운 용어 옆에 [즉, ~] 쉬운 풀이
- 개념문제: 영어 문제 + 한글 번역 + 빈 풀이 칸(줄 없이 칸만) + 정답·해설.
  단답·서술 답은 한글 + 🔑 핵심어, 객관식·T/F는 **틀린 보기마다 왜 틀렸는지**.
- 통합모의고사: 문제지는 **영어만**(번역은 해설 페이지에만), 정답표·배점·약점 진단표·보기별 해설 포함.

## PDF 생성 코드 (`_build/`) — 같은 디자인으로 이어서 만들 때
- `_build/src/` : 빌드 코드 / `_build/fig/` : 강의 슬라이드에서 잘라낸 그림 / `_build/crop.py` : 그림 자르기 스크립트
- 준비: Pretendard 폰트 설치 (`~/.fonts`에 Pretendard ttf), Node의 playwright 사용 (`/opt/node22/lib/node_modules/playwright`)
- 마스터 노트: `cd _build/src && bash lv.sh && node pdf.js $PWD/out.html 출력.pdf`
  (lv.sh가 페이지별 글자 크기를 자동으로 맞추고 넘침을 검사 → "NO OVERFLOW"면 정상)
- 모의고사: `python3 mbuild.py && node pdf.js $PWD/mout.html 출력.pdf`
- 파일 역할
  - `lib.py` 카드·표·문제 카드 함수 / `style.css` 디자인 / `front.py` 표지 / `back.py` 총정리
  - `c1.py`~`c7.py` 장별 요약 페이지 / `q1.py`~`q7.py` 장별 개념문제(한글 답·핵심어·오답 이유)
  - `annotate.py` 약어·용어 [즉, ~] 풀이 / `allen.py`+`endict.py` 영어 용어 한글 병기 사전
  - `mdata.py` 모의고사 50문항 / `mbuild.py` 모의고사 조립 / `mstyle.css` 모의고사 디자인
- 기말 범위는 `c8.py…`, `q8.py…`를 같은 형식으로 추가하고 `build.py`의 mods 목록·`lib.COLORS`를 늘리면 됨.
