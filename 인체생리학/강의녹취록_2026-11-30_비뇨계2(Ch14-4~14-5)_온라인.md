## 0. 복습 — 세 과정과 혈압 (00:03 ~ 04:53) — 슬라이드 15–16, 21–22
- 이번 한 시간으로 **비뇨계 마무리**.
- 중심 과정 3가지: **사구체 여과**(사구체 → 보먼주머니) → 컨베이어 벨트처럼 흐르며 필요한 것은 **재흡수**, 세뇨관 주위 모세혈관에서 추가로 **분비**.
- 소변 생성 = 체액량을 보존할지 내보낼지 결정 → ⭐ **혈압 조절**에도 매우 중요. 많은 **고혈압 치료제**가 소변 생성·재흡수와 그 호르몬을 조절.
- **단기 조절(압력수용기 반사)**: MAP ↓ → 압력수용기(→ 위 확인 표: 대동맥궁 + 경동맥동) → 뇌간 **심혈관 중추** → 교감 ↑ → 심박출량 ↑ + 혈관 수축 → 혈압 회복.
- **장기 조절**: 콩팥이 **체액 보존** — GFR ↓ → 소변 ↓ → 염분·체액 보존 → 혈액량 ↑ → 혈압 ↑.
- GFR은 자가조절되지만 **교감이 강하면** 이를 넘어 **들세동맥 수축** → 사구체 모세혈관 혈압 ↓. ⭐ "이 **모세혈관 압력이 GFR의 가장 중요한 원동력**". → 소변 ↓ + 재흡수 ↑ + **갈증** → 혈장량 보존 → 혈압 장기 보존.

## 1. 근위 vs 원위 · RAAS 복습 (04:53 ~ 12:39) — 슬라이드 28–33
- **근위세뇨관**: 얼마나 많이 재흡수할지(양적), 조절이 잘 안 됨.
- **원위세뇨관·집합관**: 마지막으로 얼마나 내보낼지(**질적**), **호르몬**으로 조절 → 그 시스템이 **RAAS**.
- ⭐ "여기서 **가장 중요하게 작용하는 거는 알도스테론**" → **Na⁺ 재흡수**, **K⁺·H⁺ 분비**, 물은 Na⁺를 따라 재흡수 → 염·물 보존 → 체액이 부족할 때 혈압 ↑.
- 순서: **레닌(콩팥)** → (간의 안지오텐시노겐 → **안지오텐신 I**) → **폐의 ACE** → **안지오텐신 II** → **부신피질** → **알도스테론** → 원위세뇨관에서 체액 보존.
- 레닌은 **사구체옆장치**(들세동맥과 원위세뇨관이 맞닿는 곳)에서 분비.
- 최종: Na⁺ 재흡수 → Cl⁻ 따라옴 → K⁺는 Na⁺-K⁺ 펌프로 나감 → 물 보존 → 혈장량 ↑ → 동맥압 보존.
- ⭐ **안지오텐신 II**: 알도스테론 분비 + "중요한 거는" **바소프레신(항이뇨호르몬)** 촉진 + **갈증** + **세동맥 수축**.
- ⭐ "**안지오텐신 II, 알도스테론, 레닌**이 RAAS에서 중요한 호르몬" — 이 과정을 막는 **저해제가 고혈압 치료제**(재흡수 ↓ → 소변 ↑ → 혈압 ↓).
- **알도스테론 분비 자극 두 가지**: ① 혈장 **K⁺ ↑**(→ K⁺ 분비 ↑) ② **Na⁺ ↓ · ECF ↓ · MAP ↓** → 레닌 → 안지오텐신 I·II → 알도스테론.
- 알도스테론 = RAAS의 **가장 아래 단계**, 부신피질 → 원위·집합관 → Na⁺·물 재흡수, K⁺·H⁺ 분비.
- **바소프레신**(안지오텐신 II가 분비 촉진): **뇌하수체 후엽**에서 나와 원위·집합관의 **물 재흡수** ↑.
- 근위 = 호르몬 조절 비율 낮고 재흡수 **양**은 많음 / 원위 = 양은 적지만 호르몬으로 **가변** → 체액을 최종 조절.

## 2. 세뇨관 분비 — H⁺ · K⁺ (12:39 ~ 16:11) — 슬라이드 36–37
- 분비도 **상피 통과 수송**인데 **반대 방향**(모세혈관 → 세뇨관). 노폐물을 소변으로 더 내보내는 **보조 기전**.
- 분비 대상: **H⁺, K⁺, 유기 이온**.
- ⭐ **H⁺ 분비 = 산–염기 균형**: 대사로 H⁺가 계속 생기므로 내보내 산성화를 막음. **근위·원위·집합관** 모두에서. 체액이 더 산성이면 분비 ↑. 중추(연수)·말초(대동맥·경동맥) 화학수용기가 H⁺를 감지.
- **K⁺ 분비 = 알도스테론**이 촉진. K⁺는 Na⁺-K⁺ 펌프로 대부분 **세포 안**에 있고 세포 밖 농도가 낮아서, 혈장 K⁺가 **조금만 변해도 큰 영향** → **엄격한 조절**.
- 알도스테론 → Na⁺ 재흡수 ↑ ↔ **K⁺ 분비 ↑**: 펌프가 에너지를 써서 K⁺를 세포 안으로 넣으면 기울기를 따라 **내강으로 자동으로** 나감 → K⁺가 몸 밖으로.

## 3. 세뇨관 분비 — 유기 이온 · 근위 vs 원위 요약 (16:11 ~ 20:17) — 슬라이드 38–39
- **유기 양이온·음이온** 분비 → **외래 물질 제거**. 근위세뇨관의 **비특이적 운반체**.
- 제거 대상: 식품 첨가물(보존제), 오염 물질, **농약**, **약물**, 비영양 유기물.
- ⭐ **근위세뇨관 = 대부분의 재흡수 + K⁺를 제외한 대부분의 분비**(외래 물질 분비).
- ⭐ **원위·집합관 = 최종량 결정**: 물·Na⁺는 **재흡수** 방향, K⁺·H⁺는 **분비** 방향.
- 표 14-2(슬라이드 39)
  - 근위 재흡수: 대부분의 **Na⁺**, Cl⁻·물이 따라옴, **포도당·아미노산**(Na⁺와 함께), **요소**(농도가 높아져서).
  - 근위 분비: **H⁺**(체내 농도에 따라), **유기 이온**.
  - 원위·집합관 재흡수: **Na⁺**(알도스테론), 물(Na⁺를 따라 + **바소프레신**으로 추가 조절).
  - 원위·집합관 분비: **K⁺**(알도스테론), **H⁺**(산–염기).

## 4. 혈장 청소율 (20:17 ~ 23:46) — 슬라이드 41
- **청소율(plasma clearance)** = 1분 동안 특정 물질이 **완전히 제거된 혈장의 부피**. 제거된 물질의 양이 아니라 **부피**(예: 혈장 1 L 중 100 mL에서 그 물질이 제거).
- 물질마다 다름 — 콩팥이 그 물질을 얼마나 잘 제거하는지에 따라 결정.
- 공식: **CL = U × V̇ / P**(소변 농도 × 소변 유량 ÷ 혈장 농도). ⭐ "**이거를 뭐 제가 시험에 내지는 않겠습니다.**"
- 청소율에는 **여과·재흡수·분비** 세 가지가 다 반영됨.
- ⭐ **크레아티닌**: 재흡수 거의 없음, 분비는 약간 → 청소율 ≈ **GFR** → "**크레아티닌의 청소율을 계산하면 GFR을 계산할 수 있습니다**" → 콩팥 기능 평가에 많이 씀.

## 5. 소변 농도와 수질 삼투 기울기 (23:46 ~ 26:39) — 슬라이드 42
- 콩팥은 몸의 **수분 상태**에 따라 소변 농도를 조절: 물이 많으면 **묽은 소변**을 많이, 부족하면 **진한 소변**.
- 물이 너무 많으면 ECF가 **저장성**, 물이 부족하면 **고장성**.
- 피질 약 **300** → 수질로 내려갈수록 **600 → 900 → 1200 mOsm/L**. 이 기울기는 **헨레 고리를 따라** 내려갈수록 높아짐.
- 기울기는 **세뇨관 내강 ↔ 주변 간질액** 사이에 존재 → 간질액이 진해서 **물을 끌어당겨** 소변을 농축.
- ⭐ "우리 소변이 농축될 수 있는 이유 = 수질 깊은 곳 세뇨관 근처 **간질액의 농도가 매우 높아** 물이 빠져나가기 때문."

## 6. 역류 증폭 — 수질 기울기 만들기 (26:39 ~ 33:16) — 슬라이드 43
- 기울기를 만드는 곳 = **속질곁 네프론**의 긴 **헨레 고리**.
- **하행지(descending limb)**: 물이 통과(빠져나감). **상행지(ascending limb)**: **NaCl을 내보내고 물은 불투과(impermeable)** → 이 **물 불투과성이 원동력**.
- 단계(모두 300에서 시작)
  1. 상행지가 NaCl만 내보냄 → 간질 진해짐 → 하행지에서 물이 빠져 하행지도 진해짐 → **상행지 200 vs 하행지·간질 400** (같은 높이에서 **200 차이**).
  2. 새 300 액체가 들어와 밀어줌 → 액체가 한 칸씩 이동.
  3. 다시 NaCl이 나가 상행지는 더 묽어지고(200 → 150), 아래는 더 진해짐 → 반복.
  4. 반복하면 **아래 1200, 위 300**의 세로 기울기(슬라이드 수치는 400·225·125 단계 → 위 확인 표).
- ⭐ "**작은 수평 차이(200)를 수직으로 증폭**" = **역류 증폭(countercurrent multiplication)**.
- 상행지를 나가는 액체는 NaCl이 빠져 **100 mOsm/L**로 묽어져 원위로(녹취의 "디센딩"은 상행지 → 위 확인 표). 빠진 NaCl이 수질을 1200으로 만드는 데 기여.
- 이 300 → 1200 기울기가 **바소프레신에 의한 농축의 기반**.

## 7. 바소프레신 — 물 부족 vs 물 과잉 (33:16 ~ 38:01) — 슬라이드 44–45
- 역류 증폭(헨레 고리)까지는 두 상황에서 **같음** — 원위로 들어오는 소변은 약 **100**.
- **(a) 물 부족(water deficit)**: 물을 보존 → **바소프레신 ↑** → 원위·집합관이 물에 투과적 → 집합관이 진한 수질을 지나며 물 재흡수 → **농축뇨**.
- **(b) 물 과잉**: **바소프레신 없음** → 물 재흡수 안 함 → **100 정도의 묽은 소변**이 그대로, 많이.
- 바소프레신 = **항이뇨호르몬**, **뇌하수체 후엽**에서 분비 → 원위·집합관의 **물 투과성** ↑(아쿠아포린).
- 작용 기전(슬라이드 45): 혈액(세뇨관 주위 모세혈관)의 바소프레신이 주세포의 **수용체**에 결합 → **cAMP**(2차 전령) → **AQP-2**가 늘어 물이 내강 → 세포 → 혈액으로 재흡수 → 소변 농축. (정확히는 V₂ 수용체는 **기저외측막**, cAMP는 AQP-2를 **내강막에 삽입** → 위 확인 표)
- ⭐ 바소프레신 있음 → **소변량 ↓, 농축뇨** / 없음 → **희석뇨 많이**.

## 8. 곧은혈관 — 역류 교환 (38:01 ~ 40:20) — 슬라이드 46
- 헨레 고리 주변엔 간질액뿐 아니라 **곧은혈관(vasa recta)** 모세혈관이 있음.
- ⭐ 역할 = 삼투 기울기를 **지켜 줌** — **역류 교환(countercurrent exchange)**. 곧은혈관도 300 → 1200 → 300.
- 하행 곧은혈관: **NaCl이 들어오고(물은 나가고) 진해짐** / 상행 곧은혈관: 반대로 **다시 묽어짐**(→ 위 확인 표).
- ⭐ "**헨레 고리는 기울기를 만들고(역류 증폭), 곧은혈관은 기울기를 지킨다(역류 교환)**."
- 수질을 빠져나가는 피 = 들어온 피와 같은 **300, 등장성(isotonic)**.

## 9. 신부전 · 정리 문제 (40:20 ~ 42:59) — 슬라이드 47 + 추가 슬라이드
- 콩팥 이상 시: 노폐물 축적 → **독성(요독증)** / H⁺·K⁺ 분비 실패 → **산증**, **고칼륨** → 막전위·뉴런 **흥분성이 과하게 ↑** / Na⁺를 너무 많이 내보내면 **혈압 ↓** / 인산·칼슘 불균형, **단백뇨**, **고혈압**(체액 조절 이상), **면역 저하**.
- "두세 시간짜리 강의로 소변이 만들어지는 과정, 콩팥의 구조, 콩팥에서 일어나는 과정을 배웠다."
- 정리 문제(지난 강의와 같은 내용)
  1. 콩팥의 기능이 **아닌** 것 = **백혈구 생성**.
  2. **들세동맥 확장 → GFR ↑** / 수축 → GFR ↓ → 소변 ↓. ⭐ "GFR 조절이 소변량뿐 아니라 **혈압 조절**에도 중요."
  3. 레닌 방출 자극 = **NaCl ↓, ECF ↓, 혈압 ↓**. **혈압 ↑이면 레닌 ↓**(혈압이 높을 때 체액을 보존하면 혈압이 더 높아지므로).
