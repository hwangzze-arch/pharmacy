## 0. 10장 복습 — 혈압 조절 총정리 (02:10 ~ 07:39)
- **MAP = CO × TPR**, **CO = HR × SV**.
- **교감**: 세동맥 수축 → **TPR ↑** → 혈압 ↑ / 정맥에서 **정맥 환류 ↑** → SV ↑ → CO ↑ → 혈압 ↑ / HR 직접 ↑.
- 총정리 그림: ① CO 요인 ② TPR 요인 ③ 정맥 환류 요인.
  - TPR: 혈액 점성은 적혈구 생성에 **오래 걸려** 즉각 조절 대상이 아님 → **세동맥 반지름**(교감·호르몬, 그리고 O₂·CO₂·노폐물·NO 같은 대사물을 감지하는 내인성 조절).
  - 정맥 환류: 호흡(흉강 음압으로 빨아들임), 골격근 펌프, 정맥 판막(역류 방지), 심장 흡인. 혈액량 자체를 늘리는 수분 재흡수는 배설계와 연결.
- 확인 문제: 정맥 = 주로 **혈액 저장소**(①). 세동맥 혈류가 줄어드는 상황 = 교감 지배 → 세동맥 **수축** → **저항 증가**.

## 1. 혈액의 구성 (07:39 ~ 10:41)
- SEM 사진: 적혈구·백혈구·혈소판.
- 혈액 = 체중의 약 **8%**. 부피로 액체(혈장) 약 **55%**, 세포 약 **45%** — 세포 대부분이 적혈구라 거의 **44%**(헤마토크릿 42–45%). 백혈구 + 혈소판은 합쳐 **1% 미만**.
- 세포 종류: 적혈구, 백혈구, **혈소판(세포가 찢어져 생긴 조각)**.
- **혈장** = 세포 없는 액체 성분, **90%가 물**, 약간 끈적함.
  - 무기 용질: 이온이 많음 — 염분 균형을 위해 필요한 곳으로 나르고 남는 곳에서 배설되는 통로. 혈액엔 **Na⁺·Cl⁻**가 많음(K⁺는 주로 세포 안).
  - 유기 성분: 주로 분자량이 큰 **혈장 단백질**.
  - 기타: 영양분, 노폐물, 호르몬, 녹아 있는 O₂·CO₂.

## 2. 혈장 단백질 (10:41 ~ 14:33)
- 혈장의 기능을 **혈장 단백질**이 담당.
- 거대 분자가 **콜로이드** 형태로 존재 → 너무 커서 **간질액으로 못 나감** → 혈장 안에 머물며 **삼투압** 형성 → 액체를 끌어당겨 혈장이 모세혈관 밖으로 새지 않게 함.
- 아미노산의 산성·염기성 잔기가 양성자를 잡아 **pH 완충**.
- **알부민**: 가장 많음 → **교질 삼투압**을 가장 많이 만듦 + 물에 잘 안 녹는 물질을 **비특이적**으로 붙잡아 운반.
- **글로불린**: 잘 안 녹는 물질 운반 + 혈액 응고 + 염분 균형. α·β·γ가 있고 **γ-글로불린 = 면역글로불린(항체)**, 전체 혈장 단백질의 10% 이상.
- **피브리노겐**: 지혈 과정에서 혈액 응고.

## 3. 적혈구 — 모양과 헤모글로빈 (14:33 ~ 18:55)
- 주 기능 = **O₂ 운반**. O₂는 혈장 용해도가 제한적 → **헤모글로빈**으로 추가 운반, CO₂와도 결합.
- O₂는 별도 운반체 없이 **확산** → 폐에서 받고 조직에 내줌 → 표면적이 넓은 **납작한 원반**, 핵이 빠져 가운데가 눌린 모양.
- 작고 막이 얇아 확산에 유리, 모세혈관에 들어갈 크기. **유연한 막**으로 적혈구 하나가 겨우 지나가는 가는 모세혈관도 모양을 바꿔 통과.
- **헤모글로빈**: α 폴리펩타이드 2 + β 폴리펩타이드 2 = 서브유닛 4개, 각 중심에 **철(Fe)을 가진 헴 그룹** → 철이 O₂를 붙잡음. **적혈구에만** 있음.
- 천연 색소: O₂와 결합(산소화)하면 **붉은색**, 탈산소 상태는 파랗다기보다 **더 짙은 붉은색**(혈관이 파래 보일 뿐).
- ⭐ O₂뿐 아니라 **CO₂**도 운반, **H⁺**를 잡아 pH 유지, **CO(일산화탄소)·NO(혈관 확장 물질)**도 결합.

## 4. 적혈구 — 핵·세포소기관 없음과 효소 (18:55 ~ 21:41)
- **핵·세포소기관이 없음** → 헤모글로빈 양을 최대화, 산소 운반에만 최적화.
- 생성: 만능 줄기세포 → **골수성 줄기세포(myeloid stem cell)**(골수 속, 계통이 어느 정도 정해짐) → 적아구 → **에리트로포이에틴** 같은 조혈 인자를 받으면 성숙하며 **핵·세포소기관(미토콘드리아 포함)이 분해되어 사라짐**.
- 분열은 못 해도 살아야 하니 에너지 효소는 가지고 분화:
  - 미토콘드리아가 없어 전자전달계 ✗ → **해당과정** 의존(해당 효소).
  - ⭐ **탄산탈수효소(carbonic anhydrase)**: CO₂ ⇌ **중탄산(HCO₃⁻)** 양방향 전환 → 조직에서는 CO₂를 받아들이고 **폐 모세혈관**에서는 내보내게 해 CO₂를 계속 운반.
- 적혈구의 CO₂ 운반 방법(헤모글로빈 결합 / 그 외)은 **다음 챕터(호흡)**에서.

## 5. 염소 이동 (chloride shift, Hamburger effect) — 추가 슬라이드 (21:41 ~ 23:26)
- 체순환 모세혈관: 탄산탈수효소가 CO₂를 **HCO₃⁻**로 계속 바꾸고, **AE1**(Cl⁻/HCO₃⁻ 역수송체)이 HCO₃⁻를 혈장으로 내보내고 **Cl⁻를 들여옴** → CO₂를 계속 받아들일 수 있음.
- 폐 모세혈관: AE1이 **반대 방향** → HCO₃⁻가 다시 들어와 **CO₂로** 바뀌어 날숨으로 나감.
- 적혈구 막에서 **HCO₃⁻와 Cl⁻를 교환** → CO₂를 운반해도 **전기적 중성**과 **H⁺ 농도**의 균형이 유지됨 = **chloride shift(햄버거 효과)**.

## 6. 적혈구 생성과 EPO (23:26 ~ 26:23)
- 적혈구를 만드는 과정 = **적혈구 생성(erythropoiesis)**(조혈 = hematopoiesis). 핵이 없어 분열 ✗ → 계속 새로 만들어야 함 → **골수**.
- 수명 약 **120일**("짧다고 써 놨지만 그렇게 짧은 것 같지는 않다"), 낡은 적혈구는 **비장**에서 제거.
- 붉은 골수의 **조혈모세포**가 적혈구뿐 아니라 **백혈구·혈소판**으로도 분화.
- 조절 호르몬 = **에리트로포이에틴(EPO)**, **콩팥**에서 만듦. 콩팥이 산소를 감지 → 부족하면 EPO 분비 → 골수에서 적혈구 생성 = 장기 간 **크로스 토크**, 콩팥의 **내분비** 기능.
- 빈혈 치료제: **에포젠(Epogen)**, **아라네스프(Aranesp)** — EPO 재조합 단백질(유사체), **바이오 의약품**.

## 7. 백혈구 (26:23 ~ 31:21)
- 면역 방어 담당. 면역세포 기능은 면역학에서 → **표면적인 것만**.
- 면역 = 자기가 아닌 것(종양 같은 비정상 세포, LPS 같은 병원체·병원체 패턴)을 인식해 제거·중화하고 기억 면역을 형성. 면역계 = **"정상 자기(normal self)"가 아닌 외래 것을 제거·중화**.
- 백혈구는 **혈액 밖으로 나와** 방어 — 병원체는 혈관 안보다 **조직**에 있을 확률이 높음 → 조직에서 **케모카인·사이토카인**을 내면 끌려 나와 병원체를 중화·제거·포식. 혈액에 있는 이유 = 언제든 **필요한 곳으로 이동**하기 위해.
- 다섯 종류: **과립구**(과립이 뭉쳐 보임) = 호중구·호산구·호염기구 / **무과립구** = 단핵구·림프구.
  - **단핵구**: 직접 식세포작용 → 대식세포·수지상세포.
  - **림프구**: 항체 생성·방어 → **T세포·B세포**.
- 수치: **1 mm³**당 백혈구 약 **7,000**, 적혈구 약 **500만**, 혈소판 약 **25만**.
- **골수성 줄기세포** → 과립구·단핵구 / **림프성 줄기세포** → 림프구.
- 백혈구는 항상 일정하게가 아니라 **필요할 때(침입·위급)** 많이 만들어짐. 생산 이상이 생길 수 있고, **백혈병** = 백혈구의 통제되지 않는 증식.

## 8. 혈소판과 지혈 (31:21 ~ 40:09)
- 혈소판 = 거대한 **거핵세포(megakaryocyte)**가 찢어지며 생긴 **세포 조각**. 거핵세포는 골수에 붙어 있고 백혈구보다 약 **50배** 큼. 거핵세포 하나 → 혈소판 약 **1,000개**.
- **트롬보포이에틴(TPO)**: **간**에서 만들어져 골수의 거핵세포에서 혈소판 생성을 도움. 비교: **EPO = 콩팥 → 적혈구**, **TPO = 간 → 혈소판**.
- 혈소판: 핵 없음, 그러나 **세포소기관 있음** — 에너지 생성 효소, 응고에 필요한 단백질을 **분비**하는 소기관. **액틴·마이오신**으로 **수축**. 분비·수축 기능이 **지혈**에 중요.
- 지혈이 중요한 이유: 피가 줄 뿐 아니라 혈액 속 물질이 주변 조직으로 나가 문제를 일으킴 → 손상을 막고 복구.
- **지혈 3단계**
  1. **혈관 수축(vascular spasm)**: 혈관이 터지면 주변 혈관이 즉시 수축 → 그쪽으로 피가 덜 지나가 새는 양을 1차로 줄임.
  2. **혈소판 마개(platelet plug)**: 평소 혈소판은 매끈한 **내피**에 붙지 않고 부딪혔다 지나감. 혈관이 찢어지면 내피 바깥의 **콜라겐이 노출** → 혈소판이 인식해 **부착(adhesion)** → 활성화 → **ADP·트롬복세인 A₂**로 혈소판을 더 **모음(recruitment)** → 뭉쳐 **마개**.
  3. **혈액 응고(coagulation)**: 액체였던 피가 **젤처럼 굳음**. 혈장 단백질 **피브리노겐(녹아 있음) → 피브린(녹지 않는 실)**, 촉매 = **트롬빈**. 피브린이 혈관 표면에 붙어 **그물망** → 혈구·혈소판이 들러붙음.
- 응고 연쇄(cascade): 여러 활성 인자와 **Ca²⁺**·단백질을 거쳐 트롬빈이 만들어지고, 피브린이 처음엔 느슨한 그물 → 보조 인자가 더해져 **안정화**. ⭐ "아는 건 그렇게 중요한 것 같지 않아 넘어가겠다."
