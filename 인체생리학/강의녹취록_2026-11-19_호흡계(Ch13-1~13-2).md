# 1교시 (파일 2)

## 0. 공지 (파일 2 01:04 ~ 01:46)
- 기말고사 **14일**, 시간 확인할 것. 다음 주 목요일 수업은 **온라인**, "26일까지만 들으시면 됩니다."
- 호흡계는 고등학교·대학교에서 한 번쯤 배웠을 것. "저도 그렇게 깊게 들어가고 있지는 않거든요. 원래 생리학이 그런 과목입니다."

## 1. 폐포 사진과 구조 (02:24 ~ 04:21) — 슬라이드 2
- 공기 교환이 일어나는 곳 = **폐포**(복수 alveoli, 단수 alveolus). SEM이라 표면을 본 사진.
- 폐포를 둘러싼 막이 **아주 얇고**, 그 사이로 **모세혈관**이 지나가며 적혈구가 공기를 교환.
- O₂·CO₂는 **운반체(transporter)가 따로 없어** 농도 기울기를 따라 높은 쪽 → 낮은 쪽으로 이동.
- 비유: **포도 알 = 폐포**, **포도송이 = 폐포낭(alveolar sac)**. 주변 모세혈관이 파란 피를 받아 O₂를 실어 빨간 피로 내보냄.

## 2. 항상성 관점의 호흡계 (04:21 ~ 07:27) — 슬라이드 3
- 세포는 포도당·지방산 같은 **탄소 물질**로 ATP를 얻고, 그 과정에서 **CO₂**가 생김. ATP 합성효소가 일하는 과정(양성자 펌핑, 전자전달계)에 **O₂**가 필요.
- ATP는 단백질 합성, 분비, DNA·RNA 합성 등 거의 모든 일에 쓰이는 **에너지 화폐**.
- CO₂는 **체순환 모세혈관**에서 혈액이 모아 와서 **폐**에서 내보냄.
- CO₂가 제거되지 않으면 **탄산(H₂CO₃)**·중탄산 반응으로 **H⁺**가 생겨 **pH ↓** → 산성 환경에서 단백질 기능 ↓, 질병.
- 폐의 가스 교환은 에너지를 쓰는 능동 과정이 아니라 **수동 확산(passive diffusion)**.
- 호흡계의 항상성 = 조직·혈액의 **가스 농도를 일정하게** 유지. 대기 ↔ 모세혈관 교환 + 혈액이 조직으로 전달하는 과정까지 넓게 보면 호흡계의 일.

## 3. 호흡계 구분과 세기관지 (07:27 ~ 08:58) — 슬라이드 3
- **상부**: 비강, **구강**(입으로도 숨 쉼), 인두(pharynx), 후두(larynx) → 공기가 지나가는 곳.
- **하부**: 기관(trachea), 기관지(bronchi), **세기관지(bronchiole)**, 폐포낭, 폐포 → 실제 교환·생리적 조절이 일어나는 곳.
- ⭐ **세기관지 ≈ 세동맥**: 세동맥이 수축하면 TPR ↑ → 혈압 ↑인 것처럼, 세기관지도 **신경으로 조절**되어 공기 교환을 컨트롤함.

## 4. 호흡계 영상 해설 (08:58 ~ 22:10) — 슬라이드 5
- **비강**: 섬모(cilia)와 **점액(mucus)** → 들어오는 공기의 **습도·온도를 올려** 폐 자극을 줄임 + 공기 속 바이러스·감염 물질을 거르는 **1차 면역 방어**.
- **인두·후두**는 식도와 길을 공유 → 막아 주는 벽(후두덮개)이 음식물이 기관으로 들어가지 않게 함(소화계에서 다시).
- **기관·기관지**: 폐가 양쪽이라 기관지(bronchus)가 둘(bronchi). **연골 조직(cartilaginous tissue)**이 둘러싸 **항상 열려 있게** 붙잡음 — 막히면 교환이 안 되기 때문.
- **폐엽**: 대부분 심장이 왼쪽으로 커서(좌심실이 두꺼움) **왼쪽 폐가 작고 엽이 2개, 오른쪽 3개**. (곁가지: 심장 판막도 오른쪽 삼첨판·왼쪽 이첨판 — "전혀 상관없는 것 같긴 한데", 심장 때문에 왼쪽에 엽이 하나 덜 생긴다고 알려져 있음)
- ⭐ **호흡근은 골격근** → 심장 펌프와 달리 **의식적으로 조절 가능**. 늑간근(외·내), 횡격막, 그리고 공기를 완전히 내보낼 때 **복근**. 근육이 폐 주변 부피 → 압력을 바꿔 대기압보다 높냐 낮냐에 따라 공기가 드나듦. "**근육이 좀 많이 중요한 것 같습니다.**"
- **화학 조절**: CO₂ ↑ → pH ↓ → 혈액·**뇌척수액(CSF)** 산성화. 센서가 **혈관 쪽**과 **연수**에 있어, 연수는 CSF pH ↓를 감지하면 호흡을 늘림.
- 호흡은 **수의적 + 불수의적(자율신경계)** 이중 경로.
- **표면활성제(계면활성제)**: 폐포는 끈적해서 **탄력 반동으로 쪼그라들려는** 성질 → 2형 폐포세포가 표면활성제를 분비해 **표면장력 ↓**, 폐포가 팽창한 상태 유지. **신생아**는 잘 안 만들어져 **호흡곤란증후군**이 생길 수 있음.

## 5. 세포호흡 vs 외호흡 — 외호흡 4단계 (22:10 ~ 24:27) — 슬라이드 6
- 호흡 = **세포 안의 호흡(세포호흡)** + **개체가 외부와 하는 호흡(외호흡)**. 이 장은 외호흡: 세포호흡에서 쓴 O₂·생긴 CO₂를 항상성 수준으로 되돌리는 교환.
1. **호흡·환기(breathing, ventilation)**: 코·입으로 공기를 드나들게 함.
2. **폐포 ↔ 폐모세혈관 혈액** 사이 확산.
3. 폐정맥·대동맥을 타고 조직으로 **운반(transport)**.
4. **체순환 모세혈관 ↔ 조직** 사이 O₂·CO₂ 교환(역시 농도 기울기를 따른 수동 확산).
- 세포호흡 = 그 안(미토콘드리아)에서 에너지를 얻는 과정.

## 6. 호흡계의 비호흡 기능 (24:27 ~ 28:36) — 슬라이드 7
- **수분 손실·열 배출**: 내쉬는 공기는 늘 가습되어 수증기가 많음 → 물이 빠져나감. 몸에서 나가는 공기는 따뜻해서 **열 방출 경로**.
- 폐포 내벽으로 들어오는 공기는 점액 덕분에 미리 가습되어 있음.
- **정맥 환류 ↑**: 들숨 때 흉강 부피 ↑ → **보일의 법칙**으로 압력 ↓ → 심장 쪽으로 피가 더 들어옴(10장 정맥 환류 5요인).
- **산–염기 평형**: CO₂가 H⁺를 만들기 때문.
- **발성·후각**(코·입·목).
- **면역**: 점액·면역세포가 들어오는 길목에 있어 이물질 제거.
- **프로스타글란딘 비활성화**: 염증 촉진 물질. 전신 염증이 과하면 **폐 모세혈관 내피세포**가 비활성화해 줄임("사실 폐가 하는 게 아니라 폐 근처 모세혈관이 하는 것").
- **안지오텐신 II 활성화**: 같은 내피세포의 **ACE(안지오텐신 전환효소)**가 **안지오텐신 I → II**. 안지오텐신 II → 수분 재흡수 ↑(체액량 ↑) + 혈관 수축(TPR ↑) → **혈압 ↑**.

## 7. 호흡 해부 — 기도와 폐포 세포 (28:36 ~ 33:07) — 슬라이드 8
- 호흡계 = **기도(airway) + 폐 + 호흡근** 세 부분. 호흡근도 호흡계의 일부.
- 기도 = 대기 ↔ 공기주머니(air sac) 사이 관: 코·입 → **인두(목)** → **후두**(더 아래) → **기관(기도)** → 기관지 → 세기관지 → 폐포. 내려갈수록 **가늘어지고 수가 많아짐**(순환계가 모세혈관으로 쪼개지듯).
- **기도는 항상 열려 있음**: 기관·기관지를 **연골 고리(cartilaginous ring)**가 붙잡아 닫히지 않음.
- **세기관지 벽 = 평활근, 자율신경(ANS) 지배** (세동맥과 비슷)
  - **부교감** 활성 → 세기관지 평활근 **수축** → 지름 ↓ → 공기 ↓ → 공기 교환 ↓
  - **교감** → 평활근 **이완** → 공기 교환 ↑
- **폐포(air sac)**: 벽이 매우 얇고 주변을 폐모세혈관이 지나 교환이 쉬운 구조.
  - **1형 폐포세포**: 대부분, 얇고 **납작(flat)** → **가스 교환**이 직접 일어나는 곳.
  - **2형 폐포세포**: **입방형(cube)** → **폐 표면활성제** 분비(표면장력 ↓) + 1형이 손상되면 **줄기세포**처럼 1형으로 **분화**해 구조 유지.

## 8. 해부 그림 — 기도 순서와 콘 구멍 (33:07 ~ 34:49) — 슬라이드 9
- "여기 **항상 헷갈리는데**" — **인두(pharynx) → 후두(larynx)**(목의 조금 아래쪽) → 기관 → 두 갈래 기관지 → 세기관지. 후두까지는 큰 기능은 없는 것 같음.
- 가장 마지막으로 갈라진 제일 가는 세기관지 = **종말세기관지(terminal bronchiole)** → 여러 **폐포낭**이 모인 곳으로 연결.
- 폐포낭 = 폐포가 **포도송이처럼** 모인 것, 제일 작은 단위(동그라미 하나) = 폐포.
- 폐포와 폐포 사이에 작은 **구멍(pore, 콘 구멍)** → 폐포끼리 공기가 통함.

## 9. 폐포와 폐모세혈관 (34:49 ~ 37:56) — 슬라이드 10
- 납작하고 얇은 경계 = **1형**, 납작하지 않은 소수 세포 = **2형**(표면활성제 분비, 염색 사진에서 더 큼).
- 공기에 병원체가 많으므로 폐포에 **대식세포(macrophage)**가 많음.
- **탄성섬유(elastin fiber)**: 혈관에도 있었던 것. 폐포가 스스로 수축할 수 있게 **탄력 반동(elasticity)**을 줌.
- 폐포 경계는 얇은 **폐포액(alveolar fluid)**으로 덮여 있음 — 기체가 세포에 직접 닿으면 말라서 문제. 여기에 2형 세포의 표면활성제가 많이 있어 **과하게 수축하는 것을 막음**.
- 공기–혈액 사이 두께 **0.5 μm(500 nm)** → 교환이 잘 됨.
- 폐포는 얇고 넓게 펼쳐진 구 모양 → **표면적 극대화**(→ 위 확인 표: 실제로는 폐포 수가 많아서).

## 10. 폐엽 · 흉강 · 흉막 (37:56 ~ 43:21) — 슬라이드 11–12
- 폐엽: **왼쪽 2, 오른쪽 3**(앞에서 보면 3·2), 각 엽마다 기관지 하나.
- 폐 = 탄성 결합조직(연골도 결합조직), 폐포낭 주변 **탄성섬유** → 주변 압력에 따라 부피가 잘 변함.
- **골격근**: 횡격막·늑간근·복근 = 세 종류 근육 중 **골격근**. 흉강 부피를 바꿔 압력 → 공기 출입.
- **평활근**: 세동맥처럼 **세기관지**에도 있음 → 신경계가 공기 교환 조절.
- ⭐ 원리: 근육이 **흉강(흉곽)의 부피**를 바꿔 → 폐 부피가 바뀌어 → 공기 출입.
- **흉강** 안: 폐, 일부 신경, 기도, **흉선(thymus)**, 심장·관상혈관.
- **흉곽**: 갈비뼈 **12쌍**이 가운데 **흉골(sternum)**에 붙고, 뒤는 **흉추**(T 척추). 바닥 = **횡격막** → 횡격막의 수축·이완이 흉곽 부피를 조절.
- ⭐ **흉막 주머니(pleural sac)** = 폐 바로 바깥의 주머니(폐가 둘이니 좌·우). 그 안쪽 공간 = **흉막강(pleural cavity)** = 폐와 흉막 주머니 벽 사이.
  - 비유: **풍선에 막대사탕을 넣은** 모양.
  - 흉막강은 **흉막액(intrapleural fluid)**으로 차 있고, 흉막 주머니 표면에서 분비됨. 흉막 주머니 바깥 = **흉벽**.
  - 흉막 주머니가 팽창·수축하면서 **폐를 간접적으로** 팽창·수축시킴 → 공기 출입. "**폐를 둘러싸고 있는 주머니라는 거를 기억**해 두시면 될 것 같습니다."

## 11. 호흡 역학 — 세 압력, 경벽압, 보일의 법칙 (43:21 ~ 51:58) — 슬라이드 14–17
- ⭐ "기본적으로 **기압 차가 중요**합니다." 대기압은 일정 → **폐포 기압이 대기압보다 높냐 낮냐**로 환기 결정.
- 세 압력: **대기압**, **폐포내압(intra-alveolar)**, **흉막내압(intrapleural)**.
- **경벽압 기울기(transmural pressure gradient)** = 벽을 사이에 둔 압력 차. **흉막내압이 항상 폐포내압보다 낮아서** 폐가 항상 **부풀어 있음**. 반대로 흉막 쪽이 더 높으면 폐가 눌려 쪼그라듦.
- 폐에는 **근육이 없음** → 흉곽 ↑ → 흉막 주머니 ↑ → 폐 ↑ → 공기 유입. 폐는 전체 움직임을 **따라가며** 수동적으로 부피 조절.
- 휴식 시 흉막강과 폐포 사이 **4 mmHg** 차 → 폐를 둥글게 팽창시키는 원동력.
  - 폐포내압 **760**: 들숨 때 **760보다 낮춤** → 공기 유입 / 날숨 때 **760보다 높임** → 공기 유출.
  - 흉막내압 **756**: 들숨 때 756보다 낮아지고, 날숨 때 756보다 크게 높아지지는 않음(756으로 돌아옴).
- **보일의 법칙**: 온도 일정 → **압력 × 부피 = 일정**. 호흡근(복근·횡격막 등)이 흉강 부피를 바꿔 압력을 조절. 흉곽 부피 ↓ → 압력 ↑ → 공기 유출.
- 폐 부피와 폐포내압(슬라이드 17): 이완 상태 760/756 → 들숨 = **들숨근 수축**으로 흉강 팽창, 기압 ↓ → 공기 유입 → 날숨 = **들숨근 이완**(일부 날숨근 수축도 있지만 기본은 들숨근 수축/이완) → 폐 내부 기압 ↑ → 공기 유출.
- ⭐ **순응도(compliance)**: 표면활성제 같은 것이 있으면 주변 압력 차를 따라 **자유롭게 팽창**하는 성질 → **들숨**.
- ⭐ **탄력 반동(elastic recoil)**: 폐포액의 **높은 표면장력** + **탄성섬유** 때문에 폐가 **원래대로 수축하려는** 성질 → **날숨**.
- "여기는 제가 11시 5분부터 이어서 하겠습니다." [51:58] → 쉬는 시간

## 12. 호흡근 — 영상과 한 번의 호흡 주기 (00:00 ~ 16:13) — 슬라이드 18–21
- **횡격막** 수축 → **아래로 내려옴** → 흉곽 부피 ↑ → 흉막 주머니 부피 ↑·압력 ↓ → 폐포 부피 ↑·압력 ↓ → 공기 유입. [01:00]
- ⭐ **외늑간근 = 들숨(inspiration), 내늑간근 = 날숨(expiration)** — 이름과 기능이 "반대로" 되어 있어 헷갈림. [02:09]
  - 외늑간근(늑간근 중 **바깥쪽**) 수축 → 갈비뼈 **위로** → 부피 ↑ → 압력 ↓ → 공기 유입.
  - 내늑간근 수축 → 갈비뼈 **아래로** → 공기 유출.
  - 늑간근 = **늑골(rib) 사이** 근육. 배 쪽에서 보면 외늑간근이 앞, 내늑간근이 뒤.
- **보조 근육**(더 강하게 들이쉬거나 내쉴 때)
  - 목 쪽 근육: 갈비뼈를 끌어올려 흉강 ↑ → **깊은 들숨**.
  - **복근**: 수축 → 횡격막을 위로 올려 흉곽 부피 최소화 → **날숨**. 평소엔 호흡에 관여 안 하고, 강하게 숨 쉬거나 뛸 때 사용.
- ⭐ **주 들숨근 = 횡격막 + 외늑간근** [06:10]
  - 횡격막: 위아래 부피 ↑ / 외늑간근: **양옆·앞뒤** 부피 ↑(근섬유 방향 때문에 수축하면 갈비뼈가 위로).
  - 내늑간근은 근섬유 방향이 반대 → 수축하면 갈비뼈가 아래로.
- **조용한 날숨 = 수동**: 들숨근이 **이완** → 갈비뼈 내려가고 횡격막 원위치 → 흉벽 원위치 + 폐의 **탄력 반동** → 원래 크기 → 폐포내압이 다시 대기압 수준 이상. "특별히 어떤 근육이 수축한다기보다 수축했던 근육이 원래 상태로 이완."
- **강한(능동) 날숨**: 한 번에 교환하는 공기량을 늘려야 할 때.
  - ⭐ **주 날숨근 두 개 = 복근 + 내늑간근** [11:27]
  - 복근 수축 → **복압 ↑** → 횡격막 위로 / 내늑간근 수축 → 갈비뼈 더 아래로 → 흉강 부피 최소 → 압력 ↑ → 공기 최대한 유출.
- 압력 그래프(슬라이드 20–21): 들숨 근육 수축 → 흉막 주머니 압력 ↓ → **경벽압 기울기** → 폐가 따라 팽창("압력이 낮은 진공 상태에 있으면 물체가 부풀어 오르잖아요" → **순응**).
  - 폐포내압: 들숨 때 **759**(대기압보다 1 낮음), 날숨 때 **761**(1 높음).
  - 흉막내압: 흉곽 부피가 먼저 변해서 **756 → 754**로 떨어졌다가 **756까지 돌아옴**(756보다 올라가지는 않음) → 둘 사이에 **항상 약 4의 경벽압**.
  - 공기를 빨아들이려면 **먼저 흉막내압이 낮아지도록** 흉강 부피가 변함.
- 수동 날숨: 외늑간근·횡격막 원위치로 끝 / 능동 날숨: **내늑간근 + 복근** 수축 추가.
- **학생 질문** [14:51]: "외늑간근이랑 내늑간근 구분해야 되나요?" → ⭐ "**네.** 기능이 아예 달라. 일반 호흡은 **횡격막 + 외늑간근**만으로 가능, 더 능동적으로 내보내려면 **복근 + 내늑간근**까지 → **익스터널·인터널 구분해야 됩니다.**"
- 교수님은 고등학교 생물에서 배웠지만 요즘은 필수로 안 배우는 것 같아 설명함.

## 13. 기도 저항 (16:13 ~ 20:33) — 슬라이드 22
- 공기가 지나는 길(기관·기관지)은 마찰이 있어 **저항**이 생김. "진짜 **혈액의 이동처럼**" 공기 흐름도 저항의 영향을 받음.
- **F = ΔP/R**: 압력 기울기(ΔP)는 기도가 정하는 게 아니고(앞에서 다룬 근육·압력), 기도가 조절하는 것은 **저항(R)** = 결국 **기도 지름(반지름 r)**.
- 반지름 ↓ → 저항 ↑ → 흐름 ↓ / 반지름 ↑ → 저항 ↓ → 흐름 ↑.
- 반지름을 바꾸는 것 = 세기관지 **평활근 수축** → **기관지 수축(bronchoconstriction)**(혈관 수축 vasoconstriction처럼).
- **부교감 자극** → 세기관지 평활근 수축 → 공기 교환 ↓. 부교감은 "편안한 상태"가 목적이라 공기 흐름을 줄임.
- **화학 조절**: **CO₂ ↓ 또는 pH ↑** → "호흡이 충분하니 줄여라" → 수축. 신경적으로(호흡중추 감지)도, **국소적**으로(근처 CO₂)도 조절.
- **기관지 확장(bronchodilation)**: 반지름 ↑. **교감 자극**은 직접 평활근을 덜 수축시키기 어려워 **부교감에 비해 효과가 약함**(표 13-1 "minimal effect"). **CO₂ ↑ / pH ↓**(공기 교환 모자람) → 세기관지 확장.

## 14. 순응도 · 탄력 반동 · 표면활성제 (20:33 ~ 25:15) — 슬라이드 23
- 폐가 늘 같은 정도로 늘었다 줄었다 하는 게 아님 — 예: **폐 섬유화(fibrosis)** 환자는 폐가 **뻣뻣**해서 압력 차로 부피를 잘 못 바꿈. 폐의 성질이 공기 교환을 결정.
- **순응도** = 얼마나 잘 늘어나나 / **탄력 반동** = 얼마나 잘 원래대로 돌아오나.
- **탄력 반동 요소 두 가지**: ① 폐포를 덮은 액체의 **표면장력**(서로 끌어당겨 수축하려 함) ② 폐포 주변 **탄성섬유**(엘라스틴·콜라겐 결합조직).
- ⭐ 기압 변화가 없을 때 폐포를 쪼그라들게 만드는 **주요 요인(major factor) = 폐포액의 표면장력**.
- **표면활성제**: **2형 폐포세포**가 만듦(계면활성제) → 폐포 내벽 액체와 섞여 **물 분자 사이 수소결합을 끊어** 표면장력 ↓ → 탄력 반동 ↓, **순응도 ↑**.
- ⭐ 표면활성제 많음 → **탄력 반동 ↓, 순응도 ↑** → 폐포 허탈(collapse) 방지, 폐가 늘 팽창한 구조 유지.
- **신생아 호흡곤란증후군**: 표면활성제가 잘 안 만들어져 순응도 부족 → 폐가 쪼그라들어 교환이 잘 안 됨.
- 그림: 폐포 주변 하늘색 = 폐포액(표면장력), 2형 세포가 표면활성제를 섞어 줌.

## 15. 폐용적 (25:15 ~ 28:30) — 슬라이드 24–25
- 최대 폐 용량: **남 5.7 L, 여 4.2 L**(교과서는 5.7 L 기준). 한 번 숨 쉴 때 5.7 L가 다 드나드는 게 아님.
- **1회 호흡량(tidal volume)** ≈ **500 mL**("조석처럼 들어갔다 나갔다") → 나머지 5.2 L는 교환 안 됨.
- X선 찍을 때 최대로 내쉬어도 **잔기량(residual volume) 1.2 L**가 남음 → 최대로 내쉰 상태에서도 혈액–폐포 공기 사이 교환은 계속됨.
- ⭐ "**요런 지표들은 넘어가도록 하고요**" [27:15] — 스파이로그램 세부 지표는 건너뜀.
- **스파이로그램** = 폐 속 공기 부피 기록. 최대 5.7 L는 최대로 들이쉬었을 때. 조용한 호흡은 **2.7 L ↔ 2.2 L** 사이에서 **500 mL**씩. (5.7 L에는 기관 등에 든 공기도 포함일 것)

## 16. 폐환기 vs 폐포환기 — 사강 (28:30 ~ 34:16) — 슬라이드 26
- 환기(ventilation) = 공기 교환. ⭐ **폐포환기 < 폐환기**: 지나가는 길목(기도)의 공기는 폐포를 통해 교환될 수 없음 = **사강(dead space)**.
- **폐환기 = 1회 호흡량 × 호흡수(respiratory rate)** = 1분 동안 드나드는 전체 공기.
- ⭐ 폐환기를 늘리려면 **1회 호흡량을 늘리는 게 더 효과적** — 사강이 일정해서, 자주 쉬면 **과호흡**만 생김. **깊게** 들이쉬어야 함.
- **해부학적 사강 150 mL**(기도에 갇힘): 500 mL를 들이쉬어도 150은 교환 안 됨 → 매번 **350 mL**만 새 공기로 폐포에 공급. 내쉴 때도 150(헌 공기)은 그대로 남음.
- **폐포환기 = (1회 호흡량 − 사강) × 호흡수** → 이 예에서 폐환기의 약 **70%**(350/500). = 실제로 **대기 ↔ 폐포** 사이에서 교환된 공기량.
- **폐포 사강**(질환): **폐색전증** — 혈전이 **폐동맥**을 막아 공기는 드나들지만 폐모세혈관에 피가 안 가서 교환 안 됨.

## 17. 호흡 패턴 (34:16 ~ 35:22) — 슬라이드 27

## 18. 세기관지·폐세동맥의 국소 조절 (35:22 ~ 43:00) — 슬라이드 28–29
- 세동맥 평활근 수축 → 혈관 수축 → **TPR ↑ → MAP ↑**처럼, 세기관지도 매우 비슷: 저항을 조절해 **공기 흐름** 조절.
- 세기관지 수축 → 반지름(r) ↓ → 저항(R) ↑ → 흐름 ↓(흐름은 저항에 반비례).
- **CO₂ → 세기관지(공기) 조절**
  - 폐포가 공기를 너무 적게 받음 → 국소 **CO₂ ↑**(H⁺ ↑, pH ↓) → 기도 평활근 **이완** → 기도 확장 → 공기 ↑.
  - **CO₂ ↓**(교환 과다) → 평활근 **수축성 ↑** → 저항 ↑ → 공기 ↓.
- **O₂ → 폐세동맥(혈액) 조절** — 세기관지가 아니라 폐모세혈관으로 들어오는 **세동맥**의 평활근.
  - (a) **혈류 > 공기**: 혈액의 O₂가 낮아 국소 **O₂ ↓** → **폐세동맥 수축** → 혈류 ↓(공기에 혈류를 맞춤). 동시에 CO₂ ↑ → 세기관지 **이완** → 공기 ↑.
  - (b) **공기 > 혈류**: **CO₂ ↓** → 기도 평활근 **수축** → 공기 ↓ / **O₂ ↑** → 폐세동맥 **이완(확장)** → 혈류 ↑.
- ⭐ "**CO₂는 공기를 조절하고 O₂는 혈액을 조절합니다.**" → 공기와 혈액의 가스 교환 **균형**을 국소에서 스스로 맞춤.
- "오늘 여기까지 하고 다음 주에 이어서 하도록 하겠습니다." [43:00]
