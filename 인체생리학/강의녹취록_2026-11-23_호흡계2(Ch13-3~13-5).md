## 0. 복습 — 국소 조절과 환기–관류 맞춤 (00:00 ~ 02:15) — 슬라이드 28–29
- **CO₂ → 세기관지(공기)**: CO₂ 낮음 = 교환 충분 → 세기관지 **수축** → 기도 저항 ↑ → 공기 ↓. CO₂ 높음 → 세기관지 **확장**.
- **O₂ → 폐세동맥(혈액)**: O₂ 높음 = 교환 충분 → 혈액이 더 와야 함 → **혈관 확장** → 혈류 ↑. O₂ 낮음 → 폐세동맥 **수축**.
- "**O₂는 혈관 쪽을 조절하고, CO₂는 에어웨이 쪽을 조절**하고요."
- 그림(AI 느낌 그림, 교수님이 그린 것은 아님): **환기–관류 맞춤(ventilation–perfusion matching)**. 환기 = 공기 교환, 관류 = 혈액 흐름. 정상 **V/Q ≈ 0.8**(환기 약 4 L/분 : 혈류 약 5 L/분).

## 1. 가스 교환 원리 — 분압 기울기 (02:15 ~ 04:33) — 슬라이드 31–32
- 가스도 **농도 기울기**를 따르는데, 기체의 농도를 재는 단위가 **압력** → **분압(partial pressure) 기울기**를 따라 **수동 확산**(에너지 X). O₂·CO₂ 모두 많은 쪽 → 적은 쪽.
- 확산을 최대화하려고 폐포–모세혈관 접촉 **표면적**을 최대로 한 구조.
- 분압 = **몰 분율** 기준: 대기 = N₂ **79%**, O₂ **21%**, CO₂ **0.03%**(+ 아르곤 등).
- ⭐ "분자량이 아니라 **분자 하나가 동일한 압력**" → "**몰 농도가 중요**".
- 대기압 **760 mmHg** = N₂ **600** + O₂ **160** + CO₂ **0.23**.

## 2. 폐포 공기 vs 대기, 폐·조직의 분압 (04:33 ~ 09:47) — 슬라이드 31, 33–35
- 폐포 공기의 분압 구성은 대기와 다름.
  - 기도(기관·기관지·목)를 지나며 **가습** → **수증기 분압**이 자리를 차지(슬라이드: P<sub>H2O</sub> = 47 mmHg).
  - 폐포 **P<sub>O2</sub> 100**(대기 160보다 낮음). 사강 등으로 다 못 나가는 CO₂가 있어 폐포 **P<sub>CO2</sub> 40**(대기보다 훨씬 높음).
  - 그래도 혈액보다는 O₂가 많고 CO₂가 적어 → O₂는 혈액으로, CO₂는 폐포로 **확산**.
- **폐순환**: 폐동맥으로 들어오는 혈액 **O₂ 40 · CO₂ 46** → 폐를 지나며 폐포와 **평형** → **100 · 40**(O₂ 많은 피 = 빨간색).
- **체순환**: 좌심방·좌심실 → 뇌·콩팥·심장 등 **병렬**로 연결된 조직. 조직은 세포호흡으로 O₂를 쓰고 CO₂를 내므로 **P<sub>O2</sub> < 40, P<sub>CO2</sub> > 46**(조직마다 다름) → 교환 후 정맥혈 평균 **40 · 46** → 폐동맥으로.
- 이 모든 교환은 분압 기울기를 따른 확산이며 **특별한 운반체(transporter)는 없음**.

## 3. 분압 기울기 외의 요인 (09:47 ~ 12:05) — 슬라이드 36 (표 13-5)
- **가장 주된 결정 요인 = 분압 차이**.
- **표면적**: 폐포–모세혈관 막은 표면적이 매우 넓음. **운동 중에는 조절되어 극대화**. 폐가 막히는 등의 상황에서는 교환이 잘 안 됨.
- **두께**: 정상에서는 조절 대상이 아님. **폐 섬유화(fibrosis)**, **폐렴** 같은 병적 상황에서 섬유가 많아지면 두께 ↑ → 교환 ↓.
- **확산계수**: ⭐ **CO₂ > O₂**. O₂ 기울기는 100 → 40으로 크지만 CO₂는 46 → 40으로 작음 → 그래도 CO₂가 잘 교환되는 이유 = **확산계수가 더 큼**(화학적 특성, 슬라이드: 20배).

## 4. O₂ 운반 — 헤모글로빈 (12:05 ~ 15:10) — 슬라이드 38–39
- 운반 단백질 = **헤모글로빈**.
- ⭐ 혈액 속 O₂ 두 형태: **물리적 용해 1.5%**(O₂는 용해도가 낮음) / **헤모글로빈 결합 98.5%**.
- 헤모글로빈 = **α 사슬 2 + β 사슬 2** = 서브유닛 4개, 각 중앙에 **헴(heme)**, 헴 중심에 **철(Fe)**. 탈산소 Hb ↔ 산소 Hb에서 철의 위치가 약간 위로 올라옴.
- O₂ 결합·방출은 **가역 반응**.
- Hb 1분자 = 헴 4개 → **O₂ 4분자** 운반. 혈액 P<sub>O2</sub>에 따라 몇 개의 헴이 O₂로 차는지가 결정됨.
- 포화도는 P<sub>O2</sub>에 비례하지만 **직선이 아니라 두 구간**으로 나뉜 곡선.

## 5. O₂–Hb 해리곡선 — 평탄부와 급경사부 (15:10 ~ 19:03) — 슬라이드 39
- 포화도의 **주된 요인(primary factor) = P<sub>O2</sub>**.
- 헴 4개 중 평균 3개가 O₂와 결합 = **포화도 75%**.
- 생리적 범위: 폐(신선한 공기) **100** ↔ 체순환 **40 이하**.
- **평탄부(plateau portion)**: 높은 P<sub>O2</sub> 쪽. P<sub>O2</sub>가 꽤 변해도 포화도가 크게 안 변함 — 직선이라면 40에서 40%여야 하는데 실제로 40에서도 **70–75%**.
  - 장점: 폐포 P<sub>O2</sub>가 100보다 살짝 낮아도(공기가 조금 모자라도) O₂를 **잘 싣는(loading)** 구간. 100 → 80·70으로 떨어져도 O₂를 내놓지 않고 잘 가지고 있음.
- **급경사부(steep portion)**: 40에서 조금만 떨어져도 **75% → 25%**까지 O₂를 잘 **내려놓음(unloading)**.
- 요약: 받아야 하는 곳(폐)에선 농도가 변해도 잘 붙잡고, 내놔야 하는 곳(조직)에선 조금만 떨어져도 많이 방출.

## 6. 헤모글로빈이 필요한 이유 (19:03 ~ 21:04) — 슬라이드 40
- Hb가 없다면 혈액 P<sub>O2</sub>가 폐포 P<sub>O2</sub>와 같아질 때까지만 O₂를 가질 수 있는데, O₂는 **잘 안 녹아서** 조금밖에 못 실음.
- (교수님이 잠시 말을 멈춤 — 위 확인 표 참고) Hb가 O₂의 약 **98%**를 붙잡아, 혈액 내 용해 농도가 낮아 수송을 못 하는 단점을 보완.
- ⭐ **폐(폐포)에서는 O₂ 저장고**, **조직에서는 빠른 O₂ 방출**. Hb가 없으면 전신 수준의 O₂ 전달이 어려움.

## 7. 오른쪽 이동 — O₂ 방출 촉진 요인 (21:04 ~ 24:40) — 슬라이드 41
- 곡선이 **오른쪽으로 이동** = 같은 P<sub>O2</sub> 40에서도 포화도가 **75% → 50%** 정도로 떨어짐 → **unloading 촉진**.
- 요인
  - **CO₂ ↑** = 혈액 **pH ↓**(탄산탈수효소 → 중탄산·H⁺ 생성으로 자동적으로 산성).
  - ⭐ **보어 효과(Bohr effect)**: CO₂나 pH 변화로 해리곡선이 이동하는 현상 — CO₂ ↑·pH ↓ → **오른쪽 이동** → Hb–O₂ **친화력 ↓** → O₂를 더 잘 놓음.
  - **체온 ↑**.
  - **2,3-BPG**: 적혈구가 **해당과정**으로 에너지를 얻으며 만듦 → "O₂를 더 내놔야 한다"는 신호. **고산지대**처럼 O₂가 부족할 때 RBC가 2,3-BPG 생산을 늘려 조직에 O₂를 더 방출.
- 운동하는 근육 등 **대사가 활발한 조직**에서는 곡선이 오른쪽으로 이동해 있어 O₂를 더 많이 받음.

## 8. CO₂ 운반 세 가지 + 염소 이동 (24:40 ~ 29:05) — 슬라이드 42–43
- O₂는 두 가지 형태였지만 CO₂는 **세 가지**.
  1. **용해 10%** — O₂보다 잘 녹음.
  2. **헤모글로빈 결합 30%** = **카바미노헤모글로빈(HbCO₂)** — 조직 모세혈관에서 O₂를 내준 뒤 CO₂를 받아 폐로 운반.
  3. ⭐ **중탄산 이온(HCO₃⁻) 60%** — 가장 많음. **용해도가 가장 높은** 형태. **탄산탈수효소**가 CO₂ → H₂CO₃ → HCO₃⁻로 전환 → 더 많은 CO₂를 저장.
- **염소 이동(chloride shift)**(11장 혈액에서 봤던 그대로): 탄산탈수효소가 반응을 계속 오른쪽으로 돌려 HCO₃⁻를 만들고, **Cl⁻와의 역수송체(antiporter)**로 HCO₃⁻가 혈장으로 나감. HCO₃⁻가 음이온이므로 음이온 하나(Cl⁻)를 받아 **전기적 균형** 유지.
- **폐에서는 반대**: 역수송체가 반대 방향으로, 탄산탈수효소가 HCO₃⁻를 다시 CO₂로(가역 반응) → 카바미노 Hb의 CO₂, 녹은 CO₂, 중탄산 형태 CO₂가 모두 **기체 CO₂로 폐포로 나감**.
- 체순환 모세혈관 = CO₂ 저장 / 폐모세혈관 = 역반응으로 방출.

## 9. 호흡기 질환 — 저산소증 (29:05 ~ 30:02) — 슬라이드 44
- 교환이 안 되면 **질식**, O₂가 부족하면 **저산소증(hypoxia)**.
- 예: 저산소 환경에서 **암세포**가 **VEGF(혈관내피성장인자)** 등을 만들어 암 조직으로 **혈관 생성**을 촉진.

## 10. 호흡 조절 — 리듬은 뇌간에서 (30:02 ~ 32:50) — 슬라이드 46
- 심장처럼 호흡도 의식하지 않아도 **주기적**으로 일어남(반은 의식적 조절 가능).
- 들숨근(횡격막·외늑간근)이 리듬 있게 수축 → **1분에 약 12번**.
- **호흡 중추 = 뇌간(brain stem)** → 리듬 있는 호흡 패턴 생성.
- ⭐ 심장은 SA 결절 같은 **박동조율 세포**가 있지만, 호흡근은 **스스로 활동전위를 만들지 않음** → 호흡 중추가 **주기적 신경 신호**를 보내야 수축. 이게 없으면 안 됨.
- 국소 O₂·CO₂ 변화, 특히 **CO₂ ↑ → pH ↓**를 인식해 호흡 중추가 신호를 더 많이 보냄.
- 의식적으로(말할 때 등) 바꿀 수도 있지만 기본은 호흡 중추의 리듬 있는 신경 자극.

## 11. 연수·교뇌의 호흡 중추 (32:50 ~ 35:05) — 슬라이드 47
- 주로 **연수**에 호흡 중추 → 주 들숨근(횡격막·외늑간근)의 수축·이완 명령.
- **등쪽호흡군(DRG)**: 연수의 등(dorsal) 쪽 — 들숨근을 지배하는 **들숨 뉴런**.
- **배쪽호흡군(VRG)**: 앞(ventral) 쪽 — **들숨근 + 날숨근** 모두 조절.
- ⭐ **프리뵈트징거 복합체(전뵈트징거 복합체)**: VRG의 일부, **호흡 리듬 생성** — 박동조율 활동을 가진 것.
- **교뇌(pons)** 호흡 중추 = 연수 중추를 조절.
  - **호흡조절중추(pneumotaxic center)**: 들숨이 과할 때 **들숨 뉴런을 꺼 줌**.
  - **지속흡식중추(apneustic center, 무호흡중추)**: 무호흡이 되지 않도록 **들숨 뉴런이 꺼지지 않게** 하는 보조 역할.

## 12. 환기량 조절 — 화학수용기 (35:05 ~ 41:34) — 슬라이드 48–49
- ⚠️ "**교과서가 약간 잘못된 부분이 있어 가지고 살짝 수정**" [35:05]
- 호흡 중추 = 신경 신호를 만들어 횡격막·외늑간근에 활동전위 전달. 환기량을 조절하려고 몸이 감지하는 것 = 혈액의 **O₂, CO₂, pH**. 기본 원리: "**CO₂가 많으면 호흡을 증가시켜라.**"
- 운동 등으로 전신 대사 ↑ → CO₂ ↑ → 환기 ↑. 이를 아는 경로는 "산소보다는 **이산화탄소 분압**".
- **화학수용기(chemoreceptor)** — 화학 농도를 재는 수용기.
- ⭐ **말초 화학수용기**: "**가장 중요한 거는 목 쪽에 있는 경동맥 소체(carotid body)**" — 연수와도 가까움. **대동맥궁의 대동맥 소체**는 보조(supportive).
  - **O₂는 주로 경동맥체**에서 측정. 몸이 O₂ 부족을 느끼는 건 **진짜 긴급한 상황에서만**.
  - 운동 등에서 환기를 늘리는 것은 **O₂ 감소보다 CO₂ 증가**.
- ⭐ **동맥 P<sub>CO2</sub> ↑** = 환기량을 **가장 주요하게** 조절. 호흡 중추 근처의 **뇌척수액 CO₂**, 경동맥체를 지나는 혈액의 CO₂를 측정 → 환기 ↑.
- **pH ↓(H⁺ ↑)**: CO₂ ↑이면 pH도 자동으로 ↓. **경동맥체(말초)**는 **CO₂ ↑ + pH ↓**를 인식.
- **중추 화학수용기(연수)**: 뇌척수액의 CO₂를 감지 — "요거는 **CO₂만**". 혈액의 H⁺는 CSF 쪽으로 잘 통과 못 함 → **pH는 말초에서만** 추가 감지. (정확히는: 동맥 H⁺는 BBB 통과 X, 중추는 CO₂가 만든 뇌 ECF H⁺를 감지 — 위 확인 표)
- CO₂ ↑·pH ↓ → **연수 호흡 중추 활성** → 횡격막·외늑간근이 더 강하게 수축 → 호흡이 **깊어짐**. "저번에 호흡 횟수보다 **1회 호흡량**을 늘리는 게 더 효과적이라고 했었고" → 이것이 연수 호흡 중추가 하는 일.
- 음성 되먹임: 동맥 P<sub>CO2</sub> ↑ → 말초·중추 화학수용기 자극 → 환기 ↑ → 동맥 CO₂ ↓.
- 결과: 1회 호흡량 ↑ → 폐가 더 늘어나 한 번에 더 많이 교환 → 더 큰 분압 기울기.

## 13. 강의 끝 요약 문제 (41:34 ~ 45:07)
1. **흡기 때 폐포내압은 어디까지 떨어지나**: 흉곽·폐를 팽창시켜 보일의 법칙으로 압력을 낮춤. 교수님은 "760이니까 756, 4 정도 차이"라고 설명했지만, 슬라이드 17·20 기준 **흡기 중 폐포내압 = 759**(1 ↓), **756 = 흉막내압**(흡기 때 754), **4 = 경벽압**. 0이 되면 진공이니 0까지는 안 떨어짐.
2. **표면활성제** → **정답 ②**: 폐포액의 **표면장력 ↓** → 폐가 쪼그라들기보다 잘 늘어남 → **탄력 반동 ↓, 순응도 ↑**, **폐포 허탈 방지**. 폐포 허탈 = 탄력 반동이 과해 폐가 너무 수축할 때. **신생아 호흡곤란증후군** = 표면활성제가 덜 만들어져 폐가 잘 팽창하지 못함.
3. **O₂–Hb 해리곡선(= 산소 포화 곡선)을 오른쪽으로 이동시키는 요인** → **정답 ③**: 온도 ↑, CO₂ ↑, "CO₂가 많아지면 **pH가 떨어지고 H⁺가 많아지는** 거기 때문에 요거는 3번". (교수님이 "O₂가 적어지거나"도 말했지만 슬라이드 기준 이동 요인은 CO₂·H⁺·온도·2,3-BPG)
4. **일산화탄소(CO)**: Hb와의 **친화력이 매우 높아** CO가 O₂ 대신 결합 → O₂가 전달되지 않아 **질식**.
