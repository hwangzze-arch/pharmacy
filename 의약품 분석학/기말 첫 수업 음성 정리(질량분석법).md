## 1. 질량분석법의 정의와 기기 구성 [파일1 00:47–05:31]

### 1-1. 정의와 특징
- 🗣️ 분광분석법으로 분류돼 있지만 **빛을 전혀 쓰지 않음** → 분광분석과 관계없음. 엄밀히는 기기분석을 **분광분석 / 질량분석 / 분리분석**으로 나눠야 함.
- 🗣️ 무게를 직접 달지 않고도 시료 구성 물질의 질량을 알아냄. 원자 상태든, 분자 상태든, 분석 중 쪼개진 **조각(fragment)** 상태든 **그 상태의 질량을 직접 측정할 수 있는 유일한 분석법**.

### 1-2. 3대 구성 요소 (+ 컴퓨터 시스템)
| 구성 | 역할 |
|---|---|
| **이온원 (Ion source)** | 중성 분자를 이온으로 만듦 |
| **질량분석관 (Mass analyzer)** | 이온 상태에서 m/z를 측정·분리 (종류 매우 다양) |
| **검출기 (Detector)** | 분리된 이온 검출 |

### 1-3. 왜 꼭 이온이어야 하나
- 🗣️ 우주의 4대 힘(강한 핵력·약한 핵력·중력·**정전기력**) 중 기기분석은 전부 **정전기력** 기반.
- 🗣️ 그래서 **중성 물질은 분석 불가, 이온만 분석 가능**. 의약품은 대부분 중성이므로 이온원에서 이온화한 뒤 분석. 중력 기반 질량분석기는 개발될 수 없으므로 앞으로도 이온만 분석함.

### 1-4. 기체 상태 이온 · m/z
- 🗣️ **기체 상태 + 이온** 둘 다 만족해야 분석 가능.
- 🗣️ 기체 이온에 전기장을 걸어(인력/척력) 매우 빠르게 가속 → 질량분석관 통과 중 측정.
- 🗣️ ★ 질량분석기는 **질량을 직접 측정하지 못함**. 과거·현재·미래의 모든 질량분석기는 항상 **질량 대 전하비 (m/z)** 를 측정.
- 결과는 UV-Vis·형광·NMR 스펙트럼처럼 **질량 스펙트럼(mass spectrum)** 으로 나타남.

## 2. 전자 이온화 (EI) — ⚠️ 녹음 누락, 📝 보충
- 📝 가열 필라멘트에서 나온 전자를 **70 V로 가속(70 eV)** 해 기체 시료 분자와 충돌 → 전자 1개가 떨어져 **분자 이온 M•⁺ (라디칼 양이온)** 생성.
- 📝 70 eV는 결합 에너지보다 훨씬 커서 **조각화가 많이 일어남 → 하드 이온화(hard ionization)**. 분자 이온 피크가 작거나 안 보일 수 있음.
- 🗣️ (파일 2 첫머리에서) "EI에서 분자가 너무 많이 깨지는 문제" → 이를 해결하려고 나온 것이 소프트 이온화.

## 3. 화학 이온화 (CI, Chemical Ionization) [파일2 00:00–03:39]
- 🗣️ **소프트 이온화(soft ionization)** 의 하나. 기체 상태의 **산-염기 반응 같은 화학 반응**으로 이온화.
- 🗣️ EI 장치를 그대로 쓰되 유일한 차이: 이온원에 **시약 기체(reagent gas)** 를 낮은 압력으로 불어넣음.
  - 시약 기체: **메탄(CH₄), 아이소뷰테인(isobutane), 암모니아(NH₃)**
- 🗣️ 전자 에너지는 EI(70 eV)보다 **더 강한 100–200 eV**.
  - 이유: 전자가 분석물이 아니라 **시약 기체와 충돌**하기 때문. 이온원 안에 분석물은 아주 적고 시약 기체가 훨씬 많으므로 전자빔이 먼저 시약 기체를 이온화함.
- 🗣️ 메탄 예시: CH₄ + e⁻(100–200 eV) → 일련의 반응 → **CH₅⁺** (기체 상태의 매우 강한 산)
  → CH₅⁺ + M(중성 목적 성분) → **[M+H]⁺ (양성자화 분자, protonated molecule)**
- 🗣️ [M+H]⁺는 엄밀히 분자 이온(M•⁺)이 아님 → 부가물(adduct)로 생기는 이 이온을 **준분자 이온(quasi-molecular ion)** 이라고 부름.
- 🗣️ 양성자화된 것을 알기 때문에 **측정 질량 − 1(H) = 원래 분자량**.
- 🗣️ 조각화가 거의 없어 분자량을 그대로 측정 가능. **현재는 하드보다 소프트 이온화를 더 많이 사용**.

| | EI | CI |
|---|---|---|
| 분류 | 하드 | 소프트 |
| 전자 에너지 | 70 eV | 100–200 eV |
| 전자가 충돌하는 대상 | 분석물 | 시약 기체 (CH₄, isobutane, NH₃) |
| 주 이온 | M•⁺ (분자 이온) | [M+H]⁺ (준분자 이온) |
| 조각화 | 많음 | 거의 없음 |

## 4. 분해능(Resolving power)과 해상도(Resolution) [파일2 03:40–10:50]

### 4-1. 분해능 RP — 얼마나 작은 질량 차이를 두 피크로 구분하나
**① 고전적 방법 — 인접한 두 피크 (10% valley)**
- **RP = m / Δm**
- 두 피크가 높이의 90%는 분리되고 골짜기에서 **10%만 겹친 상태**를 "충분히 분리됨"으로 정의. 이때 두 피크의 질량 차가 Δm, **작은 쪽 질량이 m**.
- 예: 500과 501이 10%만 겹침 → RP = 500/1 = **500**
- Δm이 작을수록 더 작은 차이를 구분 → **RP는 클수록 좋음**.
- 🗣️ 딱 10%만 겹치는 조건을 실험적으로 만들기 어려워 **지금은 거의 안 씀**.

**② 현대적 방법 — 단일 피크의 반치폭 (현재 표준)**
- **RP = m / m₁/₂ (= m / FWHM)**
- 피크 하나면 됨. m = 그 피크의 m/z, **m₁/₂ = 피크 높이 50% 지점의 폭 (Full Width at Half Maximum)**.
- 피크가 샤프할수록(FWHM 작을수록) **RP가 커서 좋음**.
- 🗣️ 같은 피크를 ①과 ②로 계산하면 숫자가 **2배 이상 차이** → 성능 차이가 아니라 **계산법 차이**.
- 🗣️ 폭이 넓어져 RP가 500으로 떨어지면 인접 두 피크가 완전히 하나로 겹쳐버림.

### 4-2. 용어 혼용 ★
| 용어 | 교과서 정의 | 좋은 방향 |
|---|---|---|
| Resolving power (분해능) | m/Δm 또는 m/FWHM | **클수록** 좋음 |
| Resolution (해상도) | 구분 가능한 최소 질량 차 **Δm = m/RP** | **작을수록** 좋음 |

- 🗣️ 현실에서는 섞어 씀: 이름은 **"Resolution"** 이라 부르면서 계산은 **m/FWHM** 으로 함 → "레졸루션이 클수록 좋다"고 말함. 고가 장비 이름도 **HRMS (High-Resolution MS)**.
- 🗣️ 질량분석에서 누가 Resolution이라고 하면 → **"Resolving power 얘기구나, 클수록 좋구나"** 로 이해.

### 4-3. 솔라닌(solanine, 배당체 천연물) 예시
- 위 기기: FWHM ≈ 0.5 → **RP ≈ 1,737** → 질량 1 차이를 겨우 구분
- 아래 고가 기기: 폭이 훨씬 좁아 **RP ≈ 48,250** → 0.01 차이도 쉽게 구분
- 📝 검산: 1,737 × 0.5 ≈ m/z 868 (솔라닌 [M+H]⁺ ≈ 868.5)과 맞음.

## 5. 동위원소 패턴 [파일2 10:51–28:40]

### 5-1. 동위원소체 (isotopologue)
- 🗣️ 한 물질인데 질량 1씩 차이 나는 피크가 여러 개 → 자연 동위원소 때문.
- 🗣️ **화학식·구조는 같고 동위원소 구성만 달라 질량만 다른 것 = 동위원소체(isotopologue)**.
- 🗣️ 동위원소는 질량분석의 **재앙이자 축복**: 자연 존재비가 정해져 있어 **어느 질량에 어느 비율로 나올지 확률 계산으로 완벽히 예측 가능** → 내가 생각한 물질이 맞는지 확인하는 데 활용.

### 5-2. 벤젠 C₆H₆ (EI)
- 고리의 C–C, C–H가 튼튼해 잘 안 깨짐 → **M•⁺가 크게** 검출.
- 모두 ¹²C·¹H → **명목 질량(nominal mass) 78** = M 피크 (100%)
- **M+1 (m/z 79) ≈ 6.5%**: C 6개 중 1개가 ¹³C **또는** H 6개 중 1개가 ²H
- **M+2 (m/z 80)**: ¹³C 2개 / ²H 2개 / ¹³C 1개 + ²H 1개
- 이론상 최대 M+12 (C 6개 모두 ¹³C, H 6개 모두 ²H) → **M ~ M+12, 총 13개** 가능 (뒤로 갈수록 확률이 극히 낮아 안 보일 뿐)

### 5-3. 바이페닐 C₁₂H₁₀
- 명목 질량 **154**, 이론상 **M+22**까지
- **M+1 ≈ 12.9% (이론 13.08%)** → 벤젠의 약 2배 (C 6→12, H 6→10으로 ¹³C/²H가 들어갈 경우의 수가 약 2배)

### 5-4. 탄화수소 CₙHₘ 의 M+1 공식 ★
> **%(M+1) = n × 1.08 + m × 0.012** (M = 100% 기준; 1.08% = ¹³C 존재비, 0.012% = ²H 존재비)

📝 검산: 벤젠 6×1.08 + 6×0.012 = **6.55** / 바이페닐 12×1.08 + 10×0.012 = **13.08**

### 5-5. 동위원소 기여도 표 활용 [17:16–24:55] — 🗣️ **시험 때 표 제공, M+1·M+2 계산할 수 있어야 함**
- 유기 의약품 주요 원소: C, H, N, O, S, P, 할로젠(F, Cl, Br, I), Si
- **H**: X+2 기여 ≈ 0.00000001 × n(n−1) → 소분자에선 0 → 표에서 생략
- **C**: X+1 = **1.08 × n**, X+2 = **0.0058 × n(n−1)**, X+3 이상은 소분자에서 무시
- **F, I**: 동위원소가 1개(¹⁹F, ¹²⁷I) → **M+1, M+2 기여 0** (M만 만듦)
- **Cl**: ³⁵Cl : ³⁷Cl ≈ **100 : 32.5 (≈ 3 : 1)**
- **Br**: ⁷⁹Br : ⁸¹Br ≈ **100 : 97.3 (≈ 1 : 1)**
- Cl·Br은 질량 차가 2 → **M+1에는 기여 없음, M+2를 결정**

**예: 뷰틸 브로마이드 C₄H₉Br (명목 질량 136)**
- 136 (M) : 138 (M+2) ≈ **1 : 1**
- M+2 = 97.3 × 1 (Br) + 0.0058 × 4 × 3 (C) ≈ 97.37 → C·H 기여는 1도 안 됨 → **Br이 M+2를 결정**
- M+1 (137)도 있지만 4 × 1.08 + 9 × 0.012 ≈ **4.4%** 라 작게 보임

### 5-6. 거대분자: 동위원소 포락선 (isotopic envelope) [24:56–28:40]
- BSA (소 혈청 알부민): 약 **66.5 kDa**, **C₂₉₃₄H₄₅₈₁N₇₈₂O₈₉₇S₃₉**
- C ~3,000개, H ~4,500개 → 소분자에서 0으로 무시하던 M+2, M+3, … M+n 기여가 더 이상 0이 아님.
- **단일동위원소 질량(monoisotopic mass)** 피크 = 가장 가벼운 동위원소(¹²C, ¹H …)로만 된 것 → **맨 왼쪽**.
- 소분자: 보통 M 피크가 가장 큼 / 단백질: ¹³C·²H가 여러 개 들어갈 확률이 커져 **M보다 오른쪽 피크들이 훨씬 큼**.
- 수많은 동위원소 피크가 **종 모양 한 덩어리** → **동위원소 포락선(isotopic envelope)**.

## 6. 정밀 질량과 고분해능 질량분석 (HRMS) [파일2 28:41–31:00]
- 🗣️ monoisotopic mass는 너무 전문 용어라 보통 **정밀 질량(exact mass)** 이라고 부름.
- 🗣️ 화학식이 다른데 **명목 질량은 같고 소수점 이하가 다른** 물질이 많음.
  - **C₅H₈O⁺ 84.0575** vs **C₄H₈N₂⁺ 84.0688** (둘 다 명목 질량 84)
  - 명목 질량 28: **CO / N₂ / C₂H₄** (정밀 질량이 조금씩 다름)
- 🗣️ 저분해능 기기에선 한 피크로 겹치지만 **RP 4,000 이상의 HRMS**로는 분리해서 구분 가능.
- 📝 참고값: CO 27.9949, N₂ 28.0061, C₂H₄ 28.0313. 필요한 RP ≈ m/Δm으로 계산 (예: CO vs N₂ → 28/0.0112 ≈ 2,500).

## 7. 조각화 (fragmentation)와 중성 손실 [파일2 31:01–35:30]

### 7-1. 왜 조각화를 보나
- 🗣️ 화학식이 완전히 같은 **이성질체(isomer)** 는 정밀 질량도 같아서 **HRMS로도 분자 이온만으로는 구분 불가**.
- 🗣️ 일부러 깨뜨려(fragmentation) 생기는 **조각 이온(fragment ion)들의 패턴(피크 크기 비율 등)** 을 비교해 구조를 해석.

### 7-2. 중성 손실 (neutral loss)
- 🗣️ 분자 이온(M•⁺ = **선구 이온 precursor ion / 모이온 parent ion**)이 쪼개질 때 **총전하 보존** → 한쪽이 양전하를 가져가 조각 이온이 되면 다른 쪽은 **중성**.
- 🗣️ 중성 조각은 이온이 아니라 **검출되지 않음 = 중성 손실(neutral loss)**.

**예: 뷰틸 브로마이드 C₄H₉Br (M = 136/138)**
- Br의 비공유 전자 1개가 떨어져 분자 이온이 됨 → C₂–C₃ σ결합이 **균일 분해**(전자 1개씩 나눠 가짐)
- 에틸 라디칼 **CH₃CH₂• (29)** → 중성 손실 (M−29), 검출 안 됨
- Br을 가진 조각 **C₂H₄Br⁺ (•CH₂CH₂Br에서 유래한 양이온)** → **m/z 107 / 109, 1 : 1 쌍**으로 검출
- 🗣️ 107/109 쌍만 봐도 **이 조각에 Br이 있다**는 걸 바로 앎.
- 📝 정정: 받아 적은 원문의 "CH₂=CHBr•⁺"는 질량이 106이라 맞지 않음. 136 − 29 = 107이므로 C₂H₄Br⁺가 맞음.

### 7-3. 아세트아미노펜 (분자량 151) ★ 실험에서 합성한 물질
- 🗣️ CI(또는 ESI 등 소프트 이온화) → **N에 H⁺가 붙은 [M+H]⁺** → 정밀 질량 **152.07 (m/z 152)**
- 🗣️ 벤젠 고리는 잘 안 깨지고 **가장 약한 아마이드 C–N 결합**이 충돌로 끊어짐.
- 🗣️ 아세틸 쪽은 **케텐 (CH₂=C=O, 42)** 중성 기체로 떨어져 나감 → **neutral loss = 42**
- 🗣️ 남은 쪽 **HO–C₆H₄–NH₃⁺ (4-아미노페놀 양이온)** → **m/z 110 (정밀 질량 110.06)** 조각 이온
- 🗣️ **아세트아미노펜 확인 = m/z 152 ([M+H]⁺)와 m/z 110 조각이 나오는지 확인.**

## 📌 시험 포인트 요약
1. 질량분석은 **빛을 안 씀**, **정전기력** 기반 → **기체 상태 + 이온**만 분석, 측정값은 항상 **m/z**
2. 구성: **이온원 → 질량분석관 → 검출기**
3. EI(70 eV, 하드, M•⁺, 조각 많음) vs CI(100–200 eV, 시약 기체 CH₄/isobutane/NH₃, CH₅⁺, [M+H]⁺ 준분자 이온, 소프트)
4. RP = m/Δm (10% valley) = m/FWHM (현재 표준), **클수록 좋음**. Resolution(Δm)은 원래 작을수록 좋지만 현실에선 RP와 같은 뜻으로 씀
5. **%(M+1) = 1.08n + 0.012m**, C의 X+2 = 0.0058 n(n−1), **F·I 기여 0**, **Cl 3:1 · Br 1:1 (M+2)** → **표 주고 계산 문제 나올 가능성 큼**
6. isotopologue / monoisotopic(exact) mass / nominal mass / isotopic envelope 구분
7. 명목 질량이 같은 물질(84: C₅H₈O vs C₄H₈N₂, 28: CO/N₂/C₂H₄) → **HRMS**로 구분, 이성질체 → **조각화 패턴**으로 구분
8. 중성 손실: 뷰틸 브로마이드 −29 → **107/109**, 아세트아미노펜 **152 → 110 (−42, 케텐)**
