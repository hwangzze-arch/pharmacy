# 의약품분석학 노트 제작 파일

Claude가 PDF 노트를 만들 때 쓴 원본이야. 새 채팅에서 "의약품 분석학/_제작파일 써서 ○○ 만들어줘"라고 하면 같은 디자인으로 바로 만들 수 있어.

| `중간고사_마스터요약/` | 의약품분석학II_중간고사_마스터요약_개념문제Lecture2-4_필기반영.pdf | 표지·개념 페이지(💡📖📐✍️🧠)·문제 페이지(왼쪽 문제/풀이칸, 오른쪽 정답·해설) |
| `강의_번역상세설명/` | 의약품분석학II-Lecture5_질량분석법_번역_상세설명.pdf | 슬라이드 1장 = 1쪽, 한글 번역 + 상세 설명 |

## 중간고사_마스터요약 파일 역할
- `build.py` — 디자인(CSS)과 페이지 틀. 개념/문제 페이지 모양을 바꾸려면 여기.
- `c00_front.py` — 표지·시험 정보·족보 체크리스트·수학 페이지
- `c10…c61_*.py` — PART별 내용 (`t="c"` 개념, `t="q"` 문제)
- `c90_final.py` — 혼동 쌍 총정리·숫자 카드
- `annot.py` — 삼성노트 필기 반영(빨간 박스 `REPL`, ★중요 `FLAGS`, 내 필기 `NOTES`, 삭제 `EXCLUDE`)
- `render.js` — 글자가 넘치지 않게 자동 맞춤 후 PDF 출력

## 다시 만들기
```sh
cd "의약품 분석학/_제작파일/중간고사_마스터요약"
sh make_img.sh            # 슬라이드 그림 생성(용량이 커서 저장소에는 안 올림)
python3 build.py          # index.html 생성
NODE_PATH=$(npm root -g) node render.js "$PWD/out.pdf"
```
필요: Python 3, Node + playwright(Chromium), poppler-utils(pdftoppm), ImageMagick, 한글 폰트 Noto Sans KR.

## 모의고사_문제풀이/
물리약학 「중간고사 모의고사 객관식35OX15」·「문제 풀이」와 같은 디자인(A4 가로, 문제지 2단 → 빠른 정답표 → 3문제씩 사고의 흐름 해설).
- `xd.py` — 공용 디자인(CSS)·문제 카드·사고의 흐름(👀단서 🤔질문 💡연결 🧮계산 🔍함정 체크 ✅결론)·자동 페이지 나눔
- `exam.py` — 모의고사(객관식 `MC` 35 · `OX` 15 · 주관식 `SA` 9). 정답 위치 `POS`(①–⑤ 각 7개)
- `book.py` — 문제 풀이: 1쪽 한 장 정리 + 마스터 요약의 모든 문제 40개와 개념 예제(`EX`)를 사고의 흐름으로 변환
- 실행: `python3 exam.py && python3 book.py`, 그다음 `NODE_PATH=$(npm root -g) node render.js "$PWD/exam.html" "$PWD/exam.pdf" "$PWD/paginate.js"` (book도 같은 방식)

## 실제 시험 기록 (새 자료 만들 때 꼭 반영)
### 2026-2 중간고사 (Lecture 2–4 범위) 후기
- 총 39문제: **객관식 33** + **주관식 단답형 4** + **서술형 2**
- 객관식은 **답이 하나인 문제와 여러 개인 문제(다답형)를 섞어서** 냄. 몇 개를 골라야 하는지 헷갈리게 출제
- 결은 `의약품분석학II_중간고사 모의고사 객관식35OX15주관식9.pdf`와 비슷했지만 **더 어렵고 헷갈리게** 냄. 객관식·단답형은 모의고사보다 난이도가 한 단계 높음
- 서술형 2문제
  1. 원자분광 스펙트럼과 분자분광 스펙트럼의 차이점 (선 스펙트럼 vs 띠 스펙트럼: 진동·회전 준위 유무)
  2. 형광광도법에서 형광 세기가 시료 농도에 비례하지 않는 이유 (고농도 내부여과효과·자체흡수, 소광, A>0.05 조건에서 직선성 붕괴 등)
- 기말 대비 모의고사를 만들 때: 다답형 객관식 포함, 함정 선지 강화, 서술형 비중 반영, 난이도는 중간 모의고사보다 높게
