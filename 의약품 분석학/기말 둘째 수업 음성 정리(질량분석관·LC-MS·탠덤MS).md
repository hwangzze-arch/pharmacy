## 1. 질량분석기로 할 수 있는 것 [전반 03:11–07:15]
- 🗣️ **분자량** 측정: 분자 이온(M•⁺)이든 준분자 이온([M+H]⁺)이든 질량을 잴 수 있음
- 🗣️ **화학식 유추**
  - 아주 정확한 질량(정밀 질량)을 재면 컴퓨터 프로그램으로 화학식을 역산 (화학식이 정해지면 질량이 정해지니까)
  - **동위원소 패턴**도 화학식으로 결정되므로 거꾸로 화학식을 유추 가능
- 🗣️ **구조 유추**: 조각화는 무작위가 아니라 화학 반응으로 일어나므로 구조에 특징적인 조각이 생김
- 🗣️ **단백질 서열 분석(protein sequencing)**: 펩타이드를 조각화하면 아미노산 서열에 특징적인 조각이 생김 → 프로그램으로 서열 역산 (이번 수업 범위 밖)
- 🗣️ **대사체학(metabolomics)**, **단백체학(proteomics)**, 정량분석 등
- 🗣️ 시장에서 가장 큰 비중을 차지하는 건 **사중극자(quadrupole) LC-MS 시스템**. 우리 약대에도 질량분석기가 2대 있음.

## 2. 사중극자 질량분석기 (Quadrupole MS) [전반 07:15–38:45]

### 2-1. 구조
- 🗣️ 정식 이름은 Transmission Quadrupole MS. 보통 "transmission"은 빼고 부름. 우리말로 **사중극자**.
- 🗣️ Quadru(4) + pole(극): **서로 평행하게 배치된 쇠막대기 4개**가 전부. 움직이는 부품 없음, 크기도 작음.
  - 마주 보는 한 쌍 = **+ 전극**, 다른 한 쌍 = **− 전극**
- 🗣️ 예시 그림의 앞단은 **EI 이온원**: 필라멘트에서 나온 전자를 가속 → GC 칼럼에서 나온 기체 시료와 충돌 → 이온화
- 🗣️ 이온이 막대 4개 사이의 좁은 틈으로 들어감
  - **특정 m/z 이온만** 작게 진동하며 막대에 부딪히지 않고 통과해 검출기에 도달
  - 그보다 크거나 작은 이온은 궤적이 불안정(진동이 커짐) → 막대에 충돌해 중화·소실
  - 어떤 전압 조건에서 신호가 나왔는지 알기 때문에 그 조건에 해당하는 m/z가 있다는 걸 앎

### 2-2. 핵심: 직류(DC) + 교류(RF)를 동시에 ★
- 🗣️ ① **마주 보는 한 쌍의 전극은 완전히 똑같음** (+끼리, −끼리)
- 🗣️ ② **모든 전극에 DC와 AC를 동시에** 걸어줌 → "DC + AC"
  - DC = Direct Current(직류), AC = Alternating Current(교류)
- 🗣️ 교류는 **RF (radio frequency, 라디오파)** 영역: RF 전압
  - 가정용 교류: **60 Hz** (1초에 60번 극성이 바뀜)
  - 라디오파 범위는 3 kHz – 300 GHz, 사중극자에 쓰는 건 **약 1 MHz (1초에 약 100만 번)**
  - 안의 전기장도 1초에 100만 번 요동침

### 2-3. 분해능: 단위 분해능 (unit resolution) ★
- 🗣️ 구분할 수 있는 최소 질량 차가 **약 0.3 Da** → **고분해능 질량분석기가 아님**
- 🗣️ **1 Da 차이는 확실히 구분** (294 vs 295 ○, 294.3 vs 294.4 ×) → **unit resolution 장비**
- 🗣️ 모든 시료를 고분해능으로 잴 필요는 없어서 매우 쓸모가 많음

### 2-4. 전극 전압의 모양 [18:08–21:57]
| | DC (빨간선) | RF (파란선) | 합쳐진 전압 |
|---|---|---|---|
| **+ 전극** | + 값으로 일정 | 0을 중심으로 ±, 1 MHz | 대부분 +, **잠깐씩 −로 내려감** |
| **− 전극** | − 값으로 일정 (예: −10 V) | 0을 중심으로 ±, 1 MHz | 대부분 −, **잠깐씩 +로 올라감** |

- 🗣️ **전극의 극성을 결정하는 건 DC**. 교류는 +/−를 똑같이 오가서 극성이 없음.
- 🗣️ 일부러 "잠깐 반대 극성"이 되도록 만듦. 이게 없으면 작동하지 않음.
- 🗣️ **DC 전압**(빨간선을 위아래로 이동)과 **RF 전압**(진폭을 키우거나 줄임, 주파수는 고정)을 **각각 자유롭게 바꿀 수 있어야** 작동함.

### 2-5. 안정성 도표 (stability diagram) [22:45–30:30] ★★
- 🗣️ **x축 = RF 전압**, **y축 = DC 전압** (둘을 독립적으로 바꿀 수 있음)
- 🗣️ 이온마다(예: m/z 28, 69, 219) **산봉우리 모양의 영역**이 있음
  - 봉우리 아래 옅은 파란 부분 = **안정 영역 (stable region)**
  - (RF, DC) 조합이 봉우리 안에 있으면 그 이온이 사중극자를 통과함
- 🗣️ 문제: **질량이 다른 이온이 동시에 통과하면 뭐가 검출됐는지 모름** → 한 순간에 **한 종류만** 통과해야 함
- 🗣️ 해결: 실제 기기는 **원점을 지나는 직선(주사선, scan line) 위의 값만** 씀
  - 직선 위에 있으려면 **DC/RF 비율을 일정하게 유지하면서 동시에 바꿔야** 함 → 그 비율 = **기울기(slope)**
- 🗣️ **기울기가 낮으면(실선)**: 219가 통과하는 구간은 길어지지만 인접한 **218 영역과 겹쳐서** 같이 통과 → 구분 불가
- 🗣️ **기울기를 높이면(점선)**: 봉우리 꼭대기 근처만 지나므로 구간이 좁아지고 인접 이온과 겹치지 않음 → **분해능 ↑**
- 🗣️ ★ "**DC와 RF를 동시에 바꾼다, 그 비율을 유지하면서 바꾼다.** 왜 자꾸 이 얘기를 하겠어요? **시험에 내려고** 하는 거지."
- 📝 정리: 기울기 ↑ → 분해능 ↑ (대신 통과 구간이 좁아져 신호(감도)는 줄어듦)

### 2-6. 직관적 이해: 고질량 통과 / 저질량 통과 필터 [30:30–38:45] ★
**양이온을 분석할 때**

| 전극 쌍 | 평소 작용 | 잠깐 바뀔 때 | 결과 | 필터 |
|---|---|---|---|---|
| **+ 전극 쌍만 있다면** | 양쪽에서 **척력** → 가운데로 밀어 통과 | 잠깐 −가 되어 **인력** | 가벼운 이온은 끌려가 충돌, **무거운 이온은 관성으로 통과** | **고질량 통과 필터 (high-mass filter)** |
| **− 전극 쌍만 있다면** | 처음부터 **인력** → 위/아래로 끌림 | 잠깐 +가 되어 밀어냄 | 무거운 이온은 방향을 못 바꿔 충돌, **가벼운 이온만 통과** | **저질량 통과 필터 (low-mass filter)** |

- 🗣️ 비유: 트럭(무거운 이온)에 줄을 던져 당겨도 그냥 지나감, 자전거(가벼운 이온)는 끌려옴
- 🗣️ ⚠️ **"high-mass filter"는 무거운 걸 걸러 없앤다는 뜻이 아님 → 무거운 것만 통과시킨다는 뜻**
- 🗣️ 두 필터의 **컷오프(cut-off)가 살짝 겹치게** DC/RF를 조정하면 겹치는 질량만 통과 (= 띠 통과)
  - 특정 (DC, RF)에서 검출기 신호가 나오면 그 값에 해당하는 m/z가 있다는 뜻
- 🗣️ **음이온을 분석하면 두 전극의 역할이 정반대** → 어느 쪽이 high/low-mass filter인지는 **양이온/음이온 중 무엇을 분석하느냐**에 달림

## 3. 비행시간형 질량분석기 (Time-of-Flight, TOF) [전반 38:45 – 후반 01:19]

### 3-1. 원리
- 🗣️ 고전역학을 그대로 이용: 무거운 이온과 가벼운 이온에 **똑같은 운동에너지(KE)** 를 주고 동시에 출발 → **가벼운 이온이 먼저 도착**
- 🗣️ 도착 시간 = **time of flight** → 질량으로 환산
- 🗣️ 옛날에는 그냥 길게 만들어 "100 m 달리기"를 시킴. 지금은 리플렉트론으로 꺾어서 돌아오게 만듦
- 🗣️ **비행관(flight tube)**: 고진공의 이온 비행 튜브
- 🗣️ 출발선(소스 영역): 0 V 접지 전극과 **약 5,000 V** 전극 → 척력으로 이온을 밀어냄 (양이온 +5,000 V, 음이온 −5,000 V)

### 3-2. 식 유도 ★
> **KE = ½mv² = zeV**  (z: 전하수, e: 기본 전하량, V: 가속 전압)

→ **v = √(2zeV / m)**: 무거울수록 느리고, 전하가 클수록 빠름

→ **m/z = 2eV / v²**, v = L/t 대입:

> **m/z = (2eV / L²) · t² = A · t²**  → **m/z는 비행시간의 제곱에 비례**

- 🗣️ L(비행 거리), e, V는 고정 → 상수 A. **t를 재서 제곱하고 A를 곱하면 m/z**
- 🗣️ 여기서도 **질량이 아니라 m/z를 측정** (질량도 전하도 모르니까)
- 📝 예: 같은 기기에서 m/z가 4배면 비행시간은 2배

### 3-3. 리플렉트론 (reflectron) ★
- 🗣️ **촘촘히 배열된 링 전극(ring electrode)**. 안쪽으로 갈수록 전압을 점점 세게 (양이온: +10 V, +20 V, …; 음이온은 극성만 반대)
- 🗣️ 이온이 들어가면 척력이 점점 커져 **감속 → 멈춤 → 반대로 튕겨 나옴**
- 🗣️ **왜 필요한가: 같은 질량인데 출발 조건이 다름**
  - 같은 질량의 이온들이 **백플레이트(backplate)** 로부터 같은 위치에 들어갈 수 없음
  - 백플레이트 가까이(뒤)에서 출발한 이온 → 전기장을 더 길게 거쳐 **KE가 더 큼, 더 빠름**
  - 앞에서 출발한 이온 → KE가 작고 느림
  - 리플렉트론이 없으면 뒤에서 출발한 빠른 이온이 앞의 이온을 추월 → 같은 질량인데 도착 시간이 달라 **피크가 넓어짐(broad) → 분해능 저하**
- 🗣️ **해결**: 빠른(KE 큰) 이온은 리플렉트론 **깊숙이** 들어갔다 나옴(경로가 김), 느린 이온은 **얕게** 들어갔다 나옴(경로가 짧음)
  → **동시에 검출기에 도착**
- 🗣️ 비유: 빠른 친구는 트랙 바깥쪽, 느린 친구는 안쪽에서 뛰게 함

### 3-4. TOF는 고분해능 ★
- 🗣️ 리플렉트론 등으로 같은 질량이 거의 완벽하게 동시에 도착 → **대표적인 고분해능 질량분석기**
- 🗣️ 구분 가능한 최소 질량 차: **소수점 셋째 자리까지** (사중극자는 1 Da 단위). 측정 질량 범위도 넓음. 우리 약대도 보유.
- 🗣️ 구체적인 RP 숫자는 기술이 바뀌므로 중요하지 않음

| | 사중극자 (Q) | TOF |
|---|---|---|
| 원리 | DC + RF 전기장에서 특정 m/z만 안정 궤적 | 같은 KE → 비행시간 차이, m/z ∝ t² |
| 분해능 | **단위 분해능 (~0.3 Da)**, 고분해능 아님 | **고분해능** (소수점 셋째 자리) |
| 특징 | 가장 많이 쓰임, 시장 1위 | 리플렉트론으로 KE 차이 보정 |

### 3-5. 진공 [후반 01:19–02:07]
- 🗣️ 이온이 빠르게 날아가야 하므로 다른 분자에 부딪히면 경로가 틀어짐 → **모든 질량분석기에 고진공 필수**
- 🗣️ **분해능이 클수록 더 높은 진공**이 필요

## 4. 크로마토그래피-질량분석 연결 (GC-MS, LC-MS) [후반 02:07–08:15]
- 🗣️ 현대 질량분석기는 대부분 **크로마토그래피와 연결**해서 사용: 혼합물을 먼저 분리 → 각 성분을 순서대로 이온화 → 질량 측정
- 🗣️ 어려운 점: 크로마토그래피(고압)와 질량분석기(고진공)의 **압력 조건이 정반대**
- 🗣️ **GC-MS**: 오래전부터 연결됨. 목적 성분이 이미 **기체** → EI로 전자만 때리면 이온화 → 쉬움
- 🗣️ **LC-MS가 문제**: 용액 상태 → **기체 상태 이온**으로 바꿔야 함
  - 용액이 기체가 되면 부피가 엄청나게 늘어남
  - 용액 속 분자를 기체 이온으로 바꾸기가 어려움 → 오랫동안 연결이 안 됨
- 🗣️ 두 기술을 하이픈(-)으로 잇는 것 = **hyphenated technique** (GC-MS, LC-MS)
- 🗣️ LC-MS를 가능하게 한 기술: **API (Atmospheric Pressure Ionization, 대기압 이온화)**
  - 대표 2가지: **ESI** (Electrospray Ionization, 전기분무 이온화), **APCI** (Atmospheric Pressure Chemical Ionization, 대기압 화학 이온화)
- 🗣️ **ESI: 1984년 개발, 2002년 노벨상**. MALDI(1년 뒤 개발)도 함께 노벨상. 지금 거의 모든 질량분석기에 ESI 이온원이 붙어 있음 (약대 2대 모두 ESI)
- 📝 참고: 2002년 노벨화학상은 존 펜(ESI)과 다나카 고이치(soft laser desorption, MALDI 계열)가 공동 수상. 수업에서는 ESI만 다룸.

## 5. ESI와 APCI [후반 08:15–23:16]

### 5-1. ESI (Electrospray Ionization) ★★
- 🗣️ 원리는 가정용 **분무기(spray)** 와 같음. 노벨상을 받은 아이디어는 **"전기장에 분무한다"** 는 것 (electro-)
- 🗣️ **열분무(thermo-spray)**: 뜨거운 상태로 분무해 용매를 증발
  - **건조 기체(drying gas)**: 뜨겁게 데운 불활성 기체 (**N₂**, Ar, 주로 질소)
- 🗣️ 체임버에 **강한 전기장**: 수업 예시는 **−3,500 V → 양이온 분석**. 음이온을 보려면 **+3,500 V**
- 🗣️ **분무관(nebulizer capillary)**: 아주 가는 금속 모세관 끝이 −3,500 V 전기장과 마주함
- 🗣️ ★ **이온화는 용액 상태에서 이미 일어나 있음** → 따로 이온화시킬 필요 없음
  - 의약품은 대부분 중성·약산·약염기라 조금만 이온화돼 있어도 충분
  - **약산 → 음이온 상태 → 음이온 모드**로 분석
  - **약염기 → 양이온 상태 → 양이온 모드**로 분석
- 🗣️ **과정**
  1. 용액은 전체적으로 전하 중성 (양이온 ≈ 음이온)
  2. −3,500 V 전기장 쪽으로 모세관 끝에 **양이온이 선택적으로 끌려 나옴**
  3. 분무된 **액적(droplet, 에어로졸)** 에는 **양이온만** 들어 있음: 매우 불안정하지만 전기장 에너지로 가능
  4. 뜨거운 기체로 **용매 증발 → 액적이 작아짐 → 양이온끼리 거리가 가까워져 반발 증가**
  5. 한계 크기보다 작아지면 **펑 터짐 (쿨롱 폭발, Coulombic explosion)** → **기체 상태 이온** 생성
  6. 압력 차와 전기장으로 질량분석기 안으로 끌려 들어감 (뒤는 Q든 TOF든 상관없음)

### 5-2. APCI (Atmospheric Pressure Chemical Ionization)
- 🗣️ 대기압에서 일어나는 **화학 이온화(CI)**. 원리가 ESI와 완전히 다름
- 🗣️ 마찬가지로 열분무하지만 모세관 끝을 **약 500 °C**로 가열. **전기장에 분무하는 게 아님**
- 🗣️ 분무 끝에 **코로나 니들(corona needle, 약 6,000 V)**: 바늘 모양 전극
- 🗣️ 양이온·음이온·**중성 분자가 모두** 분무됨 → 용매가 증발하면 **기체 상태 중성 분자**로 남음
- 🗣️ 코로나 니들에서 **전자 방출** → N₂, 용매 등과 연쇄 반응 → **기체 상태 강산 (H₃O⁺, 수화된 하이드로늄 이온)** 생성
  → 기체 중성 분자와 반응(양성자 전달) → **기체 상태 이온** (음이온도 가능)

### 5-3. ESI vs APCI ★★
| | ESI | APCI |
|---|---|---|
| 이온이 만들어지는 곳 | **용액 상태 (liquid-phase)** | **기체 상태 (gas-phase)** |
| 이온화 방식 | 용액에 이미 있는 이온을 전기장으로 끌어내 쿨롱 폭발 | 코로나 방전 → H₃O⁺ → 화학 이온화 |
| 핵심 장치 | ±3,500 V 전기장 | 코로나 니들 ~6,000 V, ~500 °C |
| **분석물 휘발성 필요?** | **No** | **Yes** (기체 중성 분자가 돼야 함) |
| 거대분자 (단백질, DNA) | **가능** (용액에서 이온화만 되면 됨) | **불가능** (가열하면 분해) |

- 🗣️ "다 외울 필요는 전혀 없고, **이온화 매질(용액/기체)** 과 **휘발성 필요 여부(No/Yes)** 기본 차이는 잘 알아둬라"
- 🗣️ 단백질은 기화시킬 수 없지만 ESI로는 분석 가능 → 분석 대상이 엄청나게 넓어짐 → 노벨상감

## 6. LC-MS 데이터: TIC, SIM, EIC [후반 23:16–37:30]

### 6-1. 예시: 강물 속 제초제
- 🗣️ 강물에 제초제 6종을 **1 ppb (parts per billion)** 로 **스파이크(spike)** (표준품을 일부러 첨가)
- 🗣️ **LC-UV (240 nm)**: 칼럼에서 나오는 용액의 흡광도를 실시간 측정
  - 피크 1–6이 보이긴 하지만 잡피크가 많고 베이스라인이 출렁여서 정확한 정량이 어려움
- 🗣️ 기기분석의 두 가지 데이터 ★
  - **크로마토그램(chromatogram)**: **x축 = 시간**
  - **스펙트럼(spectrum)**: x축 = 파장 / 화학적 이동 / **m/z**

### 6-2. TIC (Total Ion Chromatogram)
- 🗣️ **스캔(scan)**: 일정 범위(예: m/z 50–500)의 모든 m/z를 매우 빠르게(1초보다 훨씬 짧게) 순차적으로 측정
  - 사중극자라면 DC/RF를 순차적으로 바꾸며 훑음
- 🗣️ 각 시점에서 얻은 질량 스펙트럼의 **모든 신호를 단순히 합쳐** y축으로 나타낸 것 = **TIC**
- 🗣️ LC-UV보다 조금 나아 보이지만 1억 원 더 쓸 가치는 없어 보임 → **여기서 끝이 아니라 시작**
- 🗣️ 데이터는 **3차원** (시간 × m/z × 세기, 엑셀 시트처럼 저장)
  - 시간 축 + 세기 → 크로마토그램
  - m/z 축 + 세기 → 질량 스펙트럼

### 6-3. SIM (Selected Ion Monitoring) ★
- 🗣️ 사중극자의 **DC/RF를 특정 값에 고정** → 그 m/z만 통과 → **원하는 이온만 검출**, 나머지는 아예 안 나타남
- 🗣️ 예: 제초제 6번 = m/z 312 → 312만 입력 → 잡피크가 싹 사라지고 피크 하나만 나옴
- 🗣️ 여러 이온을 순차적으로(각 몇 ms) 모니터링 가능: 6개, 20개, 100개도 가능. 모두 SIM.
- 🗣️ UV 검출기로는 불가능 → 질량분석기의 힘

### 6-4. EIC (Extracted Ion Chromatogram) ★
- 🗣️ 일정 범위를 **전부 스캔해 둔 데이터(TIC)** 에서 **사후에 컴퓨터로 원하는 m/z만 뽑아** 다시 그린 크로마토그램 (예: m/z 202)
- 🗣️ **실험을 새로 하는 게 아님**, 같은 데이터를 다르게 플롯할 뿐

| | SIM | EIC |
|---|---|---|
| 언제 고르나 | **측정 전**: 기기를 그 이온만 보도록 설정 | **측정 후**: 스캔 데이터에서 추출 |
| 측정하는 이온 | 선택한 이온만 | 범위 내 모든 이온 |
| 선택성·감도 | **더 높음** (기기 능력을 한 이온에 집중) | 더 낮음 (능력이 모든 이온에 분산) |

- 🗣️ "**SIM과 EIC를 구분할 줄 알아야 돼요**"

## 7. 탠덤 질량분석 (Tandem MS, MS/MS) [후반 37:30–끝]

### 7-1. 개념
- 🗣️ 질량분석을 한 번 하고, 거기서 **선택한 이온으로 또 한 번** 질량분석 → **MS/MS** 또는 **MSⁿ**
- 🗣️ 탠덤 자전거(2인용)처럼 질량분석기 두 대를 직렬로 연결. 요즘 질량분석기는 대부분 탠덤 (약대 2대 모두 탠덤)
- 🗣️ 질량분석기가 1대인 것 = **single MS**

### 7-2. 삼중 사중극자 (Triple Quadrupole, QQQ) ★
- 🗣️ 사중극자가 3개인데도 MS/MS/MS가 아니라 **MS/MS**라고 부름 → **Q2는 질량 선택을 하지 않기 때문**

| | 역할 |
|---|---|
| **Q1** | 1차 질량 선택 (선구 이온 고르기) |
| **Q2** | **충돌관 (collision cell)**: 불활성 기체(N₂, Ar)를 채워 선택된 이온을 충돌시켜 조각화. 질량 선택 없이 이온 빔을 모아주기만 함. 요즘은 **헥사폴(hexapole, 전극 6개, 60° 간격)** 을 주로 씀 |
| **Q3** | 조각 이온(fragment ion) 분석 및 선택 |

- 🗣️ 이렇게 충돌로 조각나는 것 = **CID (Collision-Induced Dissociation)** = **CAD (Collision-Activated Dissociation)**: **같은 말**
- 🗣️ 약대 장비 구성: LC → ESI 이온원 → Q1 → Q2 → Q3 → 검출기

### 7-3. 작동 모드 경우의 수 ★
- 🗣️ **Q2: 2가지** (충돌 기체 On / Off)
- 🗣️ **Q1, Q3: 각 3가지**
  - **Scan (full scan)**: DC/RF를 훑어 범위 내 모든 이온을 순차 검출
  - **SIM**: 원하는 이온만 통과
  - **RF only**: **DC를 끄고 교류만** 걸면 일정 범위의 모든 이온이 통과
- 🗣️ 3 × 2 × 3 = **이론상 18가지**. 의미 없거나 겹치는 게 있어서 실제로 많이 쓰는 건 **6가지**
- 🗣️ **Q2 Off** → 싱글 MS와 같음: **Full scan, SIM** 2가지
- 🗣️ **Q2 On** → MS/MS 모드 4가지 추가 → 총 6가지

| 모드 | Q1 | Q2 | Q3 | 무엇을 알 수 있나 |
|---|---|---|---|---|
| Full scan | Scan | Off | (RF only) | 범위 내 모든 이온 |
| SIM | SIM | Off | (RF only) | 선택한 이온만 |
| **Product ion scan** 🗣️ | **SIM** | **On** | **Scan** | 선택한 선구 이온에서 **어떤 조각들이 생기는지 전부** |
| **SRM (Selected Reaction Monitoring)** 🗣️ | **SIM** | **On** | **SIM** | 선택한 선구 이온 → **선택한 조각 이온**만 검출 (가장 선택적) |
| Precursor ion scan 📝 | Scan | On | SIM | 특정 조각을 만드는 **선구 이온들** 찾기 |
| Neutral loss scan 📝 | Scan | On | Scan (일정 질량 차를 두고 Q1과 함께) | 특정 **중성 손실**을 보이는 이온 찾기 |

- 🗣️ 수업에서는 **SRM (SIM–On–SIM)** 과 **Product ion scan (SIM–On–Scan)** 까지 설명. SRM 결과 데이터는 **다음 주에 계속**.
- 📝 Full scan/SIM에서 Q1과 Q3 중 어느 쪽이 RF only가 되는지, 그리고 Precursor ion scan·Neutral loss scan은 교재 기준 보충이야. 다음 수업에서 확인하자.

## 📌 시험 포인트 요약
1. 사중극자 = 평행한 막대 4개, 마주 보는 쌍은 같은 전압, **모든 전극에 DC + RF(~1 MHz) 동시**. 극성은 **DC가 결정**.
2. **안정성 도표**: x = RF, y = DC, 이온마다 안정 영역. **DC/RF 비율(기울기)을 일정하게 유지하며 동시에 변화** → 기울기 ↑ = 분해능 ↑ ★"시험에 내려고"
3. 양이온 기준: **+ 전극 쌍 = high-mass filter** (무거운 것 통과), **− 전극 쌍 = low-mass filter** (가벼운 것 통과). 음이온이면 반대.
4. 사중극자 = **단위 분해능 (~0.3 Da), 고분해능 아님** / TOF = **고분해능 (소수점 셋째 자리)**
5. TOF: **½mv² = zeV**, **m/z = (2eV/L²)·t² ∝ t²**
6. **리플렉트론**: 링 전극, 안쪽으로 갈수록 전압 ↑. 같은 질량인데 KE가 큰 이온은 깊이, 작은 이온은 얕게 들어갔다 나와 **동시에 도착** → 분해능 ↑
7. 모든 MS는 **고진공** 필수. 분해능이 클수록 더 높은 진공.
8. GC-MS는 쉬움 (이미 기체 + EI). LC-MS는 **API (ESI, APCI)** 로 가능해짐. **ESI 1984 개발, 2002 노벨상**.
9. **ESI**: 용액에서 이미 이온화, 전기장(±3,500 V)에 열분무 → 액적 축소 → **쿨롱 폭발**. **휘발성 불필요, 단백질 가능**. 약산 → 음이온 모드, 약염기 → 양이온 모드
10. **APCI**: ~500 °C 분무 + **코로나 니들 (~6,000 V)** → H₃O⁺ → 기체상 화학 이온화. **휘발성 필요, 거대분자 불가**
11. 크로마토그램(x = 시간) vs 스펙트럼(x = 파장/δ/m/z). **TIC** = 모든 이온 합, **SIM** = 측정 전 선택 (감도 ↑), **EIC** = 측정 후 추출
12. 탠덤 MS / **QQQ**: Q1 선택 → **Q2 충돌관 (CID = CAD, 헥사폴)** → Q3. 모드 3 × 2 × 3 = **18**, 실제 **6**. **SRM = SIM–On–SIM**, **Product ion scan = SIM–On–Scan**
