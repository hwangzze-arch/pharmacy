## 1. 복습: 분리도와 피크 폭 [파일1 시작–05:25]
- 🗣️ 분리분석의 목표 = 섞인 시료의 성분을 분리. 그래서 **얼마나 잘 분리하는지 나타내는 정량 지표**가 반드시 있음 → **분리도**
- 🗣️ 분리도를 결정하는 두 가지: ① 두 피크가 **얼마나 멀리** 떨어져 있나 ② **피크의 폭**
- 🗣️ ★ “**피크의 폭. 그걸 절대 잊어버리시면 안 돼요.** 그 피크의 폭이 **제일 중요한 파라미터**예요, 분리에.” 피크가 좁아지면(narrow) 모든 게 다 좋아짐
- 🗣️ 피크를 넓히는 주원인 = **확산**. 그런데 **유일한 요인은 아님** → 다른 요인을 이용해 피크를 좁힐 여지가 있음 (= 공부할 이유)
- 🗣️ 확산만 생각하면 피크 폭 ∝ σ ∝ **√t** (칼럼에 머문 시간의 제곱근)

## 2. 이론단 높이 H (plate height) [파일1 05:25–18:30] (슬라이드 30) ★
- 🗣️ 분리 효율을 수치로 나타내는 지표 중 “**가장 중요하다고 할 수 있는 개념**”. 정확한 이름은 **이론단(theoretical plate)의 높이**

### 2-1. 분별 증류에서 빌려 온 개념
- 🗣️ 원래 **화학공학**: 원유 정제(울산·여수의 증류탑) = **분별 증류**
  - 원유를 가열 → 증발 → 끓는점 낮은 성분은 위까지 올라가고, 높은 성분은 아래에서 먼저 응축 → 높이별로 분리 (휘발유, 등유, 나프타…)
  - 탑 안의 가로 판 = **단(plate)**. 단을 촘촘히 설치할수록 더 작은 끓는점 차이를 구분
  - **이론단 높이 = 인접한 두 단의 간격** → **작을수록 좋음** (단 수↑ = 분리 효율↑)
- 🗣️ 칼럼엔 실제 단이 없지만 이 효율 개념을 **그대로 빌려 옴** → 그래서 “이론(theoretical)” 단

### 2-2. 유도
- σ = √(2Dt) (D = **확산계수**), 시간 t = 이동 거리 x / 이동 속도 uₓ
- σ² = 2Dt = (2D/uₓ)·x → 비례상수 **2D/uₓ를 이론단 높이 H로 정의**
- **H = 2D/uₓ = σ²/x**
- 🗣️ 두 물질이 **같은 거리 x**를 이동했는데 피크 폭(σ²)이 다르다면 → 그 차이는 **H 때문**. 피크가 더 넓은 쪽이 H가 더 큼
- 🗣️ H는 확산계수 D가 클수록 커짐 (피크가 더 넓어지니까)

### 2-3. 왜 중요한가
- 🗣️ “왜 중요하냐, 이런 것보다 **이 관계**죠”: **H↓ → 피크가 좁아짐 → 분리도 식의 분모(피크 폭)↓ → 분리도↑ → 크로마토그래피 성공**
- 🗣️ 결국 목표는 **어떤 식으로든 H를 작게** 만드는 것
- 🗣️ ★ **H의 단위 = 길이** (cm, mm, μm…). “**뒤에 단위, 길이가 빠졌다 그러면 잘못된 거예요.**”

## 3. 이론단수 N (number of plates) [파일1 18:30–28:30] (슬라이드 31) ★
- 🗣️ H의 약점: **작을수록 좋다는 게 반직관적**. 분리 효율은 큰 걸 추구하는데 핵심 지표는 작은 걸 추구 → 뒤집어서 **이론단수 N**을 훨씬 많이 씀 (같은 개념, 방향만 반대)
- 🗣️ **N은 단위가 없음** (개수니까)
- 🗣️ **N = L / H** (칼럼 길이 ÷ 이론단 높이). 실제로는 N을 구하는 게 훨씬 쉬워서 계산법이 잘 개발돼 있음

### 3-1. 유도
1. N = L/H, H = σ²/x 대입 → N = Lx/σ²
2. 검출기에서 검출되는 순간 용질은 칼럼을 다 통과 → **x = L** → N = L²/σ²
3. 가우스 곡선에서 **σ = W/4** (🗣️ “뒤에 다시 시험 공부하다 보면 나올 겁니다”) → **N = 16L²/W²**
4. 거리는 재기 거의 불가능, 시간은 쉬움. 분자·분모가 같은 단위라 **길이 → 시간**으로 바꿔도 됨: L → **t_r**, W → 크로마토그램 상의 피크 폭(시간) → **N = 16 t_r²/W²**
5. 측정이 쉬운 **반높이 폭 W½** 사용: W = 1.70 W½ → **N = 5.55 t_r² / W½²**
- 🗣️ “**거의 대부분의 크로마토그래피 전문가들이 N 계산에 쓰는 식**. 이 식을 가지고 여러분들도 **과제를 직접** 해 보셔야 되는데.”
- 🗣️ ★ “**N은 단위가 없게 나와야 돼요**” (분자·분모 모두 시간²)
- 🗣️ H는 거꾸로 **H = L/N** → 반드시 **길이 단위**, 아주 작은 숫자(mm, μm). cm 단위로 나오면 쓸모없는 방법

### 3-2. 관계 정리
- 🗣️ 피크 폭 W ∝ **1/√N** (N에 반비례가 아님!) ∝ **√H**
- 🗣️ 분리도 ∝ 1/피크 폭 → 피크 폭을 줄이려면 N↑ 또는 H↓
- 🗣️ 그것도 모르겠으면 **긴 칼럼**: 칼럼 길이에 **정확히 비례**하는 것 = **N** (학생 답). 칼럼이 길면 단이 많아지니까 당연
- 📝 분리도는 √N ∝ √L에 비례 (길이에 정비례는 아님)

### 3-3. 실제 칼럼 성적서 (RESTEK) [파일1 31:00–35:00]
- 🗣️ 칼럼을 사면 성능 성적서(certificate)를 줌. “잘 분리된다”는 말을 전문가는 싫어함 → **수치화**
- 🗣️ 나온 지표: **머무름시간, k′(용량인자), W½(반높이 폭), 대칭성(symmetry), plates per column = N, plates per meter**
  - 칼럼 길이 **30 mm(3 cm)**에 단이 5,000개 넘음 → 1 m로 환산하면 엄청 큰 수
  - H = L/N → 약 **10⁻³ mm 수준** (📝 5.6 × 10⁻³ mm = 5.6 μm) → 성능이 뛰어나다는 자랑
- 🗣️ ★ 이 값들(N, H, k′)은 **특정 피크**(여기선 마지막 피크)에 대한 값. **피크가 바뀌면 숫자가 다 달라짐** → 어떤 피크인지 특정해야 함
- 🗣️ 분리도는 **두 피크를 골라서** 계산 → 어떤 두 피크인지도 특정해야 함
- 🗣️ 칼럼 하나에 정해진 값이 아니라 **그 실험 조건의 그 피크**에 한정되는 값 → 그래서 조건이 다 적혀 있음. 같은 조건끼리 비교해야 의미

## 4. 비대칭 피크와 비대칭 인자 [파일1 35:00–42:30] (슬라이드 33)
- 🗣️ 모든 피크가 대칭(가우스)은 아님. 비대칭 피크가 매우 자주 나옴 (실습 HPLC에서도 아마 완전 대칭은 아닐 것)
- 🗣️ 측정법: 꼭짓점에서 수직선 → 피크 높이의 **10% 지점**(50% 아님!)에서 양쪽으로 선 → **오른쪽(뒤쪽) 길이 A, 왼쪽(앞쪽) 길이 B**
- 🗣️ **비대칭 인자 (asymmetry factor) = A/B** (“시메트리 팩터가 아니고 **에이시메트리** 팩터”, 1에서 멀수록 비대칭)

| A/B | 피크 모양 | 이름 |
|---|---|---|
| = 1 | 대칭 | symmetric |
| > 1 | 뒤로 꼬리 | **tailing** (더 흔함) |
| < 1 | 앞으로 끌림 | **fronting** |

- 🗣️ 지금까지의 N 식은 **대칭 피크 가정**. 비대칭이면 N ≈ 41.7(t_r/w₀.₁)² / (A/B + 1.25) — 🗣️ “**굳이 이렇게 해서 쓸 필요는 없어요.** 앞서 나온 식으로 대부분 계산”
  - 분모에 A/B → 꼬리 끌수록 **N이 작아짐** (피크가 넓어지니까 당연)
- 🗣️ ★ “크로마토그래피를 하는 사람이 추구하는 피크 모양은 항상 **① 내로우(제일 중요) ② 시메트릭**”
- 🗣️ 완벽히 1은 거의 안 나옴 → 보통 **0.8–1.2 정도면 허용(acceptable)**
- 📝 슬라이드 기준: A_s 1.0–1.05 우수, 1.2 허용, 2 불가, 4 매우 나쁨

## 5. van Deemter 식 [파일1 42:30–58:00] (슬라이드 39) ★★★
- 🗣️ ★ “크로마토그래피를 배웠는데 **반 딤터 방정식을 못 들어봤다, 모른다** 이러면 안 돼요. … 모른다고 얘기하는 순간 **제가 잘못 가르친 게** 됩니다. **그만큼 중요합니다.**”
- 🗣️ ★ (파일2 시작) “**반 딤터 방정식은 진짜 잘 알아야 돼요. 시험에도 나오고** 크로마토그래피에서는 아주 핵심적으로 활용되는 방정식”

> **H = A + B/uₓ + C·uₓ** (A, B, C는 상수, uₓ = 이동상 유속)

- 🗣️ **이론단 높이 H와 이동상 유속 사이의 관계**. 좌변 H를 작게 하려면 우변의 어떤 파라미터를 건드리면 되는지 알려 주는 식. 복잡한 이론 없이 직관적

| 항 | 이름 | uₓ와의 관계 | 그래프 |
|---|---|---|---|
| **A** | **여러 흐름 경로** (multiple flow paths) | 무관 (상수) | 수평선 |
| **B/uₓ** | **세로 확산** (longitudinal diffusion) | 반비례 | 감소 곡선 |
| **C·uₓ** | **평형 시간** (equilibration time) = 물질 전달 | 비례 (기울기 C, y절편 0) | 증가 직선 |

- 🗣️ 세 항을 같은 x에서 더하면 **파란 곡선** (U자 모양)
- 🗣️ 이 곡선으로 알 수 있는 두 가지: ① 그 조건에서 얻을 수 있는 **최소 H**(더 이상은 안 됨) ② **최적 유속** (그림에선 약 30) — 그보다 느려도 빨라도 H↑
- 🗣️ 최적 유속 = **B항과 C항이 같아지는 지점**: B/u = C·u → **u_opt = √(B/C)**
- 🗣️ u_opt를 식에 대입하면 **H_min** (📝 H_min = A + 2√(BC))
- 🗣️ “**아주 쉬운 식인데 굉장히 중요한 식**입니다.”

### 5-1. B항: 세로 확산 (가장 이해하기 쉬움) [파일1 51:30–54:30] (슬라이드 40)
- 🗣️ 유속↑ → B항↓. 왜? (학생 답) 빨리 지나가니까 → **머무름시간↓ → 칼럼에 머무는 시간↓ → 확산↓**. “우리가 알고 있는 그거예요”
- 🗣️ 하지만 무작정 빨리 흘리면 **C항이 커짐** → 여러 가지를 고려해 **최적 조건**을 찾아야

### 5-2. C항: 두 상 사이의 유한한 평형 시간 [파일1 54:30–58:00] (슬라이드 41)
- 🗣️ B항과 **정반대**: 가능하면 **천천히** 흘려야 좋음
- 🗣️ 이동상(위)과 고정상(아래) 사이에서 **분배 평형을 유지하면서** 띠가 이동해야 대칭 피크. 처음엔 물질이 이동상에만 있고, 평형에 도달하는 데 **시간이 걸림**
- 🗣️ 이동상이 너무 빨리 움직이면 → 고정상 쪽 물질은 평형을 이룰 시간이 없어 뒤처지고 이동상은 앞서감 → 띠의 **양 끝이 평형에 도달 못 함** → 전체 폭(맨 왼쪽 끝 ~ 맨 오른쪽 끝)이 넓어짐
- 🗣️ 천천히 흘리면 평형에 충분히 도달 → 이 현상이 안 생김 (대신 너무 느리면 확산으로 넓어짐)

## 6. C항 자세히: 물질 전달 항 [파일2 00:00–10:30] (슬라이드 42–43)
- 🗣️ C항 = **물질 전달 항 (mass transfer term)** — 이동상·고정상 사이 물질 이동. A·B는 이해하기 쉽고 C가 상대적으로 복잡
- 🗣️ H_물질전달 = C·uₓ = (**Cₛ** + **Cₘ**)uₓ — 물질 이동은 **고정상 안(Cₛ)에서도, 이동상 안(Cₘ)에서도** 일어나야 함. **둘 다 작아야** 함
- 🗣️ ★ “**k는 신경 쓰지 마세요.** 오른쪽 떨어져 있는 **두 가지만** 신경 쓰시면 돼요”

| | 식의 핵심 | 작게 하려면 | 이유 |
|---|---|---|---|
| **Cₛ** (고정상) | **d²/Dₛ** | 고정상 두께 **d↓**, 고정상 확산계수 **Dₛ↑** | 평형의 원동력은 확산. 확산이 빠를수록, **이동해야 할 거리가 짧을수록** 빨리 평형 |
| **Cₘ** (이동상) | **r²/Dₘ** | 칼럼 반지름 **r↓**, 이동상 확산계수 **Dₘ↑** | 칼럼이 가늘면 조금만 움직여도 고정상(벽)에 닿음 |

- 🗣️ **d는 얇을수록 좋다 = 반직관적**. 여기선 분배 평형만 생각: 고정상이 얇으면 고정상 속 물질이 조금만 움직여도 이동상으로 나갈 수 있음
- 🗣️ **B항은 D가 클수록 나쁘고, C항은 D가 클수록 좋음** (반대!)
- 🗣️ 실제 칼럼 제조: **칼럼은 가늘게, 고정상은 얇게** 코팅 → 피크가 아주 샤프. “**중요한 원칙**”

### 6-1. 온도 ★
- 🗣️ 분석할 때 D를 키우는 가장 쉬운 방법 = **가열(온도↑)** → Dₛ, Dₘ↑ → H↓ → 피크 샤프. 그래서 거의 모든 크로마토그래피 장비에 **칼럼 온도 조절 장치**
- 🗣️ 또 온도↑ → 용매 **점도↓** → 압력↓ → **유속을 더 올릴 수 있음** → B항↓ (C항은 불리하지만 누가 이길지는 해 봐야)
- 🗣️ 예 (슬라이드 43): 같은 칼럼, 온도만 다름
  - **30 ℃, 1 mL/min**: 약 10분 (1–2번 분리도는 조금 더 좋음)
  - **100 ℃, 5 mL/min**: **1분 안에** 5개 다 분리
  - → 시료 하나 분석 시간 10배 차이. 🗣️ “**그래서 온도도 중요하다는 거.**” 실습 때도 온도 조절 필수

## 7. A항: 여러 흐름 경로 [파일2 10:30–14:30] (슬라이드 44)
- 🗣️ **충전 칼럼**: 고정상 입자(실리카겔처럼)가 완벽히 똑같을 수 없음 → 모양·크기 제각각 → 용질이 입자 사이 틈을 비집고 지나가는 **경로 길이가 다 다름**
  - 3번 위치 물질: 길게 돌아가 늦게 도착 / 1번: 운 좋게 직선 경로로 빨리 도착 → 같은 피크인데 도착 시간이 퍼짐 → 피크 넓어짐
- 🗣️ **확산과 아무 관계 없음** — 확산이 전혀 없어도 생김. 확산 효과는 여기에 **더해짐**
- 🗣️ 해결: **입자를 작게, 균질하게** (완벽히는 불가) → 완벽한 해결 = **고정상 입자를 아예 없애기** = **개관(open tubular) 칼럼 → A = 0**
- 📝 정정: 교수님이 “C항이 아예 제로”라고 하셨지만 여러 흐름 경로는 **A항** → 개관 칼럼에서 **A = 0**

## 8. 개관 칼럼 vs 충전 칼럼 [파일2 14:30–17:40] (슬라이드 45)
- 🗣️ 칼럼은 크게 **개관 / 충전** 두 가지. 개관이 모든 면에서 우수하진 않지만 장점이 많음
- 🗣️ **압력**: 충전 칼럼이 압도적으로 높음 → 유속을 못 올림 → 피크 넓어지고 분석 시간↑ (“집에도 늦게 가고”)
- 🗣️ 개관 칼럼은 유속을 올릴 수 있어 → **B항↓** → H↓, 피크 좁아짐, 분리도↑, **분석 시간↓**
- 🗣️ **여러 흐름 경로 없음** (A = 0) → H↓ → 분리도↑
- 🗣️ 속이 비어 압력이 낮아 **긴 칼럼** 가능 → **N이 길이에 비례해 증가** → 분리도↑

## 9. 기체크로마토그래피 시작 [파일2 17:40–22:30] (Lecture 7 슬라이드 12–13)
- 🗣️ 남은 학기: **GC → LC**. 약대엔 GC가 아예 없고 LC가 압도적으로 많이 쓰이지만, 기본을 이해하려면 GC부터
- 🗣️ 이름은 **이동상**이 결정 → 이동상이 **기체**라서 GC. 고정상은 **액체 또는 고체**
- 🗣️ 분석 자체가 기체 상태 → **분석물도 반드시 기화될 수 있어야** 함 (제한점)
  - 기체 자체 (공기 중 오염물질 등 → GC로 분석하기 딱 좋음) 또는 **기화될 수 있는 액체**
  - 대부분 **용액 상태로 주입** → 기화 장치를 거쳐 기체로 분리
- 🗣️ 장치 3부분: **인젝터**(용액 주입 → 여기서 **기화**) → **칼럼** → **검출기**
  - 이동상 = **운반 기체(carrier gas)**: 기화된 목적 성분을 끌고 칼럼으로
  - ★ 인젝터·칼럼·검출기가 **모두 각자의 오븐 안**에: 잘 기화되지 않는 물질을 열로 억지로 기화시켜 **고온에서 기체 상태를 유지**해야 해서 → 분석 가능한 물질이 늘어남
- 🗣️ GC의 가장 일반적인 형태 = **기체-액체 분배 크로마토그래피 (gas-liquid partition chromatography)**
  - 기체 = 이동상 / 액체 = 고정상 / 분배 = **머무름 기전**

## 10. GC 칼럼 [파일2 22:30–50:00] (슬라이드 14–22)

### 10-1. 개관 칼럼의 구조 ★
- 🗣️ GC 칼럼 = **거의 대부분 개관 칼럼** (충전은 드물게). “**GC 하면 오픈 튜뷸러 칼럼**을 생각해야” — 이유는 앞의 장점들
- 🗣️ 재질: **용융 실리카(fused silica)** 유리관 (석영, 고급 유리) + 바깥은 **폴리이미드** 코팅 (칼럼을 뜨겁게 가열하니까 **몇백 도에서도 버티는 내열 플라스틱**)

| 숫자 | 값 | 왜 (van Deemter) |
|---|---|---|
| **안지름** | **0.1–0.53 mm** (머리카락처럼 가늚) | **C항(Cₘ)↓** — 조금만 움직여도 고정상에 닿아 평형이 빠름 |
| **고정상 막 두께** | **0.1–5 μm** (관 안벽에 화학결합) | 얇을수록 **C항(Cₛ)↓** |
| **길이** | **15–100 m** (약간 신축성이 있어 감아서 사용) | **N↑** (학생 답) — 속이 비어 저항이 작아 길게 쓸 수 있음 |

### 10-2. 개관 칼럼 3종
| 종류 | 구조 | 🗣️ 설명 |
|---|---|---|
| **WCOT** (wall-coated) | 벽에 고정상 직접 코팅 | 지금까지 설명한 기본형 |
| **SCOT** (support-coated) | 벽에 작은 **지지체 입자**를 붙이고 그 겉에 고정상 코팅 | 두껍게 만들면 H↑ → 두께는 얇게 유지하면서 **표면적↑** → 평형이 빨라져 C↓, 고정상 총량↑ |
| **PLOT** (porous-layer) | 벽에 **다공성 입자층** | 입자마다 작은 구멍 → 표면적 극대화. 많은 양을 분리할 때 필요할 수 있음. **잘 쓰지는 않음** |

- 🗣️ PLOT 예: 유리관 안쪽에 **활성탄(다공성 탄소) 가루층** — 활성탄은 다양한 물질을 잘 **흡착**, 미세 구멍으로 스펀지처럼 표면적↑
- 🗣️ **맥주 캔 헤드스페이스** 분석: 캔 위 빈 공간의 기체를 뽑아 그대로 GC → 에탄올(3번)이 가장 많음. 메탄올, 에틸 아세테이트 등 “있으면 안 될 것 같은” 물질도 → 이미 기체인 물질 분석에 GC가 딱
- 📝 수분은 이 검출 조건에선 안 보임 (교수님 언급). 다공성 탄소 PLOT은 **흡착**으로 분리

### 10-3. 왜 개관 칼럼? (슬라이드 16)
- 🗣️ 장점 3: **분리도↑** (100 m, H 작고 N 큼) · **분석 시간↓** (저항이 없어 유속↑) · **감도↑** (적은 양도 검출)
- 🗣️ ★ **단점 1: 시료 용량(sample capacity)↓** = 한 번에 분석할 수 있는 양이 적음
  - 왜? (학생 답: 관이 얇아서) → 결국 분리는 고정상에서 일어나는데 **고정상 막이 0.몇 μm로 아주 얇아** 칼럼이 길어도 **고정상 총량이 매우 적음**
  - 큰 단점은 아닐 수 있음 → 시료를 **희석**하면 되니까

### 10-4. 칼럼 변수 바꾸기 ★ (🗣️ “**어떤 변화가 일어났을 때 방향성은 여러분이 알 수가 있어야**”)
- 🗣️ **안지름↓ → 분리도↑** — 공부 안 했으면 대부분 “클수록 좋다”고 할 것 (반직관적). 그림: 0.32 mm → 0.25 mm에서 3·4번, 1·2번이 조금 더 벌어짐
  - 이유 (교수님이 AI로 만든 그림): 직경이 크면 이동상 속 물질이 고정상까지 가야 할 **평균 거리**가 늘어 평형에 오래 걸림. 직경이 작으면 조금만 움직여도 고정상에 닿음
  - 단점: **압력↑** (유속을 충분히 못 올림), **시료 용량↓** (고정상 양↓)
- 🗣️ **길이↑ → N↑ → 분리도↑** (분리도 ∝ √N). 15 → 30 → 60 m에서 점점 분리
- 🗣️ **고정상 두께** — 그림이 “기대한 거랑 **반대**”: 0.25 μm보다 **1.0 μm**에서 분리가 더 좋음
  - 우리가 잘못 안 게 아니라 **다른 효과가 지배**: 7개 물질 모두 **머무름시간이 매우 짧음** = 고정상에 잘 안 머무는 물질들 → 고정상이 너무 얇아(양이 너무 적어) **제대로 머물지 못하고** 분리되는 둥 마는 둥 다 흘러나옴
  - 해결 = **고정상을 늘려 더 오래 머물게** → 머무름시간 증가 → 분리. “**레졸루션의 문제가 아니에요. 머무르게 만들어야 분리가 돼요.**”
  - 정리: 용질이 **충분히 머물 때**는 얇을수록 좋다(C항)가 맞지만, 고정상 양이 너무 적으면 반대 효과
  - 📝 슬라이드 정리: 두께↑ → 머무름시간·시료 용량↑, 일찍 나오는 피크(k′ ≤ 5) 분리도↑, 실리카 표면을 가려 꼬리 끌기↓

| 변수 | 분리도 | 압력 | 시료 용량 |
|---|---|---|---|
| 안지름↓ | ↑ | ↑ | ↓ |
| 길이↑ | ↑ (√L) | ↑ | — |
| 막 두께↑ | ↑ (잘 안 머무는 물질, k′ ≤ 5) | — | ↑ |

### 10-5. 고정상 선택: Like dissolves like [파일2 41:00–47:00] (슬라이드 20–21)
- 🗣️ GC로 분리할 물질이 워낙 다양 → 다양한 고정상 칼럼. 대원칙 = **라이크 디졸브즈 라이크** (기름은 기름에, 물은 물에)
  - 지용성 물질 → **지용성 고정상** → 고정상에 녹아 들어가 오래 머묾 → 분리 (“**머무는 게 우선**”)
  - 🗣️ GC뿐 아니라 **LC에도 똑같이** 적용되는 원리
- 🗣️ 가장 흔한 고정상 = **실리콘 오일 = 폴리실록세인** (–Si–O–Si–O– 폴리머, 실리콘 바를 때 그것). **R기**가 성질을 결정
  - **메틸 / 페닐** 비율을 조절해 극성 조절
  - 더 극성(수용성) → **사이아노프로필**기
  - 그래도 부족하면 폴리실록세인 대신 **폴리에틸렌 글라이콜(PEG)** — 에틸렌 글라이콜 자체가 매우 수용성
- 🗣️ 용질 극성 분류 표 (비극성 / 약한 중간 / 강한 중간 / 강한 극성): “**외울 필요는 전혀 없고**” 분석할 물질의 관능기로 카테고리를 확인 → 극성이 맞는 칼럼 선택 → 시행착오↓

### 10-6. 충전 칼럼 (GC) [파일2 47:00–50:00] (슬라이드 22)
- 🗣️ GC에선 **아주 특별한 경우만**. 칼럼 안이 꽉 차 있어 **길게 못 씀** (보통 1 m 미만, 몇십 cm) → **N이 상대적으로 작음**
- 🗣️ 확실한 장점: 칼럼 전체가 고정상 → 고정상 양이 상상을 초월할 정도로 많음 → **시료 용량이 압도적**. 많은 양을 분석하고 싶으면 충전
- 🗣️ 단점: 분리도↓, N↓, H↑
- 🗣️ ★ **GC = 개관 칼럼, LC = 충전 칼럼** (LC는 개관 칼럼을 쓸 수 없음 → 전부 충전. LC 때 다시)
- 🗣️ 전형적 크로마토그램: 오른쪽(늦게)으로 갈수록 피크가 넓어짐 → **확산** (칼럼에 머문 시간이 기니까). 이걸 조금이라도 좁히려는 게 van Deemter 공부

## 11. 머무름 지수 (Kovats) 도입 [파일2 50:00–끝] (슬라이드 23)
- 🗣️ GC에서 주로 쓰는 또 하나의 정량 지표 = **머무름 지수 (retention index, I 또는 RI)**. 머무름시간으로 계산
- 🗣️ 기준 = **노말 알케인** (메테인 C1, 에테인 C2 … 노네인 C9). 내 물질의 머무름시간을 노말 알케인의 머무름으로 **정규화(normalize)** 한 것
- 🗣️ 노말 알케인의 머무름시간은 조건(칼럼 길이, 두께…)마다 달라짐 → 아예 노말 알케인의 **머무름 지수를 고정**: **I = 탄소 수 × 100** — 실험 조건과 **아무 상관 없이 항상 일정**
  - 헥세인 = **600**, 옥테인 = **800**
- 🗣️ 내 물질이 헥세인과 헵테인 사이에 나오면 → I는 **600–700 사이**. 정확한 값은 환산 식으로 (단순 중간값 아님)
- 🗣️ 예: 1 헥세인, 3 헵테인, 2* 미지 물질, t_m = 2분 → 계산하면 **I = 644**
- 🗣️ “**다음 주에 나머지 마무리**”
- 📝 공식 (슬라이드): I = 100 × [n + (N − n)·(log t′_r(미지) − log t′_r(n)) / (log t′_r(N) − log t′_r(n))] — **t′_r(= t_r − t_m)** 의 **log**를 씀. 검산: t′_r = 4.50, 6.25, 9.50 → (0.796 − 0.653)/(0.978 − 0.653) = 0.44 → I = 644 ✓

## 📌 시험 포인트 요약
1. 분리도의 두 요소 = 피크 간 거리 + **피크 폭**. ★“피크 폭이 제일 중요한 파라미터”
2. **H (이론단 높이)** = 분별 증류의 단 간격에서 빌린 개념. **H = 2D/uₓ = σ²/x**, **작을수록 좋음**, ★**단위 = 길이** (없으면 틀린 답)
3. **N = L/H = L²/σ² = 16t_r²/W² = 5.55 t_r²/W½²**, ★**단위 없음**, 클수록 좋음, **칼럼 길이에 비례**. 과제로 직접 계산!
4. 피크 폭 ∝ **1/√N ∝ √H**, 분리도 ∝ √N ∝ √L
5. N, H, k′는 **특정 피크**, 분리도는 **특정 두 피크**에 대한 값 (성적서 RESTEK: 30 mm, plates/column, plates/meter, H ≈ 5.6 μm)
6. **비대칭 인자 = A/B** (10% 높이, A = 뒤쪽): 1 대칭 / >1 **tailing** / <1 **fronting**. 허용 약 0.8–1.2. 비대칭이면 N↓. 추구하는 피크 = ① 내로우 ② 시메트릭
7. ★★★ **van Deemter: H = A + B/uₓ + C·uₓ** (“모르면 제가 잘못 가르친 것”, “시험에도 나오고”)
   - A = 여러 흐름 경로 (유속 무관, 입자 작고 균일하게, **개관 칼럼 A = 0**, 확산과 무관)
   - B/uₓ = 세로 확산 (빨리 흘리면 머무는 시간↓ → ↓)
   - C·uₓ = 평형 시간·물질 전달 (빨리 흘리면 평형 못 따라가 ↑)
   - **u_opt = √(B/C)** (B항 = C항 지점), H_min = A + 2√(BC)
8. **Cₛ ∝ d²/Dₛ, Cₘ ∝ r²/Dₘ** (★k는 신경 쓰지 말 것) → **고정상 얇게, 칼럼 가늘게, 온도↑(D↑, 점도↓ → 유속↑)**. B항은 D↑가 나쁘고 C항은 D↑가 좋음
9. 온도 예: 30 ℃·1 mL/min 약 10분 vs 100 ℃·5 mL/min 1분 이내. ★“온도도 중요”
10. 개관 칼럼 장점: 압력↓ → 유속↑(B↓, 시간↓), A = 0, 길게 → N↑ → 분리도↑. 단점: **시료 용량↓** (고정상 양이 적음)
11. **GC**: 이동상 기체(운반 기체), 고정상 액체/고체, **분석물은 기화 가능해야**. 인젝터(기화)·칼럼·검출기 **각자 오븐**. 대표 = **기체-액체 분배** 크로마토그래피
12. GC 칼럼 = **개관**(용융 실리카 + 폴리이미드). ★숫자: **안지름 0.1–0.53 mm · 막 0.1–5 μm · 길이 15–100 m**. WCOT / SCOT(지지체로 표면적↑) / PLOT(다공성, 활성탄, 흡착)
13. 변수 방향성: 안지름↓ → 분리도↑·압력↑·용량↓ / 길이↑ → N↑ / 막 두께는 **잘 안 머무는 물질이면 두꺼워야** 분리됨 (머무는 게 우선)
14. 고정상 선택 = **Like dissolves like** (GC·LC 공통). 폴리실록세인(메틸/페닐 비율) → 사이아노프로필 → **PEG**(가장 극성)
15. GC 충전 칼럼: 짧음(1 m 미만), N↓, **시료 용량↑**. ★**GC = 개관, LC = 충전**
16. **Kovats 머무름 지수**: 노말 알케인 I = 탄소 수 × 100 (조건 무관 고정), 헥세인 600 · 옥테인 800, log t′_r로 보간 → 예제 **644**
