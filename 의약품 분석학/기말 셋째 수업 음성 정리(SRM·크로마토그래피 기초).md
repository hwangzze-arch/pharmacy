## 1. SRM / MRM — 탠덤 MS의 대표 정량법 [00:03:01–00:18:08]

### 1-1. 탠덤 MS 복습
- 🗣️ 지금 질량분석기는 거의 다 탠덤으로 바뀜 (비싸지만 장점이 압도적). 약대 2대도 모두 탠덤
- 🗣️ 질량분석관을 연달아 배치해 질량분석을 순차적으로 함 → **얻을 수 있는 질량 스펙트럼의 종류가 다양해짐** → 정성·정량 정보가 늘어남

### 1-2. SRM = MRM ★
- 🗣️ **Selected Reaction Monitoring (SRM) = Multiple Reaction Monitoring (MRM)**: 같은 말. 실험실에선 다들 **MRM**이라고 부름
- 🗣️ **현존하는 가장 민감한(sensitive) 정량분석법 중 하나** (분광분석 포함)
- 🗣️ 주로 **삼중 사중극자(QQQ)** 로 얻는 스펙트럼의 한 종류

| 단계 | 하는 일 |
|---|---|
| **Q1** | 분석할 물질(예: 아세트아미노펜)의 질량만 통과하도록 DC/RF를 고정 → **선구 이온(precursor ion, = parent ion)** 선택 (**1차 선택**) |
| **q2** (소문자로 쓰기도 함) | **충돌관(collision cell)**: 질량 선택 안 함, 이온 빔을 모아줌. N₂·Ar을 넣어 **조각화** → 무작위가 아니라 **정해진 조각**만 생김 |
| **Q3** | 원하는 **조각 이온(product/fragment ion)** 만 선택해 검출 (**2차 선택**) |

- 🗣️ ★ "**이 '선택'이란 단어가 중요해요.**" → **선택을 두 번** (Q1에서 한 번, Q3에서 또 한 번) → 선택성이 크게 좋아짐
- 🗣️ 싱글 MS(SIM)와의 차이: **Q1까지는 똑같음**. 싱글 MS는 Q1에서 끝나고 바로 검출. 탠덤은 q2 + Q3에서 **한 번 더 고름**
- 🗣️ 분석할 물질을 **이미 알고 있을 때** 쓰는 방법 (의약품 분석에선 흔한 경우)

### 1-3. SIM vs MRM: 왜 MRM이 훨씬 깨끗한가 ★★
- 🗣️ 크로마토그램 비교 (x축 시간, y축 세기)
  - **SIM (싱글 MS, 분홍)**: 원하는 질량만 골랐는데도 **방해 이온(interference ion)** 피크가 잔뜩 → 같은 질량의 물질이 시료에 많고, MS가 워낙 민감해서 조금만 있어도 다 검출
  - **MRM (탠덤, 파랑)**: 같은 시료인데 방해 피크가 싹 사라지고 **원하는 피크 하나만**
- 🗣️ 이유 (학생 답: "q2랑 Q3"): 방해 이온은 **질량만 같고 화학 구조가 다름** → 깨도 같은 조각이 안 나옴. "질량도 같고 깼을 때 같은 조각이 나올 확률은 **거의 0**"
- 🗣️ ★ **신호 대 잡음비(S/N)**: 클수록 좋음. MRM의 S/N이 압도적으로 큼
  - "**시그널 자체는 커진 게 아니라요, 노이즈가 사라진 거예요.**" 신호가 그대로여도 잡음이 거의 0이 되면 S/N은 커짐
  - "**중요한 거는 시그널 투 노이즈 레이쇼거든요.**"
- 🗣️ 예: SIM으로 m/z 154만 통과 → 피크 2개 (하나는 목표, 하나는 질량만 같은 다른 물질) / 탠덤으로 154 → **Q3에서 152 또는 102** 통과 → 뒤 피크와 앞의 작은 피크들까지 사라지고 피크 하나만 남음 (구조가 달라 조각화 패턴이 다르니까)

> 📝 **족보 직결**: 2025-2 기말 주관식 "**SIM보다 SRM의 signal-to-noise가 큰 이유?**"
> 모범 답안: SIM은 Q1에서 **질량(m/z) 하나로만** 선택하므로 같은 m/z를 갖는 방해 물질도 함께 검출돼 바탕 잡음이 크다. SRM은 Q1에서 선구 이온을 선택한 뒤 q2에서 조각화하고 Q3에서 **특정 조각 이온을 한 번 더 선택**하므로, 질량은 같지만 구조가 다른 방해 물질은 같은 조각을 만들지 못해 걸러진다. 그 결과 **신호는 그대로지만 잡음이 거의 사라져** S/N이 크게 증가한다.

### 1-4. 실제 예: 17α-에티닐에스트라다이올 (EE2)
- 🗣️ **경구 피임제** 성분. 복용 → 소변 배설 → 강물에 **극미량**으로 존재 (사람이 만든 오염) → 환경 연구에서 분석하려면 엄청 민감한 방법이 필요 → **MRM**
- 🗣️ **생성 이온 스펙트럼 (product ion spectrum)** (아직 MRM 아님)
  - EE2의 **[M−H]⁻ = m/z 295** → **음이온 모드**. 이게 선구 이온
  - Q1에서 295 통과 → 조각화 → 여러 작은 조각 피크
- 🗣️ MRM: 그중 **가장 큰 피크 2개, m/z 145와 159**만 번갈아 검출 (슬라이드: m/z 295 → 159 + 145)
  - "295를 깨서 159와 145를 만드는 물질은 자연에서 거의 이 물질밖에 없다"
- 🗣️ 결과 크로마토그램은 S/N이 좋아 보이지 않지만, **농도가 3.6 ppt (3.6 ng/L)** 라서 그런 것. 이렇게 낮은 농도도 검출 가능하다는 극단적인 예
- 📝 정정: ppm = 10⁻⁶, ppb = 10⁻⁹, **ppt = 10⁻¹²**. 교수님이 "ppt는 10의 9승분의 1"이라고 말씀하셨지만, 슬라이드 표기는 **3.6 ng/L (ppt)** 이고 물 1 L = 1 kg = 10¹² ng이니까 **ppt = 10¹²분의 1**이 맞아.
- 📝 검산: EE2 = C₂₀H₂₄O₂, 분자량 약 296 → [M−H]⁻ = 295 ✓ (페놀성 –OH가 H⁺를 잃어 음이온 모드에서 잘 이온화)

### 1-5. Q-TOF와 다른 탠덤 장비
- 🗣️ 약대 보유 **Q-TOF**: HPLC → **ESI** → Q1 → q2 → **TOF** (Q3 자리에 TOF)
- 🗣️ QQQ의 Q3(사중극자)은 **고분해능이 아님 (~1 Da)**. TOF는 **고분해능** → **조각 이온의 정확한 질량** 측정 → 선택성이 더 높아짐
- 🗣️ Q1·q2는 같고 뒤에 뭘 붙이느냐에 따라 이름이 바뀜

| Q3 자리 | 장비 이름 |
|---|---|
| 사중극자 | **Triple quadrupole (QQQ)** |
| TOF | **Q-TOF** |
| Orbitrap (매우 고분해능, 비쌈) | Q-Orbitrap |
| Linear ion trap | (Q-LIT 등) |

- 🗣️ ★ "적어도 **탠덤 질량분석기가 뭔지**, 그리고 **그걸 왜 하는지**에 대한 기본적인 이유는 알아야 된다"

## 3. 용매 추출과 분배계수 [00:22:15–00:26:59] (슬라이드 10)
- 🗣️ 용매 추출이 나오는 이유: **크로마토그래피의 기본 원리가 용매 추출과 똑같음**
- 🗣️ 아세트아미노펜 합성 실험의 **분액깔때기(separatory funnel)** 가 바로 용매 추출. 물층 + **에틸 아세테이트**층 (섞이지 않는 두 상, 에틸 아세테이트가 위에 뜸)
- 🗣️ 섞이지 않는 두 상 사이에서 물질이 **평형을 이루며 이동(transfer)** 하는 현상 = 화학 평형의 일종
- 🗣️ 두 상이 모두 액체 → **액-액 추출 (LLE)**. 액체–기체 사이도 가능
- 🗣️ 평형 상수 = **분배계수 K (partition coefficient)** = 두 상의 농도 비
  - 엄밀히는 **활동도** 비지만, 활동도 계수 = 1로 가정하고 농도(몰) 비로 계산
- 🗣️ K가 클수록 추출이 잘 됨 (한두 번에 끝). **K가 작으면 추출을 여러 번 반복**해야 함
- 🗣️ ★ "어려운 거 전혀 없지만 **이걸 기억해 두세요. 크로마토그래피의 가장 기본적인 원리가 이거하고 똑같아요.**"

## 4. 크로마토그래피의 정의 [00:26:59–00:33:46] (슬라이드 11)
- 🗣️ 어원: chromatos(색) + graphein(쓰다). 옛날엔 **눈이 검출기**(가시광선만)라 색 있는 물질만 분리할 수 있어서 붙은 이름
- 🗣️ ★ **정의**: 섞이지 않는 두 상 사이 물질 이동에 기반한 분리법인데, **한 상은 반드시 고정(고정상, stationary phase), 다른 상은 이동(이동상, mobile phase)**
  - 용매 추출은 두 상이 **모두 움직임** (고정상 없음)
  - "**고정상이 있고 이동상이 있으면 크로마토그래피**, 없으면 크로마토그래피라고 부를 수 없다"
- 🗣️ 학생 실험의 **칼럼 크로마토그래피**: 고정상 = **실리카겔**, 이동상 = **에틸 아세테이트 + 헥세인** (극성 조절) → **순상** 크로마토그래피
- 🗣️ **칼럼 두 종류**
  - **충전 칼럼 (packed column)**: 고정상을 채워 넣음 (학생들이 쓴 것)
  - **개관 칼럼 (open tubular column)**: 속이 뻥 뚫림 → 고정상은 **튜브 안쪽 벽(내벽)** 에 붙어 있음
- 🗣️ 용어: **eluent (용리액)** = 들어가는 이동상 / **eluate (용출액)** = 분석물이 녹아 나오는 액 / 전체 과정 = **elution (용리)**

## 5. 크로마토그래피의 분류 [00:33:46–00:44:33] (슬라이드 12)
- 🗣️ "표 다 외우라고 전혀 요구하지는 않지만 **핵심적인 거는 알아야** 돼요"
- 🗣️ 분류 기준 4가지: ① **이동상** ② 이동상을 흘리는 **힘** ③ **고정상** 종류 ④ **머무름 기전**

### 5-1. 이동상 ★ (이름을 결정하는 가장 중요한 기준)
- 🗣️ 고체는 이동상 불가 → **기체 → GC**, **액체 → LC**
- 🗣️ 초임계 유체(액체와 기체 중간, 대표 CO₂) → SFC. "**이건 몰라도 돼요.** 기체하고 액체는 **확실히 구분**할 줄 알아야"
- 🗣️ 학생 칼럼 크로마토그래피 = **액체 크로마토그래피**

### 5-2. 이동상을 흘리는 힘
| 힘 | 예 |
|---|---|
| 압력 (펌프) | HPLC, GC |
| **중력** | 학생들의 **칼럼 크로마토그래피** |
| **모세관 작용** | **TLC** (고정상 실리카, 이동상은 챔버에 부은 용매) |
| 전기삼투 | MEKC 등 |

### 5-3. 고정상
- 🗣️ 기체는 고정상 불가 → **고체, 액체** (액체도 어딘가에 붙여 안 움직이게 하면 고정상 가능)
- 🗣️ **결합상 (bonded phase)**: 실리카겔 표면에 어떤 물질을 **화학적으로 붙인** 것 → **전 세계에서 가장 많이 쓰는 고정상**. 매우 비쌈 → 소규모·고효율 분리용
- 🗣️ 학생들은 결합상이 아니라 **실리카겔 그대로 (고체)** 사용 (대량 합성용으로 결합상은 너무 비쌈)
- 🗣️ ★ 이름 규칙: "**기체-고체** 크로마토그래피"면 **앞 = 이동상, 뒤 = 고정상**. "**헷갈리면 안 됩니다.**" 실제론 그냥 GC, LC라고만 부르는 경우가 대부분

### 5-4. 머무름 기전
- 🗣️ 용질이 **고정상에 머무르는 메커니즘**. 머물러야 크로마토그래피가 시작됨. "메커니즘을 이해하고 효율성을 따질 때 **가장 중요한 부분**"
- 🗣️ 흡착, **분배**(추출의 그 분배, 가장 대표적), 이온교환, 크기배제, 친화, 겔투과/겔여과
- 🗣️ Q: 학생들의 실리카겔 칼럼에서 아세트아미노펜의 머무름 기전? → **흡착** (가장 고전적)
- 🗣️ ★ 앞으로 집중할 두 가지
  - **GC**의 대부분 = **기체-액체 크로마토그래피 (GLC)** (이동상 기체, 고정상 액체)
  - **LC**의 대부분 = **결합상 크로마토그래피 (BPC)**

## 6. 머무름 기전 5가지 [00:44:33–00:55:28] (슬라이드 13–17)

### 6-1. 흡착 크로마토그래피
- 🗣️ 실리카겔은 확대하면 **구멍이 숭숭 뚫린 스펀지** → **표면적을 넓히려고** (흡착 표면 최대화)
- 🗣️ 흡착을 잘(강하게) 할수록 → 오래 머묾 → **나중에 용리**
- 🗣️ 가장 오래된 방식. 고정상은 **반드시 고체**(흡착 표면), 이동상은 **액체·기체 모두 가능**

### 6-2. 분배 크로마토그래피
- 🗣️ 요즘 더 많이 씀. 예: **개관 칼럼 단면** — 바깥 튜브(실리카 등), 안쪽 벽의 얇은 층 = **고정상**
- 🗣️ 튜브 표면(실리카)에 유기 물질을 **공유결합**으로 붙임 → 표면이 **용매 층처럼** 작용 → 용질이 두 상 사이에서 **분배 평형** = 추출과 같음
- 🗣️ 학생 답: 고정상에 더 잘 녹으면 → **더 오래 머묾** (고정상 쪽 분배계수 ↑ → 머무름시간 ↑)
- 🗣️ 고정상은 **액체**(성질), 이동상은 **기체·액체 모두**. 주로 GC에 많이 씀

### 6-3. 이온교환 크로마토그래피 ★★
- 🗣️ **정전기 인력**(반대 전하 사이 상호작용)을 머무름 기전으로 이용
- 🗣️ 고정상 = **플라스틱 수지(resin)**, 표면에 양전하/음전하 물질을 마음대로 붙일 수 있음
- 🗣️ 예: 수지 표면이 **양전하** → **음전하 용질**이 선택적으로 붙어 오래 머묾 → 이건 **음이온교환 수지 (anion-exchange resin)**
- 🗣️ ★ "**음이온교환 수지의 표면은 양전하, 양이온교환 수지의 표면은 음전하. 요거 시험 잘 나와요, 헷갈리니까.**"

| 수지 | 수지 표면 | 붙잡는 용질 |
|---|---|---|
| **양이온교환** (cation-exchange) | **음전하** (–SO₃⁻) | 양이온 |
| **음이온교환** (anion-exchange) | **양전하** (–N(CH₃)₃⁺) | 음이온 |

- 📝 외우는 법: 수지 이름 = **붙잡는(교환하는) 이온**의 이름. 표면 전하는 그 **반대**. (교수님도 수업 중 이름을 거꾸로 말씀하셨다가 바로 정정하셨을 만큼 헷갈리는 부분)

### 6-4. 크기배제 크로마토그래피 (분자배제, 겔여과, 겔투과)
- 🗣️ 이름이 여러 개지만 같은 기전. **크기에 따라** 머무름시간이 달라짐
- 🗣️ 고정상에 아주 작은 구멍이 많음
- 🗣️ 예: 배양액에서 **단백질 분리정제** → 전해질(작은 물질)을 없애고 싶음
  - 단백질은 구멍에 **못 들어감** → 빨리 나옴
  - 작은 물질은 구멍에 들어갔다 나왔다 → **더 오래 머묾** (학생 답: "작은 거")
  - 먼저 나오는 분획을 받으면 순수한 단백질
- 🗣️ 고정상 **고체**, 이동상 **액체만** (**GC에는 못 씀**)

### 6-5. 친화 크로마토그래피
- 🗣️ **아주 선택적인 상호작용** 기반. 고정상 표면에 분리하려는 물질과 선택적으로 결합하는 물질을 붙임

| 분리하려는 것 | 고정상에 붙이는 것 |
|---|---|
| 특정 **항체** | 그 **항원** |
| 특정 **효소** | **기질** (학생 답) |
| **수용체** | **리간드** |

- 🗣️ 그 물질만 오래 머물고 나머지는 다 흘러 내려감 → **현존하는 머무름 기전 중 가장 선택적**

## 7. 배관공의 시각: 유속, 크로마토그램, 머무름 파라미터 [00:55:28–01:20:34] (슬라이드 18–21)

### 7-1. 유속 [00:55:28–00:58:38]
- 🗣️ "이건 내가 쓴 말이 아니고 **책에 나오는 말**" — 칼럼을 흐르는 이동상을 다루니까 배관공처럼 생각해야 함
- 🗣️ ★ "**유속**, 실제로 아주 중요한 파라미터" (실험에서도 플로우 레이트가 중요한 파라미터)
- 🗣️ **부피유속 (volume flow rate) u_v**: 단위 시간당 흘러간 이동상 부피 (mL/min). **대부분 이걸 씀**
- 🗣️ **길이유속 (linear flow rate) u_x**: 단위 시간당 이동 거리 (cm/min). 덜 자주 씀
- 🗣️ 둘은 호환됨: **칼럼 내경만 알면** 부피유속 → 길이유속 변환 가능 (📝 개관 칼럼: u_x = u_v / πr²)

### 7-2. 크로마토그램과 t_r, t_m, t′_r [00:58:38–01:07:19] ★
- 🗣️ 크로마토그래피에서 가장 중요한 데이터 = **크로마토그램** (x축 시간, y축 검출기 신호)
- 🗣️ 예 (GC): **메테인 → 옥테인 → 미지 물질 → 노네인**
  - 시간 0 = **주입 시간 (injection time)** (칼럼 실험에선 로딩 후 콕을 연 순간)
  - 가장 오래 머문 것 = **노네인** (학생 답) → 분배 크로마토그래피니까 **고정상에 대한 분배계수가 가장 큰 물질**
- 🗣️ **머무름시간 t_r (retention time)**: 용질이 주입구 → 검출기까지 가는 데 걸린 시간. "아주 중요한 파라미터"
- 🗣️ **t_m (dead time / void time)**: m = mobile phase
  - 메테인은 이 조건에서 고정상과 **전혀 상호작용 안 함** → 가장 빨리 나옴
  - 의미: **이동상 자체가 주입구 → 검출기까지 흘러가는 시간** = **용질이 이동상에 머문 시간**
  - 직접 재기 어려우니 **상호작용 안 하는 물질(메테인)을 일부러 넣어** 그 t_r로 측정
- 🗣️ ★ 모든 용질은 **이동상에 머문 시간이 똑같이 t_m**. t_r이 다른 이유는 **고정상에 머문 시간이 다르기 때문**
  - 🗣️ 비유: 하교길에 바로 집에 간 친구 = t_m / 문방구 들렀다 간 친구 / 문방구 + PC방 + 떡볶이까지 간 친구 → 중간에 머문 시간이 길수록 늦게 도착
- 🗣️ **t_r = (고정상에 머문 시간) + (이동상에 머문 시간 t_m)**
- 🗣️ **보정 머무름시간 t′_r (adjusted retention time) = t_r − t_m = 고정상에 머문 시간**
  - ★ "**용질이 고정상에 얼마나 잘 머무는지가 중요**한데 그 시간을 측정하려면" → t′_r. 전체 시간보다 고정상에 머문 시간이 중요해서 t_r을 쪼갬

### 7-3. 분리인자 α, γ [01:07:19–01:08:57]
- 🗣️ **분리인자 α (separation factor, relative retention)** = **t′_r2 / t′_r1** (t_r이 아니라 **t′_r**)
  - **분모에 반드시 짧은 쪽** → **α > 1**
  - α가 클수록 두 용질이 고정상에 머무는 시간 차이가 큼 → 분리가 더 잘 됨 (눈으로 보이는 걸 수치화)
- 🗣️ **γ (unadjusted relative retention)** = t_r2 / t_r1 (t_m을 안 뺌). "**별로 쓸모가 없는데**, 렐러티브 리텐션이 더 중요"

### 7-4. 용량인자 k′ ★★ [01:08:57–01:13:05]
- 🗣️ "**진짜로 중요한 게 이제 세 번째예요.**" / "**크로마토그래피를 하는 사람이라면 이걸 반드시 이해하고 사용할 줄을 알아야 됩니다.**"
- 🗣️ t_r의 한계: **이동상에 머문 시간까지 섞여 있음** ("오염되어 있다") → 사람들이 안 좋아함. 우리가 진짜 비교하고 싶은 건 **고정상에 얼마나 잘 머무는지**
- 🗣️ **k′ (retention factor = capacity factor, 용량인자) = t′_r / t_m = (t_r − t_m) / t_m**
  - 고정상에 머문 시간을 **이동상에 머문 시간의 배수**로 나타낸 것
  - **단위 없음** (분자·분모 단위가 같음)
  - k′가 클수록 그 용질이 고정상에 더 잘 머묾 → 용질끼리 k′로 비교. t_r로 비교하면 위험할 수 있음

### 7-5. k′와 분배계수 K의 관계 ★ [01:13:05–01:19:05]
- 🗣️ 분배 크로마토그래피 = 추출과 원리가 같음. 이동하면서 계속 **평형** 유지 → 두 상의 농도가 일정 비율
- 🗣️ 유도
  - k′ = (고정상에 머문 시간)/(이동상에 머문 시간) = (고정상의 용질 몰수)/(이동상의 용질 몰수) — 오래 머문다 = 그 상에 더 많이 있다
  - 몰수 = 농도 × 부피 → k′ = c_s·V_s / c_m·V_m
  - V_s/V_m: 칼럼이 정해지면 **상수**. c_s/c_m = 평형 농도비 = **분배계수 K**
  - **k′ = K · (V_s / V_m)**
- 🗣️ "**용질에 따라 k′가 달라지는 이유는 분배계수의 차이 때문**이라는 게 수식으로 바로 드러난다"
- 🗣️ K는 칼럼에서 직접 잴 수 없지만 **k′는 쉽게 측정** → K 대신 k′를 측정
- 🗣️ k′ ∝ K ∝ t′_r. 그래서 t′_r보다 **k′를 많이 씀**
- 🗣️ α도 결국 k′의 비 (= K의 비) → **두 피크가 분리되는 가장 근본적인 이유 = 분배계수의 차이**
- 🗣️ **머무름부피 V_r = t_r × u_v** (x축을 부피로 바꿀 수 있음, 잘 안 씀)

### 7-6. 슬라이드 Q 풀이 [01:19:05–01:20:34]
- 🗣️ **k′ = 0**: 가능? → 학생 답 **CH₄** (고정상과 전혀 상호작용 안 함, t_r = t_m) → **0배**
- 🗣️ **k′ = 1**: 고정상에 머문 시간 = 이동상에 머문 시간 → **1배** ("우연히 같은 거")
- 📝 **k′ = 5** → **5배** (t_r = 6 t_m)
- 🗣️ "이걸 많이 써먹어야 됩니다. 나중에 **계산도 해 보고 측정도** 해 볼 텐데요"

## 8. 분리 효율: 분리도와 확산 [01:20:34–01:41:51] (슬라이드 24–29)

### 8-1. 분리도 R ★★ [01:20:34–01:28:58]
- 🗣️ "분리 분석의 효율성을 나타내는 **정량적 지표**가 반드시 존재하죠. **아주 중요하죠.**"
- 🗣️ Q: 두 피크가 얼마나 잘 분리됐는지 결정하는 요인? → ① **머무름시간 차이** ② **피크 넓이(폭)** (학생 답). 아무리 멀리 떨어져도 피크가 넓으면 겹침
- 🗣️ **R = Δt_r / w_av** (분자 = 머무름시간 차이, 분모 = 두 피크 폭의 평균). **클수록 좋음**
- 🗣️ 피크는 특별한 언급이 없으면 **가우스 곡선(정규분포)** 으로 가정
  - 꼭대기 = 평균, **양쪽 변곡점 사이 = 2σ**
  - 변곡점 접선이 바탕선과 만드는 삼각형의 **밑변 = 4σ = 피크 폭 w**
  - **높이 50%에서의 폭 w½ = 2.35σ** (2σ와 4σ 사이)
- 🗣️ 4σ는 재기 어려움 → **50% 높이 폭**을 주로 사용. 4σ = 2.35σ × **1.70** → w = 1.70 w½
- 🗣️ ★ **R = Δt_r / 1.70 w½,av = 0.589 Δt_r / w½,av** (1/1.70 = 0.589)
  - "**전 세계적으로 가장 많이 쓰이고 있는 수식**. 거의 다 이걸 써요"
  - "두 피크의 머무름시간과 50% 높이 폭만 재면 분리도를 바로 계산. **여러분도 이걸 가지고 직접 계산을 해 봐야 됩니다.**"
- 🗣️ 왜 정규분포인가? 무작위 현상 = **확산** 때문 (뒤에서)

### 8-2. 분리도 값에 따른 모양 [01:28:58–01:31:50]
- 🗣️ 두 피크 폭이 같다고 가정 (w = 4σ)

| Δt_r | R | 모양 |
|---|---|---|
| 2σ | 2/4 = **0.5** | 합쳐서 봉우리 하나, 분리 안 됨 |
| 3σ | **0.75** | 작은 골이 생김, 여전히 분리 안 됨 |
| 4σ | **1.0** | 많이 분리, 아직 조금 겹침 |
| 6σ | **1.5** | **거의 완벽하게 분리** |

- 🗣️ ★ "**보통 최소 레졸루션이 1.5는 돼야 된다**". 크면 좋지만 비용·시간이 들어서 1.5면 충분

### 8-3. 확산: 피크 넓어짐의 주원인 [01:31:50–01:35:22]
- 🗣️ ★ "**넓은 피크는 우리한테 제일 큰 적**" — 분리가 안 된다는 뜻
- 🗣️ 피크 넓어짐(peak broadening)의 가장 중요한 원인 = **확산 (수동 확산)** → 그래서 피크가 가우스 모양
- 🗣️ 아무리 샤프하게 로딩해도, 로딩 순간부터 고농도 → 저농도로 **무작위 확산** → 띠가 점점 넓어짐. **막을 수 없는 자연의 법칙**, 잘 다뤄야 함
- 🗣️ 예: t_r 2분 피크 vs 26분 피크 → 26분이 훨씬 넓음. "**리텐션 타임이 길어지면 무조건 피크가 넓어져요**"
- 🗣️ 확산을 이해 못 하면 → 피크 넓이를 이해 못 함 → 분리도를 컨트롤할 수 없음

### 8-4. Fick의 확산 제1법칙 [01:35:22–01:38:58]
- 🗣️ **확산 속도는 농도 구배(concentration gradient)에 비례**
- 🗣️ **플럭스 J** = 단위 면적당 확산 속도. **J = −D (dc/dx)**, 비례상수 **D = 확산계수**
- 🗣️ 확산이 빠르다 = 농도 구배가 크거나 **D가 큼**. 크로마토그래피에선 플럭스가 크면 피크가 넓어지니 싫음
- 🗣️ **D에 영향을 주는 것**: 물질의 상태, 분자 크기·구조, 온도
  - 고체 < 액체 < **기체** (기체에서 확산이 가장 빠름)
  - **분자가 클수록 D 작음** (수크로스 > 단백질)
- 🗣️ 확산만 생각하면 D를 작게 할수록 덜 퍼짐

### 8-5. 확산에 의한 띠 넓어짐 식 [01:38:58–01:41:51]
- 🗣️ 피크가 가우스 곡선 → **확률밀도함수**로 그릴 수 있음 (σ와 평균만 주어지면)
- 🗣️ 확률밀도함수에서 유도한 크로마토그래피 피크 식 (위아래 모양이 비슷)
  - t = 칼럼에 머문 **시간**
  - ① 시간이 길수록 피크가 퍼지면서 **중앙값(최고 농도)이 내려감**: c(x=0) = m/√(4πDt)
  - ② 두 식을 비교하면 **2σ² = 4Dt → σ = √(2Dt)**
- 🗣️ ★ "**우리가 제일 걱정하는 게 피크 넓이**. 피크 넓이에 비례하는 값이 σ" → **칼럼에 머문 시간 t가 길수록, 확산계수 D가 클수록 피크가 넓어짐**
- 🗣️ "힘들게 해 놨더니 다 알고 있는 거네. 지극히 상식적인, 수치로 표현했을 뿐"
- 🗣️ **다음 주에 계속** (📝 슬라이드 30 이론단 높이 H부터)
