# 유기화학 폴더 작업 규칙

## 마스터요약 (기말대비_마스터요약) — 23장 형식이 기본

새 장의 마스터요약은 **`_build/마스터요약23`을 복사해서** 같은 형식으로 만든다 (22장 `_build/마스터요약`은 옛 형식, 고치지 말 것).

빌드: `sh make.sh` (넘침 검사 → 짝·혼자 쪽 결정 → PDF). 출력 `유기화학/CHnn_기말대비_마스터요약.pdf`.

### 표지
- 21장 정리본 스타일: 왼쪽 판에 큰 「nn장」 + 장 제목, 오른쪽 목차(배지·번호·제목·쪽).
- 왼쪽 판 색은 22·23장과 같은 분홍→자주 (`linear-gradient(170deg,#e64980 0%,#c2255c 38%,#862e5c 72%,#4a2347 100%)`).
- 목차 배지: 개념 보라 · 예제 분홍 · 본문 연두 · 과제 주황 · 강의 자주 · 변형 노랑.

### 문제 쪽
- 문제 다음 바로 정답·해설. **메모 칸 없음.**
- 한 쪽에 2문제 (칸마다 위 문제 / **아래쪽에 정답·해설**). 넘치면 그림을 70 %까지 줄여서라도 2문제 유지.
- 그래도 안 되면 1문제 쪽: 위 문제(+용어) / 아래쪽에 정답·해설 두 단.
  아래 정렬로 그림이 65 % 밑으로 작아지는 긴 문제만 문제 → 정답 → 해설을 두 단으로 이어서.
- 「계속」 쪽·해설집 전용 쪽은 만들지 않는다 — 그림을 줄여 한 쪽에.
- 모든 캡처 그림(원서 문제·정답·해설집·슬라이드)은 같은 배율 (`textbook.py`의 K).

### 내용
- 개념: 핵심 → 상세 → 슬라이드 그림 → 곡선 화살표 메커니즘 → 🎯 녹취 카드 → 한 줄.
- 문제: 원서 예제·본문 문제(원서·정답·해설집 캡처 + 한글 풀이), 강의자료 의약품 빈칸, 과제, 예상 변형.
- 📚 용어 풀이: 문서에서 **처음 나온 쪽에서만**.
- 시험 직전 TOP 10: 과제 → 강의 빈칸 → 녹취 강조 순.

### 색감
- 주황 · 보라 · 연두 · 분홍. **그라데이션 쓰지 않음** (표지 왼쪽 판만 예외).
- 꼬리말에 형광펜 범례 넣지 않음 (제목 + 쪽 번호만).

## 그 밖에
- 작업은 브랜치에 커밋 → 푸시 → PR → 머지 → PDF 전송.
- 번역본: `_build/강의번역23`·`강의번역24` 형식 (슬라이드 + 번역 + 설명 + 메커니즘).
