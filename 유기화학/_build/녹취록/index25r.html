00:00–04:35의자형 → 피셔 투영 · 번호 매기기 · D/L 25장 슬라이드 2–4

  • 당이 의자형(chair form)으로 그려져 있으면, 이것을 쭉 눌러 평면으로 그린 것이 피셔 투영.
  • 고리에는 탄소 대신 산소가 하나 있다. 이 산소 바로 옆 탄소가 1번 → 피셔 투영의 맨 위부터 1, 2, 3, 4 … 번호를 매긴다. 고리 산소 자리를 “6번”처럼 잡으면 그리기 편하다.
  • 1번 탄소와 고리 안 산소 사이 결합이 끊어지면 1번이 알데하이드가 된다 — 고리형과 열린 사슬은 왔다 갔다 한다(평형).
  • 읽는 법: 의자형에서 아래(down) OH → 피셔에서 오른쪽, 위(up) OH → 왼쪽. 포도당: 1번 아래(오른쪽) · 2번 아래(오른쪽) · 3번 위(왼쪽) · 4번 아래(오른쪽) · 5번은 고리에 연결 · 6번 CH₂OH는 보통 위(up)로 그린다.
  • D/L: 마지막(맨 아래 카이랄 탄소)의 OH만 본다. 오른쪽이면 D.
🎯 중요 포인트: “보시다시피 중요한 포인트가 있어요.” — 고리 산소 옆이 1번(아노머 탄소), 오른쪽 = 아래, 왼쪽 = 위, 맨 아래 OH로 D/L.
※ 확인: (02:27) “[산소/고리] 내부에 있는 산소” → 고리 내부의 산소, (02:56) “[평면형]” → 피셔 투영(평면형)으로 적었습니다.

04:35–10:52평면형(피셔) → 고리형 그리기 · α/β 아노머 25장 슬라이드 3–5

  • 평면형에서 중요한 곳은 마지막 OH(C5–OH)와 알데하이드(C1). 이 둘이 결합해 고리(헤미아세탈)가 된다.
  • 그리는 순서: 육각형을 그리고 고리 산소 옆부터 1, 2, 3, 4, 5, 산소(“6”)로 번호 → 피셔에서 오른쪽 OH는 아래, 왼쪽 OH는 위 → 마지막 CH₂OH는 그냥 위로.
  • 1번 탄소 = 아노머 탄소(anomeric carbon). 고리가 풀렸다가 다시 닫힐 때 1번 OH가 위로도 아래로도 갈 수 있어 이성질체가 생긴다 = α/β 아노머.
  • 1번 OH가 CH₂OH와 같은 방향(위) → β, CH₂OH와 반대(아래) → α. 둘 다 가능할 때는 물결선으로 표시.
🎯 범위: “되게 헷갈립니다. 그래서 그냥 알파 베타 이성질체가 있고, 이성질체는 이렇게 물결로 표시도 한다. 이 정도만 알면 좋을 것 같습니다.” · “여기서 중요한 걸 봤을 때는 평면형일 때 마지막에 있는 OH랑 그리고 알데하이드 쪽.”

“지난 시간에 다뤘던 내용 한 번 더 보여 드린 건데요 — 다양한 단당류를 볼 때 마지막 OH 기준으로 D냐 L이냐 구별한다.”

11:18–12:10포도당의 고리형 · 열린 사슬 비율 25장 슬라이드 5

  • 고리형은 알데하이드(열린 사슬) 형태로 풀릴 수 있다 — 그 비율이 그림에 적혀 있음(α 37.3 % · β 62.6 % · 열린 사슬 0.002 %).
  • 아노머 탄소의 OH와 CH₂OH가 반대 방향(trans) = α, 같은 방향 = β.
🎯 “여기는 또 시스(cis)라고 표현돼 있어 헷갈리는데, 이거를 알파, 그리고 같은 방향이면은 베타라고 합니다.” · “이거는 단당류 같은 거 좀 그리는 거에 익숙해지면 더 좋을 거 같고요.”

12:10–17:17단당류의 반응 ① — 에스터·에터, 글리코사이드 25장 슬라이드 6–8

  • 자유로운(free) OH에는 아세틸기를 달 수 있고(에스터화), H 대신 다른 친전자체(메틸 등)를 넣을 수도 있다(에터화) 25장 슬라이드 6–7.
  • 선택성: 고리 안 산소와 아노머 탄소의 1번 OH가 반응에 많이 관여한다 → 고리가 풀리거나, 안 풀리면 1번 OH 자리에서 반응.
  • 산성 조건: 아노머 탄소에서 물이 떨어지고, 생긴 양이온에 친핵체(알코올)가 들어가 글리코사이드 25장 슬라이드 8.
  • 친핵체가 아래(down)로 들어가느냐, 입체 장애가 있는 위쪽으로 가느냐에 따라 수율(선택성)이 달라진다 — 지난 시간 내용.
※ 확인: (16:07) “일렉트로파일이 들어가게 되는데, 아 뉴클레오파일이죠” — 교수님이 바로 정정하셨습니다. 아노머 탄소(양이온)에 들어가는 것은 친핵체(알코올 · Br⁻ · 페놀).
※ 확인: (17:17) “내부에 있는 산소 같은 경우 알데하이드가 형성될 수가 있는데” — 이때는 고리가 열린 알데하이드가 아니라, 고리 산소의 전자쌍이 C1과 이중결합을 이룬 옥소카베늄 이온(C1=O⁺, 고리 유지)입니다.

17:17–19:24쾨니히스-크노르 반응 — β-글리코사이드 25장 슬라이드 9–10

  • 산 조건에서 1번 탄소의 OAc가 떨어지고 → 옥소카베늄 → HBr의 Br⁻가 입체 장애가 가장 적은 아래(down, α)로 들어감 (α-브로모 당).
  • 이 자리에 페놀(알코올)을 붙인다. 아래의 Br이 떨어지면, C2의 아세틸기가 분자 내(intramolecular)로 일시적인 고리를 만든다(이웃기 참여).
  • 아래쪽이 이 고리로 막혀 있어서 친핵체는 반발이 적은 위쪽에서, SN2처럼 반대쪽에서 들어와 고리를 연다 → 위(β)에 페놀.
🎯 흐름: Br⁻는 아래(α)로 → Ag₂O로 Br 이탈 → C2 아세틸이 아래를 막음 → 친핵체는 위에서 → β-글리코사이드.
※ 확인: “코에그니스 노르 리액션”으로 들렸지만 쾨니히스-크노르(Koenigs–Knorr) 반응입니다.

19:24–21:46단당류의 환원·산화 · 엔올을 거친 이성질체 25장 슬라이드 11–15

  • 당은 고리형 ⇌ 열린 사슬(알데하이드). 열린 사슬에서 환원(NaBH₄)하면 양 끝이 모두 알코올 → 알디톨 25장 슬라이드 11.
  • Br₂, H₂O: 알데하이드만 선택적으로 산(–COOH)으로 산화 → 알돈산 25장 슬라이드 12.
  • 케톤(케토스)이 있으면 염기 조건에서 엔올로 존재 → 다시 케톤/알데하이드로 돌아올 때 평면(sp²)이 sp³가 되면서 C2의 OH가 오른쪽이면 D-포도당, 왼쪽이면 D-만노스 → 이성질체가 생김 25장 슬라이드 13.
  • 더 강한 산화제(따뜻한 묽은 HNO₃): 알데하이드와 아래쪽 끝의 알코올(–CH₂OH)을 둘 다 산화 → 알다르산 25장 슬라이드 14.
  • OH가 많은데 마지막 CH₂OH만 효소가 특이적으로 산으로 만드는 경우 → 우론산 25장 슬라이드 15.
※ 확인: (19:24) “리덕션을 진행하면 얘는 환원당이 되죠” — 환원(NaBH₄) 생성물은 알디톨(당알코올)입니다. 환원당은 톨렌스·베네딕트 시약을 환원시키는(자신은 산화되는) 당을 말하는 다른 개념입니다 25장 슬라이드 13.

22:07–24:00사슬 늘이기·줄이기 — 킬리아니-피셔 · 볼 분해 25장 슬라이드 16–17

  • 킬리아니-피셔 합성: 열린 사슬의 알데하이드에 사이아나이드(HCN)를 넣으면 탄소가 하나 늘어남 → CN을 환원(H₂, Pd)하면 이민 → 산 조건에서 물이 들어가 가수분해 → 새 알데하이드. 원래 C1은 OH를 가진 새 카이랄 탄소(C2 에피머 2개).
  • 볼 분해: 하이드록실아민(NH₂OH)으로 옥심을 만들고 → 니트릴로 바꿈(Ac₂O, −H₂O) → 염기에서 C2의 OH가 C=O(알데하이드)로 돌아가면서 CN⁻가 이탈기로 떨어짐 → 탄소 하나 줄어듦.
※ 확인: (22:07) “글루코스 같은 슈가는 사이아나이드 탄소를 하나 갖고 있죠”는 “사이아나이드가 탄소를 하나 갖고 있다(그래서 붙이면 탄소가 하나 늘어난다)”는 뜻으로 보입니다. “킬라니 피셔 [시가시스]” → Kiliani–Fischer synthesis, “울 디그라데이션” → Wohl degradation. (23:04) “[소듐/소량] 하이드록실아민”은 슬라이드 17 시약이 NH₂OH입니다.
※ 확인: 킬리아니-피셔에서 “OH가 하나 추가됐죠” — 새로 생긴 것은 알데하이드(C1)이고, 원래의 C1이 OH를 가진 C2가 됩니다.

24:00–25:568가지 필수 단당류 — 포도당 기준 차이 25장 슬라이드 18–19

  • 사슬 길이는 같은데 OH가 오른쪽이냐 왼쪽이냐만 다르다(포도당 기준).
  • 갈락토스 = C4의 OH가 반대(C4 에피머) · 만노스 = C2의 OH가 반대(C2 에피머).
  • 자일로스 = 맨 아래 CH₂OH가 하나 없음(5탄당).
  • 6-데옥시-갈락토스: D-갈락토스는 마지막 OH가 오른쪽, L-갈락토스는 왼쪽. 여기에 6번 OH가 빠진(데옥시) 것 → L-푸코스.
※ 확인: (24:00) “글루코스 기준으로 … 3번 위치가 다른 거는 갈락토스, 1번 위치가 다른 거는 만노스” — 교수님은 첫 카이랄 탄소(C2)부터 1번으로 센 것으로 보입니다. 표준 번호로는 갈락토스 = C4, 만노스 = C2가 다릅니다 (슬라이드 19의 빨간 상자).

25:56–40:14직접 그려 보기 — 갈락토스 · 만노스 · L-푸코스 25장 슬라이드 19

  • 갈락토스: 마지막 OH가 오른쪽 → D (왼쪽이면 L). 고리형: 1번 = 고리 산소 옆 아노머 탄소 · 2번 오른쪽 → 아래 OH · 3번 왼쪽 → 위 · 4번도 위 · 5번에 CH₂OH.
  • 만노스: 마지막 OH 오른쪽 → D-만노스. 고리형으로 그리면 C2의 OH가 위. 6번(C5–OH)은 고리 안쪽으로 들어가 고리 산소가 되고, CH₂OH는 밖에서 위로.
  • L-푸코스: 마지막 OH가 왼쪽 → L. 1번 위치(아노머 OH)는 위·아래 두 가지 형태.
🎯 그리는 규칙: “그릴 때 중요한 거는 처음에 알데하이드 그려 주고 제일 아래에다가 CH₂OH를 그려 줍니다.” → 1번(아노머·알데하이드 탄소)부터 고리가 연결되는 OH를 6번으로 잡고 육각형에 1–6 번호 → 오른쪽 OH는 아래, 왼쪽 OH는 위. “요런 식으로 룰 정해서 그리면서 연습하면 좋을 거 같습니다.”
※ 확인: 판서 중 정정이 여러 번 있었습니다 — (34:14–34:41) OH 개수(고리형에 OH 4개가 맞음: C1·C2·C3·C4), (35:38) “6번은 외부에 있으니까 생략”은 직전 설명대로 “C5–OH는 고리 안(고리 산소)으로 들어가니까”가 맞습니다, (38:27) 1번 위치 OH 누락 정정, (39:18) “오른쪽 OH는 위 … 아, 오른쪽은 아래, 왼쪽은 위”.
※ 확인: (38:51) “라세믹 두 가지 형태” — C1의 α/β는 거울상이성질체가 아니라 아노머(부분입체이성질체)이므로 “아노머 혼합물(물결선)”로 이해하면 됩니다.

41:41–52:41문제 풀이 ① — 22장 카보닐 α-치환

  • 22장 핵심: 케톤이 있으면 항상 α 탄소(α-position)에 집중. 염기 조건 + 할로젠 같은 친전자체가 있으면 α에서 치환.
  • 1번 (칠판: 사이클로헥사논 + 1. LDA 2. Cl₂): 염기가 들어가면 케톤의 α-H가 떨어지고 → 엔올(엔올레이트) → 친핵체로 작용. 이렇게 접근.
  • 2번 (칠판: 2-메틸사이클로헥세인카복실산): 카복실산 + PBr₃, Br₂ → 헬-볼하드-젤린스키(HVZ) 반응 — 똑같이 α 위치에 Br을 도입하는 네임드 반응.
    • 여기에 H₂O를 넣으면 산 브로마이드의 Br이 OH로 → α-브로모 카복실산.
    • 물 대신 메틸아민 CH₃NH₂ + 염기 TEA를 쓰면 친핵체(아민)가 카보닐 쪽에 들어감 → α-브로모 아마이드.

52:41–58:52문제 풀이 ② — 23장 카보닐 축합 · 마이클 반응

  • 23장: 같은 케톤 분자 둘 + 염기 → 한쪽이 엔올레이트(친핵체)가 되어 다른 케톤(친전자체)과 반응 → 축합(condensation) = 두 분자가 만나 하나의 분자가 되는 반응.
  • 마이클 반응: 이중결합이 있는 α,β-불포화 카보닐 = 마이클 받개(acceptor), 엔올레이트를 주는 쪽 = 마이클 주개(donor).
  • 양쪽에 카보닐이 있는 화합물(1,3-다이카보닐)은 두 카보닐 사이 가운데 H가 잘 떨어짐 → 엔올(레이트) → 친핵체.
  • NaOEt(소듐 에톡사이드, 강한 염기)가 주개를 엔올레이트로 → 받개의 말단(β) 탄소를 공격 → C–C 결합 생성 → 음전하(엔올레이트) → 산으로 중화하면 H가 들어가 최종 케톤 형태.
🧑‍🏫 칠판 문제 — 23장 (축합 · 마이클)
복습 + 염기알돌 두 분자 → 한 분자
① + NaOEt H₃O⁺

주개 = 아세토아세트산 에틸 (두 C=O 사이 CH₂의 H가 떨어짐) · 받개 = 페닐 바이닐 케톤 (말단 CH₂ = β 탄소 공격) · 엔올레이트 → H₃O⁺로 중화 → 1,5-다이카보닐.

58:52–1:04:36문제 풀이 ③ — 24장 아민 (산드마이어 · 니트릴 환원)

  • 1번 (칠판: 아닐린): 시약 NaNO₂, HCl → 아릴아민이 다이아조늄 염(이온 형태)이 됨. 실온에서 불안정 → 저온(0–5 °C), 산 조건에서 존재 → CuCN 같은 친핵체를 넣으면 그 자리가 치환 = 산드마이어 반응. CuCl이면 Cl, CuBr이면 Br.
  • 2번 (칠판: o-메틸벤질 브로마이드 → 2-(o-톨릴)에틸아민): 알킬 할라이드 → 아민, 그런데 탄소가 1개 → 2개로 늘어남. 탄소 하나 늘릴 때는 친핵체 NaCN(CN⁻) → Br을 SN2로 치환 → LiAlH₄(LAH)로 CN 환원 → –CH₂NH₂.
  • 그냥 아민을 친핵체로 쓰면 Br이 바로 아민으로 바뀔 뿐 — 탄소가 늘었으면 CN을 거친 것.

② NaCNSN2 LiAlH₄ (LAH) 탄소 +1 (CH₂ 하나 늘어남)
