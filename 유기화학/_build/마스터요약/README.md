# 챕터별 기말 마스터 요약본 (표준: 22장)

`../../CH22_기말대비_마스터요약.pdf`를 만든 도구. 다른 장도 이 구조 그대로 만든다.
틀은 `의약품 분석학/_제작파일/중간고사_마스터요약/`(의약품분석학II 마스터요약 필기반영본)에서 가져왔다.

## 구성 (22장 = 57쪽)
1. 표지(목차·숫자 카드) → 읽기 전에 ① 출제 스타일·사용법 ② 자료 체크리스트 ③ 한 장 반응 지도 + 4대 직관 공식
2. PART마다 **개념 쪽**들 → 그 PART의 **문제 쪽**들
   - 개념: 💡 핵심 → 📖 설명 → 슬라이드 그림 → 🎯 녹취(교수님 강조) / ✍️ 내 정리(단권화 노트) / 함정·비유 카드 → ⚗️ 메커니즘 띠 → 🧠 한 줄
   - 문제: **왼쪽 = 문제 + 풀이 칸, 오른쪽 = 정답 + Step-by-Step + 그림(해설집·메커니즘)**
   - 유형 표시: 구조식 그리기 · 시약 쓰기 · 순서 배열 · 메커니즘 · 생성물 예측 · 중간체 예측 · 빈칸 · 서술형 (`../../시험_후기.md` 기준)
3. 최종 정리: 시약 치트시트 + pKa 사다리, 혼동 쌍 + 시험 직전 10줄

## 들어가는 자료
- 강의자료 슬라이드(`../강의번역/img/s-NN.jpg`)와 번역본 내용
- 슬라이드 옆 메커니즘(`../강의번역/mslides22.py`) → `MS(키)`, `MSR(키, 줄…)`로 재사용
- 강의 녹취록 → 🎯 카드, 단권화 노트 → ✍️ 카드
- 원서 예제(Worked Example)·문제(Problem)는 **원서 그대로**: 원서 PDF에서 문제 그림을 오려 왼쪽에, 원서 Answer Key + 해설집(SSM) 풀이를 오른쪽에 (`textbook.py`)
- 과제(강의자료 마지막 슬라이드), 예상 변형(중간고사보다 한 단계 어렵게)

## 실행
```bash
python3 build.py && node render.js "../../CH22_기말대비_마스터요약.pdf"   # 넘치는 쪽은 글자·그림 자동 축소
```
- `parts.py`: 장 번호·색·파트 이름·`S()`/`C()`/`MOLS()`/`RX()` 구조식 도우미
- `c00_front.py` 표지·안내 / `c10_p1.py` `c20_p2.py` `c30_p3.py` PART별 개념·문제 / `c90_final.py` 최종 정리
- 다음 장: 이 폴더를 복사해 `parts.py`의 CH·색·파트 이름과 `c*.py` 내용만 바꾼다. 그 장의 번역본·메커니즘(`mslidesNN.py`)을 먼저 만든다.
