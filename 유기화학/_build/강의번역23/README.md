# CH23 강의자료 번역·설명 PDF

`../강의번역`(22장)과 같은 템플릿. 23장 슬라이드 이미지가 22장과 섞이지 않게 폴더를 나눴다 (fonts는 `../강의번역/fonts` 링크).

```bash
sh make_img.sh "../../CH23_약품유기화학2.pdf"     # img/s-01.jpg … s-43.jpg
python3 build.py                                   # index.html
node render.js "../../CH23_약품유기화학2_번역본.pdf"
```
- `ch23_1.py` 슬 1–21 (알돌·탈수·혼합 알돌·분자 내 알돌), `ch23_2.py` 슬 22–31 (클라이젠·디크만), `ch23_3.py` 슬 32–43 (마이클·스토크·로빈슨·생체)
- `mslides23.py`: 슬라이드 옆 곡선 화살표 메커니즘 — 슬 4·9·15·18·22(2쪽)·28·33·38
- `render.js`: 메커니즘이 넓으면 글자 대신 그림 배율만 줄임
