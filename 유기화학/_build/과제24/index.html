과제 24-32

호프만 자리옮김 — 생성물 + 메커니즘

✏️ 정답 (구조)
(a) Br₂, NaOHH₂O + CO₂
(b) Br₂, NaOHH₂O + CO₂
손글씨 요령 메커니즘은 다음 두 쪽 — (a)(b) 각각, 해설집과 같은 단계 전부. 생성물은 탄소 1개 줄어든 1차 아민 + CO₂.
과제 24-32

호프만 자리옮김 — (a) 메커니즘

✏️ (a) 메커니즘 — 3-메틸뷰탄아마이드
① OH⁻가 N–H 떼기 ② N⁻가 Br–Br 공격 (Br⁻ 이탈)−Br⁻ ③ 남은 N–H 떼기
④ O⁻ → C=O, 알킬기가 N으로, Br⁻ 이탈−Br⁻ ⑤ OH⁻가 C 공격, N이 물의 H를 받음
⑥ 카밤산 → C=O 생기며 C–N 끊김−CO₂ 1차 아민 + CO₂ + OH⁻
손글씨 요령 꼭 써야 할 것 (해설집 6단계): ① OH⁻가 N–H 떼기 ② N⁻가 Br₂ 공격 → N–Br ③ 남은 N–H 떼기 ④ O⁻가 C=O 복구 + 알킬기 N으로 이동 + Br⁻ 이탈 → 아이소사이아네이트 ⑤ OH⁻가 C 공격, N이 물의 H 받음 → 카밤산 ⑥ C=O 생기며 C–N 끊김(N이 물의 H 받음) → 아민 + CO₂.
과제 24-32

호프만 자리옮김 — (b) 메커니즘

✏️ (b) 메커니즘 — 사이클로펜테인카복스아마이드
① OH⁻가 N–H 떼기 ② N⁻가 Br–Br 공격 (Br⁻ 이탈)−Br⁻ ③ 남은 N–H 떼기
④ O⁻ → C=O, 알킬기가 N으로, Br⁻ 이탈−Br⁻ ⑤ OH⁻가 C 공격, N이 물의 H를 받음
⑥ 카밤산 → C=O 생기며 C–N 끊김−CO₂ 1차 아민 + CO₂ + OH⁻
손글씨 요령 꼭 써야 할 것 (해설집 6단계): ① OH⁻가 N–H 떼기 ② N⁻가 Br₂ 공격 → N–Br ③ 남은 N–H 떼기 ④ O⁻가 C=O 복구 + 알킬기 N으로 이동 + Br⁻ 이탈 → 아이소사이아네이트 ⑤ OH⁻가 C 공격, N이 물의 H 받음 → 카밤산 ⑥ C=O 생기며 C–N 끊김(N이 물의 H 받음) → 아민 + CO₂.
과제 24-33

커티어스 자리옮김 — 생성물 + 메커니즘

✏️ 정답 (구조)
(a) 1. NaN₃2. H₂O, Δ + N₂ + CO₂ (트랜스 그대로)
(b) 1. NaN₃2. H₂O, Δ + N₂ + CO₂
손글씨 요령 메커니즘은 다음 두 쪽 — (a)(b) 각각, 해설집과 같은 단계 전부. 이동하는 탄소의 입체 배치는 유지 → (a) 생성물도 트랜스.
과제 24-33

커티어스 자리옮김 — (a) 메커니즘

✏️ (a) 메커니즘 — 데칼린 산 염화물 (고리 접합부 탄소가 이동, 입체 유지)
① N₃⁻가 C=O 탄소 공격 ② 사면체 중간체: C=O 복구, Cl⁻ 이탈−Cl⁻
③ 가열: 알킬기가 N으로, N₂ 이탈Δ−N₂ ④ OH⁻가 C 공격, N이 물의 H를 받음
⑤ 카밤산 → C=O 생기며 C–N 끊김−CO₂ 1차 아민 + CO₂ + OH⁻
손글씨 요령 꼭 써야 할 것 (해설집 5단계): ① N₃⁻가 C=O 탄소 공격 → 사면체 중간체 ② O⁻가 C=O 복구, Cl⁻ 이탈 → 아실 아자이드 ③ 가열: 알킬기 N으로 이동 + N₂ 이탈 → 아이소사이아네이트 ④ OH⁻가 C 공격, N이 물의 H 받음 → 카밤산 ⑤ C=O 생기며 C–N 끊김 → 아민 + CO₂.
과제 24-33

커티어스 자리옮김 — (b) 메커니즘

✏️ (b) 메커니즘 — 3-뷰텐오일 클로라이드
① N₃⁻가 C=O 탄소 공격 ② 사면체 중간체: C=O 복구, Cl⁻ 이탈−Cl⁻

(a) HNO₃H₂SO₄ H₂, Pt
(b) HNO₂H₂SO₄ CuCN 1. LiAlH₄2. H₂O

HNO₂H₂SO₄ NaI CH₃OHH⁺

과제 24-64

A → B → C 예측

✏️ 정답 (구조)
(a) CH₃I과량 AAg₂OH₂O BΔ C (주)
(b) NaN₃ AΔ−N₂ BH₂O−CO₂ C
(c) KOH APhCH₂Br BKOHH₂O C
(d) + CH₃NH₂ (1당량)NaOHH₂O
