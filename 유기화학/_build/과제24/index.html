과제 24-32

호프만 자리옮김 — 생성물 + 메커니즘

✏️ 정답 (구조)
(a) Br₂, NaOHH₂O + CO₂
(b) Br₂, NaOHH₂O + CO₂
✏️ (a) 메커니즘 — 3-메틸뷰탄아마이드
① OH⁻가 N–H 떼기−H₂O ② N⁻ → Br–Br−Br⁻ ③ 남은 N–H 떼기
④ 알킬기가 N으로 + Br⁻ 이탈−Br⁻ ⑤ 아이소사이아네이트 + OH⁻H₂O 카밤산⑥ −CO₂ 1차 아민
손글씨 요령 (b) 메커니즘은 다음 쪽. 생성물은 탄소 1개 줄어든 1차 아민 + CO₂.
과제 24-32

호프만 자리옮김 — (b) 메커니즘

✏️ (b) 메커니즘 — 사이클로펜테인카복스아마이드
① OH⁻가 N–H 떼기−H₂O ② N⁻ → Br–Br−Br⁻ ③ 남은 N–H 떼기
④ 알킬기가 N으로 + Br⁻ 이탈−Br⁻ ⑤ 아이소사이아네이트 + OH⁻H₂O 카밤산⑥ −CO₂ 1차 아민
손글씨 요령 꼭 써야 할 것: ① OH⁻가 N–H 떼기 ② N⁻가 Br₂ 공격 → N–Br ③ 남은 N–H 떼기 ④ 알킬기 이동 + Br⁻ 이탈 → 아이소사이아네이트 ⑤ OH⁻ 첨가 → 카밤산 ⑥ −CO₂ → 아민.
과제 24-33

커티어스 자리옮김 — 생성물 + 메커니즘

✏️ 정답 (구조)
(a) 1. NaN₃2. H₂O, Δ + N₂ + CO₂ (트랜스 그대로)
(b) 1. NaN₃2. H₂O, Δ + N₂ + CO₂
✏️ (a) 메커니즘 — 데칼린 산 염화물 (고리 접합부 탄소가 이동, 입체 유지)
① N₃⁻ 아실 치환−Cl⁻ ② 가열: 알킬기가 N으로 + N₂ 이탈Δ−N₂
③ 아이소사이아네이트 + H₂O양성자 이동 카밤산④ −CO₂ 1차 아민
손글씨 요령 (b) 메커니즘은 다음 쪽. 이동하는 탄소의 입체 배치는 유지 → (a) 생성물도 트랜스.
과제 24-33

커티어스 자리옮김 — (b) 메커니즘

✏️ (b) 메커니즘 — 3-뷰텐오일 클로라이드
① N₃⁻ 아실 치환−Cl⁻ ② 가열: 알킬기가 N으로 + N₂ 이탈Δ−N₂
③ 아이소사이아네이트 + H₂O양성자 이동 카밤산④ −CO₂ 1차 아민
손글씨 요령 꼭 써야 할 것: ① N₃⁻가 C=O 탄소 공격, Cl⁻ 이탈 → 아실 아자이드 ② 가열: 알킬기 이동 + N₂ 이탈 → 아이소사이아네이트 ③ 물 첨가 → 카밤산 → −CO₂ → 아민.

과제 24-64

A → B → C 예측

✏️ 정답 (구조)
(a) CH₃I과량 AAg₂OH₂O BΔ C (주)
(b) NaN₃ AΔ−N₂ BH₂O−CO₂ C
(c) KOH APhCH₂Br BKOHH₂O C
(d) + CH₃NH₂ (1당량)NaOHH₂O
