# 23장 기말대비 마스터요약 (빌드)

22장 `마스터요약` 엔진을 복사해 23장 내용으로 바꾼 것.

- `c00_front.py` 표지(21장 정리본 스타일: 큰 '23장' + 목차) · 한 장 지도
- `c10_p1.py` 알돌 / `c20_p2.py` 클라이젠·디크만 / `c30_p3.py` 마이클·스토크·로빈슨 (개념 + 문제)
- `c90_final.py` 치트키 · 혼동 쌍, `top23.py` 시험 직전 TOP 10, `extra23.py` 녹취 카드
- `textbook.py` 원서 문제 도우미, `img/` 원서·정답·해설집 캡처

```
python3 build.py && node render.js ../../CH23_기말대비_마스터요약.pdf
```

## 표지 (2026-11-12부터)
빌드로 PDF를 다시 만든 뒤에 공용 기말 표지를 다시 넣는다: `cd _공용/기말표지 && python3 covers.py <id>` (id는 `_공용/기말표지/README.md` 참고). 1쪽 목차는 그대로 두고, 새 표지가 맨 앞에 붙는다.
