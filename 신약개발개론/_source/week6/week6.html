1맞춤형 암 mRNA 백신, 어디가 어려워?

돌연변이가 많다고 다 좋은 표적이 아님!

① 표적 선별 — 환자의 HLA에 실려 제시되는 신항원만 의미 있음 (T세포는 HLA 위 조각만 봄)
② 종양 이질성 — 암세포마다 돌연변이가 달라 일부가 회피
③ 빠른 생산 · 반응 유지 — 환자별 제작 + 면역억제 종양환경

흐름: 분석(WES·RNA-seq) → 예측(HLA 결합·T세포 인식, 딥러닝) → 검증(면역원성)
신항원 = 암 돌연변이로 생긴, 정상세포엔 없는 펩타이드

2mRNA 안정성 = 필요한 만큼

목표는 최대 안정성이 아니라 필요한 발현량 × 필요한 기간

mRNA 소실 ≠ 단백질 소실 — mRNA가 먼저 줄고, 단백질은 늦게 올라 늦게 내려감
같은 단백질도 서열 설계에 따라 기능적 반감기 2.6 ~ 8.8 h (3배↑ 차이)

조절 수단: mRNA 구조 · 전달체 · 투여량 · 투여 간격
예) 백신 = 며칠이면 충분 / 효소 결핍 = 길게·반복
→ 효과와 과도한 노출(안전성)을 함께 검증

3LNP 성분은 어디로 가?

음식처럼 소화관에서 소화 ✗ → 세포·조직의 지방 처리 경로

① 입자 해체 → ② 대사·재활용 → ③ 성분별 배출
이온화 지질: 에스터 가수분해 + β산화 (일부러 잘 끊기게 설계 = 생분해성)
ALC-0315 → 글루쿠론산 포합 → 소변
ALC-0159(PEG-지질) → 아마이드 가수분해
인지질·콜레스테롤 → 세포막 재료·일반 지방 대사(간)

배출: 수용성 작은 것 → 소변 / 지질성 → 담즙 → 대변
“간 하나만 / 신장 하나만” ✗

🧭 6단계 한 줄씩 (슬라이드 14)

① Target 선정 — 특정 질환 치료를 위한 Target 모색
② Target 검증 — Target과 질환의 상관·인과관계 검증
③ Hit 도출 — Target을 제어할 다수의 유효물질 탐색
④ Lead 도출 — 효과 최적·부작용 최소인 소수 선도물질
⑤ Lead 최적화 — in vitro·in vivo 검증 → 최종 후보물질
Hit = 유효물질 · Lead = 선도물질

🔤 기본 용어 (슬라이드 13)

표적 = 주로 단백질(수용체·효소·이온채널·수송체), 일부 핵산
작용제 켬 / 길항제 막음
친화도 KD·Ki · 효력 EC50·IC50 → 작을수록 강함
선택성 = 원하는 표적에만 (off-target↓)
결합 = 수소·이온·소수성·반데르발스 등 약한 비공유결합의 합 → 가역적

6주차PART 05Target 검증 (Validation) — “타겟을 바꾸면 병이 바뀌나?”슬라이드 22~25
정의타겟에 대한 약물의 효과가 허용 가능한 안전 범위(safety window) 안에서 치료 이점을 준다는 것을 여러 기법으로 증명 · 타겟의 변화가 질병의 발병과정(pathological process)과 연결됨을 확인
동정 vs 검증
동정 = “관련 있다” (상관)
검증 = “바꾸면 병이 바뀐다” (인과)
Safety window
효과 용량 ↔ 독성 용량 사이 간격
정상 조직에서도 중요한 타겟이면 좁아짐

🧰 검증 도구 8가지 (슬라이드 23)

① 동물 질병 모델 ② 발현 프로파일 ③ 바이오마커 ④ 세포 기반 질병 모델 ⑤ 약리학적 도구 화합물 ⑥ 기능 분석 ⑦ 시험관·생체 내 유전자 조작 ⑧ 질병 연관 유전학
→ 각 도구마다 한계 → 여러 근거를 겹쳐 신뢰도↑ (예: PCSK9 기능상실 → LDL↓ → PCSK9 억제제)

🔬 좁은 의미의 타겟 규명 (슬라이드 24)

= 생리활성 저분자 화합물의 작용점 규명 (화학유전체학)
타겟 3대장: 효소 · 수용체 · 이온채널
정상 대비 단백질 발현이 높거나 낮은지 확인 → 발현을 제어해 연관성 파악 (e.g., siRNA)

🛡 면역관문 (슬라이드 24~25)

모범답안
표현형 기반(forward)은 질병 모델(세포·초파리)에서 표현형 분석으로 효과 있는 화합물을 먼저 찾고, 타겟은 나중에 역추적(deconvolution)한다. 생체 내 실제 효과를 보므로 first-in-class 발견에 강하지만 타겟 규명이 어렵다. 타겟 기반(reverse)은 검증된 분자 타겟에서 출발해 정제 단백질 생화학 분석으로 화합물을 찾고 세포·동물에서 확인한다. 기전이 명확하고 HTS에 유리하지만 세포·동물에서 효과가 없을 수 있다.
