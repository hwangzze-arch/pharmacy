# 신약개발개론 시험 기록

기말 준비 때 먼저 읽을 것.

## 2026 중간고사 (2026-10-21 응시)

### 형식
| 항목 | 내용 |
|---|---|
| 총 문항 | 40문제 (본인 기억) |
| 객관식 | 26개 |
| 단답형 | 16개 |
| 서술형 | **없음** |
| 범위 | 1~6주차 강의자료 (6주차는 p.33 HTS까지) |
| 배점 | 중간 40% |

> 메모: 객관식 26 + 단답 16 = 42라서 "총 40문제"와 2개가 안 맞음. 단답 중 일부가 한 문항 안의 소문항이었거나 기억 차이일 수 있음. 기말 전 확인할 것.

### 체감
- 문제 스타일은 통합 모의고사(`신약개발개론_중간고사_총정리+통합모의고사.pdf`)와 **비슷했음**.
- 다만 **더 헷갈렸음** → 보기끼리 차이가 미세하고 세부적이었음.
- 2025 리뷰에서 교수님이 예고한 "같은 문제 3년째라 **새 문제·더 세부적인 문제**로 내겠다"가 실제로 반영된 것으로 보임.

### 2024·2025와 달라진 점
| | 2024 | 2025 | 2026 (이번) |
|---|---|---|---|
| 객관식 | 약 17 | 약 13 + O/X | **26** |
| 단답 | 약어·용어 몇 개 | 약어·빈칸·이유 쓰기 | **16** |
| 서술 | 있음 (서방/장용, 5개 쓰기) | 있음 (5개 쓰기) | **없음** |

→ 서술형이 빠지고 **객관식·단답 비중이 크게 늘었음**.

## 기말 대비 전략 (기말 45%)
1. **단답 정확도**: 단답이 16개나 나옴 → 약어 풀네임·인명·약 이름·용어를 **철자까지 정확히** (2025엔 API 철자 틀리면 오답 처리).
2. **객관식 세부 구분**: "옳지 않은 것" 보기들이 미세하게 다름 → 주차별 노트의 **상세요약 페이지**와 **헷갈리는 쌍 비교표** 위주로. 암기카드만으로는 부족.
3. **서술 대비는 최소한만**: 이번엔 없었지만 기말에 나올 수 있으니 "5개 쓰기"형 정도만 준비.
4. **기출 문장 반복 기대 ✗**: 같은 포인트라도 문장을 바꿔서 냄 → 개념 자체를 이해할 것.
5. 기말 노트도 같은 형식(상세요약 + 개념문제 + 실전문제)으로 만들되, 실전문제 비율을 **객관식 > 단답 > O/X**로 조정하고 보기 난이도를 올릴 것.
