- 2025 리뷰에서 교수님이 예고한 "같은 문제 3년째라 **새 문제·더 세부적인 문제**로 내겠다"가 실제로 반영된 것으로 보임.

## 기말 대비 전략 (기말 45%)
1. **단답 정확도**: 단답이 14개나 나옴 → 약어 풀네임·인명·약 이름·용어를 **철자까지 정확히** (2025엔 API 철자 틀리면 오답 처리).
2. **객관식 세부 구분**: "옳지 않은 것" 보기들이 미세하게 다름 → 주차별 노트의 **상세요약 페이지**와 **헷갈리는 쌍 비교표** 위주로. 암기카드만으로는 부족.
3. **서술 대비는 최소한만**: 이번엔 없었지만 기말에 나올 수 있으니 "5개 쓰기"형 정도만 준비.
4. **기출 문장 반복 기대 ✗**: 같은 포인트라도 문장을 바꿔서 냄 → 개념 자체를 이해할 것.
5. 기말 노트도 같은 형식(상세요약 + 개념문제 + 실전문제)으로 만들되, 실전문제 비율을 **객관식 > 단답 > O/X**로 조정하고 보기 난이도를 올릴 것.

### 출제 패턴
- 보기는 **두 개념을 맞바꾸는** 식: 엔브렐(바이오)↔스티렌(천연물), 서방정↔장용정, 알파폴드 = **화학상**(물리학상 ✗), 개량신약 = 신규 적응증·용도 변경(구조 개선 ✗), TPP 제출 = **의무 아님**, 표적 = 단백질 + **핵산도 가능**, Unmet need **먼저** 정의.
- 단답: 철자는 조금 틀려도 인정하지만 **다른 단어면 오답** (NDA = New Drug **Application**, Approval ✗). **뭉뚱그린 답도 오답** (베레겐 = 시네카테킨, '녹차' ✗ / 하이브리도마 = B 림프구 + **골수종 세포**, '암세포' ✗).
