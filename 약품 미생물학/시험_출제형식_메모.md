# 약품미생물학 시험 출제 형식 메모

## 2026년 2학기 중간고사 (2026-10-20 응시 후기)

- 전체 양식은 기출(「2-1학기 미생물학 중간고사 기출 스타일」)과 같았음
- **단답형·서술형 없음** → 전부 객관식
- **총 45문항, 문항당 1점 (45점 만점)**
- 출제 방식: **보기 세트형**
  - 보기 ①~⑪(11개)을 한 세트로 먼저 제시
  - 그 아래 여러 문항이 이어지며, 문항마다 **지정된 개수만큼** 해당하는 보기를 고르는 형식
    (예: "다음 설명에 해당하는 것을 보기에서 2개 고르시오")
  - 이런 세트가 약 5개 → 합계 45문항

## 기말고사 준비 시 반영할 것

- 모의고사는 서술형을 빼고, **보기 11개 × 약 5세트, 총 45문항(각 1점)** 으로 만들기
- 문항마다 고를 개수를 명시하기 (1개, 2개, 3개 …)
- 한 세트 안의 보기들은 같은 주제(예: 바이러스 과, 균 이름, 약물, 매개체)로 묶여 있으므로,
  비슷한 이름끼리 헷갈리게 섞어서 출제하기

## 기말고사 범위 (2026-10-27 기준)

- 중간고사 이후 범위만 (누적 아님)
- 1차: `Viruses_2026.pdf` 120쪽부터 끝까지 (V군 (−)ssRNA: 파라믹소·랍도·번야·오르토믹소 / VI군 레트로: HTLV·HIV / VII군 HBV)
- 강의 녹취록을 함께 참고해서 만들 예정 (업로드 대기)
- 추가 강의자료가 더 올라올 예정 → 받는 대로 범위에 추가
- 만들 것: 기말 통합본 / 실제 형식 모의고사(보기 11개 × 5세트, 45문항) / 양방향 플래시카드 + 빈칸 비교표

## 항생제 파트 출제 관련 (2026-10-27 전달받음)

- 화학 구조(구조식)를 보여주고 어떤 항생제/계열인지 맞히는 문제가 나올 예정
- 학습자료·모의고사에 구조 그림 문항을 꼭 넣을 것 (구조 → 이름, 이름 → 구조, 공통 골격으로 계열 구분)
