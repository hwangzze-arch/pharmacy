### 1. 텔라반신 이름 · 바시트라신 (세포벽 저해제 끝, 슬라이드 (3) 14~15쪽)
- **텔라반신** = 개발사 **Theravance** + **vancomycin** (이중 기전은 지난 시간)
- **바시트라신**

| 항목 | 내용 |
|---|---|
| 구조 | **고리형 폴리펩타이드(cyclic polypeptide)**, A·B·C… 여러 성분의 혼합물 |
| 기원 | ***Bacillus*** (*B. subtilis* var. Tracy — var. = 변종, Tracy = 균을 분리한 환자 이름 / 지금 분류명 *B. licheniformis*) |
| 스펙트럼 | 크다 → 그람(−) 포린 통과 X → **그람(+)만**, **MRSA O** |
| 부작용 | **신독성(nephrotoxicity)** · **아나필락시스** |
| 사용 | 그래서 주로 **외용(연고·안약)** / 캐나다 일부 주사(황색포도알균 감염 영아) |
| 기전 | **박토프레놀 탈인산화 억제** → 박토프레놀 재활용 X |

- **세포벽 저해제 끝**: β-락탐 + 사이클로세린 · 반코마이신(텔라반신) · 바시트라신

### 2. 세포막 파괴제 (cell membrane disrupters, 슬라이드 (4) 2~3쪽)

| | **폴리믹신** | **그라미시딘 D (= A+B+C)** | 그라미시딘 S |
|---|---|---|---|
| 구조 | **고리형 폴리펩타이드 + 긴 소수성 꼬리(지방산)** (바시트라신과 비슷한 구조) | **선형 펩타이드 15개(펜타데카펩타이드)**, 대부분 소수성 | **고리형 10개(데카펩타이드)** |
| 종류 | A·B·C·D·E, **E = 콜리스틴**, 임상은 **B·E** | A 80% · B 6% · C 14% 혼합 = **D** (11번 아미노산 A=Trp, B=Phe, C=Tyr) | S = **Soviet Union**(소련에서 발견) |
| 기원 | ***Bacillus polymyxa***(→ 지금 ***Paenibacillus***) / 콜리스틴: *B. colistinus* | ***Bacillus brevis*** | |
| 스펙트럼 | **그람(−)** (녹농균 등), 그람(+) 제한적 — **페니실린과 반대** | **그람(+)** 주로 | 그람(−)까지 조금 더 |
| 기전 | **LPS의 인산기에 결합(앵커)** → 소수성 꼬리가 외막에 박혀 **외막·내막 파괴** = **세제 비슷한(detergent-like)** 기전 → 투과성↑ | 2개가 나선형으로 맞물려 **이온 채널** 형성 → 양이온 이동 → **이온 항상성 붕괴** (막을 깨는 건 X) | 막의 극성을 **깨뜨림** |
| 부작용·사용 | **신독성 · 신경독성** → **최후의 선택(last resort, last-line)**, IM·IV | **용혈(hemolysis)** 등 독성 강함 → **외용** | |

- **폴리믹신 이름**: *polymyxa* = poly(많은) + **myx(점액)** — 배양 시 점액성 / **콜리스틴** = **coliform**(대장균 비슷한 장내세균)에 듣는 항생물질
- **Paenibacillus** = paeni(거의, 비슷한) + *Bacillus* — 유전자 분석으로 따로 분류
- 폴리믹신이 last-line인 이유: **1950년대 승인**이라 지금의 엄격한 임상시험을 안 거침 + 신독성·신경독성
- 폴리믹신이 그람(+)에 약한 이유: **LPS(앵커)가 없음** + 두꺼운 펩티도글리칸을 뚫고 막까지 가기 어려움
- 그라미시딘 D가 그람(−)에 약한 이유: **소수성**이라 친수성 통로인 **포린 통과 X** → 내막까지 못 감 (외막에 박혀도 이온 채널은 의미 없음)
- first-line = 1차 선택 / second-line = 2차 / **last-line = 마지막 선택**

### 3. 단백질 합성 저해제 도입 (슬라이드 (4) 4~6쪽)
- 세균 리보솜 **70S = 50S(큰) + 30S(작은)** / 진핵세포 80S = 60S + 40S
- 단백질 합성 저해제는 **30S에 붙는 그룹 / 50S에 붙는 그룹**으로 나눔 (총 5그룹을 다룰 예정: 앞 2개 + 뒤 3개)

**아미노글리코사이드 (30S)**
- 이름: **글리코사이드(당에 글리코시드 결합으로 무언가 붙은 것) + 아미노기**
- 구조 = **아미노사이클리톨 + 아미노당** (O-글리코시드 결합)
  - 알케인(C·H) → 고리형 알케인 → OH 붙으면 **사이클리톨** → NH₂ 붙으면 **아미노사이클리톨**
- 대표 = **스트렙토마이신**: **왁스만(Selman Waksman), 1940년대**, **첫 단백질 합성 저해제**
- **기원 2속** 🎯 (세균 파트에서 "아미노글리코사이드를 분비한다"고 했던 그 둘)

| 기원 | 이름 끝 | 천연 | 반합성 |
|---|---|---|---|
| ***Streptomyces*** | **-mycin** (마이신) | 스트렙토마이신·스펙티노마이신·네오마이신·파로모마이신·카나마이신·토브라마이신 등 | **디베카신·아르베카신** (-mycin 아님) |
| ***Micromonospora*** | **-micin** (미신) | **젠타미신**·시소미신 등 | 이세파미신·네틸미신 등 |

- ⚠ -kacin처럼 규칙에서 벗어나는 이름도 있음 (100% 아님)
- **주 기전**: **30S에 결합** → 큰 소단위(50S)가 와서 붙는 것을 방해 → **완전한 리보솜 형성 억제** (그 밖의 부수 기전은 슬라이드)

**번역 개시와 리보솜 자리** 🎯
1. mRNA 시작 코돈 **AUG**에 **개시 tRNA(initiator tRNA)**가 먼저 결합
2. **30S(작은)**가 와서 결합 → 3. **50S(큰)**가 와서 결합 → 완전한 리보솜 → 번역 시작
- 큰 소단위의 3자리: **A(aminoacyl-tRNA) · P(peptidyl-tRNA) · E**. 개시 tRNA는 **P 자리**에 바로 들어감
- **아미노아실 tRNA** = 안티코돈에 맞는 아미노산이 붙은 tRNA (아실 = C=O; 아미노산의 COOH에서 OH가 빠지고 결합)
- **펩티딜 tRNA** = 아미노산이 폴리펩타이드로 길게 붙은 tRNA (다음 시간 이어서)
- tRNA: 한쪽 **안티코돈 루프**(코돈 인식), 반대쪽 **억셉터 스템**(아미노산 결합)
