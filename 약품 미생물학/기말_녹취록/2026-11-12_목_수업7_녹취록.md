### 2. MRSA·PRSA 역사 🎯

1. 플레밍이 페니실린 발견 → **2차 세계대전 후 산업화**, "신의 선물"
2. 세균이 **β-락타메이스**(β-락탐 고리를 깨는 효소)를 만들도록 **돌연변이**
3. 첫 반응 세균 = **황색포도알균(*S. aureus*)**: **피부 정상세균총**, 인구의 **약 20%**가 보유 → 여드름·종기, 축농증·폐렴, 식중독·설사, 패혈증
4. → **PRSA** (penicillin-resistant *S. aureus*) = 원래 페니실린에 내성
5. → 인류가 **반합성(semisynthetic)** 페니실린 **1호 = 메티실린** 개발
6. → 다시 돌연변이 → **MRSA** (methicillin-resistant *S. aureus*) = **항생제 내성균의 상징 용어**

- **반합성(semisynthetic)** = 천연물·생물 유래 물질의 구조 일부를 바꾼 것 / **전합성(totally synthetic)** = 단순한 화학물질부터 여러 단계로 새로 만든 것

### 3. 페니실린 계열 일반 특징 (슬라이드 8쪽)
- β-락탐 안에 **페니실린 계열**, **세팔로스포린 계열**이 대표
- **반감기 매우 짧음 (2시간 이내)** → **하루 여러 번** 투여
- 과민반응 (β-락탐 공통)
- **장 흡수 불량** → 경구 복용 시 **설사**
- **스펙트럼**: broad(광범위) = 다양한 세균 / narrow(협소) = 특정 그룹만
- **그람 양성균에 잘 듣고, 그람 음성균엔 없거나 매우 제한적**
  - 그람 양성: 펩티도글리칸이 바깥에 노출 → 접근 쉬움
  - 그람 음성: **외막(outer membrane)**이 감쌈 → **포린(porin)**을 통과해야 함
  - 포린 통과 조건 2가지: **크기가 작을수록**, **수용성이 높을수록**(포린 안이 수용액) 유리. 페니실린은 대체로 포린보다 커서 통과 어려움
- (참고) 소변에 잔류 → 요로감염(장내세균목 Enterobacterales 등)에 유리
- 한계(짧은 반감기, 좁은 그람 음성 스펙트럼)를 보완하려고 **반합성 페니실린** 개발

### 4. 천연 페니실린 (슬라이드 9~10쪽)
- 반합성이 아닌 것. **페니실리움(*Penicillium*) 곰팡이의 대사산물**
- 균 이름: ***P. notatum*(옛 이름) → *P. chrysogenum*(바뀐 이름)**, 같은 것. (참고: 플레밍 원래 균주는 *P. rubens*)
- 페니실리움 = **자낭균류(Ascomycota)** 멤버: 포자가 주머니(sac)에 싸임, **진균 중 가장 큰 그룹**, *Candida albicans*(칸디다증)도 여기 속함 — "요 정도만 기억"
- **페니실린 핵심 구조 = β-락탐(사각형) + 티아졸리딘(thiazolidine, 오각형)**
  - **thia** = 황(S), **az** = 질소(N), **-olidine** = **포화(단일결합만) 5원환**

| | 페니실린 G | 페니실린 V |
|---|---|---|
| 화학명 | **벤질페니실린** (R = 벤질기) | **페녹시메틸페니실린** (R = 페녹시메틸) |
| 투여 | **비경구(IM 근육·IV 정맥)** — 경구 X | **경구용** ("oral form of penicillin G") |
| 이유·주의 | **위산에 불안정** + 장 흡수 안 됨 | 음식과 상호작용 → **식전 투여** 권고 (슬라이드: 식사 30~60분 전) |
| 비고 | 가장 많이 쓰인 천연 페니실린. 하루 여러 번 IV → **정맥염(phlebitis)** | |

**지속형 (혈중 농도를 오래 유지하는 방법)**

| | 프로카인 벤질페니실린 | 벤자틴 벤질페니실린 |
|---|---|---|
| 섞는 것 | **프로카인 = 국소마취제** | **벤자틴 = 다이아민** (N,N'-bis(phenylmethyl)ethane-1,2-diamine) |
| 원리 | **깊은 근육주사** 가능(안 아프게) → 근육에서 **서서히 방출** | 페니실린과 **상호작용·안정화** → **서서히 방출** |
| 비고 | "되게 심플한 방법" | 과거 **매독(syphilis)** 치료에 많이 씀 |

### 5. 항포도상구균 페니실린 (반합성 ①, 슬라이드 11쪽) ★
- **β-락타메이스에 내성** → 페니실린 내성 포도알균(PRSA)에 효과
- 이름 = 구조에 붙은 기 + 페니실린

| 약 | 이름 유래 (구조) |
|---|---|
| **메티실린** | **메톡시기(-OCH₃) 2개** — **첫 반합성 페니실린** |
| **나프실린** | **나프탈렌** 고리 (좀약 성분, ph→f) |
| **옥사실린** | **옥사졸**(N+O 5원환) 고리 |
| **클록사실린** | **Cl 1개** + 옥사졸 |
| **디클록사실린** | **Cl 2개** + 옥사졸 |

- 아졸(azole) = N을 가진 5원환 + N·S·O 중 원자 하나 더 → 그게 O면 옥사졸
- 바뀐 구조가 β-락타메이스로부터 β-락탐 고리를 보호
- 그래도 **반감기는 여전히 짧음** → 하루 여러 번 (참고: IV 시 정맥염)

### 6. 아미노페니실린 (반합성 ②, 슬라이드 12쪽)
- **암피실린, 아목시실린, 시클라실린** — 코어에 **아미노기(-NH₂)** 도입
- 아미노기 → **수용성↑** → 그람 음성균 외막 **포린 통과↑** → **그람 음성 커버리지 확대** (narrow → 약간 broad)

| 약 | 이름 유래 |
|---|---|
| **암피실린** | 아미노 + 페니실린 |
| **아목시실린** | 아미노 + **옥시(벤젠고리에 -OH)** + 페니실린 |
| **시클라실린** | 벤젠 대신 **사이클로헥세인**(포화 6원환) |
