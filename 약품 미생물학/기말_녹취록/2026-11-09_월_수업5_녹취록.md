## 시험 대비 핵심 정리

### ⭐ 교수님: "기말에 낼 수 있다"고 짚은 것
- HIV 기회감염은 **앞 슬라이드에 적어놓은 정도**만 기말 출제 (뒤의 큰 표는 국시용, 기말엔 안 냄)
- 레트로바이러스의 **3대 효소(역전사효소·인테그레이스·프로테이스)는 모두 바이러스가 직접 만든다** → 모두 약물 표적

### 1. 그룹 6 vs 그룹 7 공통점·차이
- **공통: 둘 다 역전사(reverse transcription)** 를 함
- 차이: **그룹 6 = RNA 바이러스(레트로)**, **그룹 7 = DNA 바이러스(HBV)**
- 기억할 과(family): **Retroviridae** 하나

### 2. 레트로바이러스 유전체와 유전자
- **retro = backward** → 센트럴 도그마(DNA→RNA→단백질)를 **역행**(RNA→DNA)
- **외피 O**
- 유전체 = **(+) 단일가닥 RNA가 2개(dimer, 이량체)** → 이중가닥처럼 보이지만 상보결합 아님. 정체는 **(+)ssRNA**
- 발현 경로: **(+)ssRNA → (−)ssDNA → (±)dsDNA → (+)mRNA → 단백질** (부호가 계속 교대)
- 유전자 3그룹

| 유전자 | 만드는 것 |
|---|---|
| **gag** | 구조 단백질 (캡시드 등) — **MA**(matrix), **CA**(capsid), **NC**(nucleocapsid, RNA 안정화) |
| **pol** | 효소 — **PR**(protease), **RT**(reverse transcriptase), **IN**(integrase) |
| **env** | 외피 단백질 — **SU**(surface, 바깥), **TM**(transmembrane) |

- **폴리단백질(polyprotein)**: 여러 단백질이 이어진 형태로 만들어짐(레트로·코로나 등). 연결부를 **프로테이스(protease)** 가 잘라 개별 기능 단백질로 만듦 → **프로테이스가 못 자르면 복제 불가**

### 3. 생활사와 3대 효소 (모두 바이러스 자신이 만듦)

| 효소 | 역할 | 비고 |
|---|---|---|
| **역전사효소 (RT)** | (+)RNA → (−)DNA | = **RNA 의존 DNA 중합효소** (RNA-dependent DNA polymerase). 숙주엔 없음 |
| **인테그레이스 (IN)** | dsDNA를 숙주 지놈에 삽입(integration) → **provirus** | 숙주엔 없음 |
| **프로테이스 (PR)** | 폴리단백질 절단 → 기능 단백질 | 숙주엔 없음 |

### 4. 분류 (사람 질병 일으키는 2속)
- Rous sarcoma virus(닭 육종, 약자 RSV) — **호흡기 RSV와 약자만 같고 다름**, 임상적으로 안 중요
- **Deltaretrovirus → HTLV** (사람 T세포 백혈병 바이러스)
- **Lentivirus → HIV** (에이즈 바이러스)
- 용어 관계: **Retroviridae(과) ⊃ Lentivirus(속) ⊃ HIV(종)**

### 5. HTLV (Human T-lymphotropic virus)
- 타입 1~4 중 **HTLV-1이 가장 중요(도미넌트)**
- 일으키는 병
  - **ATLL** = Adult T-cell leukemia/lymphoma (성인 T세포 백혈병/림프종, **혈액암**)
  - **HAM/TSP** = HTLV-1 associated myelopathy / Tropical spastic paraparesis = **탈수초성 질환**
    - HAM = HTLV-1 관련 **척수병증(myelopathy)**
    - TSP = **열대성·경직성(spastic)·양하지(para-)·불완전마비(paresis)**. (이완성=flaccid, 완전마비=plegia)
    - ⚠ 길랭-바레(탈수초·**자가면역**)와 달리 HAM/TSP는 **바이러스 매개**
- 전파: **STI(성접촉)** 가 주 경로, 체액·모유수유도 가능
- 대부분 무증상, **~5%** 가 ATLL 또는 HAM/TSP. **provirus로 30~50년 잠복** 후 면역 저하 시 발병, ATLL 발병 시 **1년 내 사망**
- 분포: **일본 남부**, 카리브해, 아프리카, 미국 남동부 (일본 남부는 2차대전 미군 주둔 추정)
- 백신 없음 / 정식 치료제 없음 → **오프라벨(off-label)**: **AZT(=지도부딘=Retrovir) + 인터페론-α** 병용 (AZT는 원래 HIV 치료제)

### 6. HIV (Human immunodeficiency virus)
- **AIDS = Acquired immunodeficiency syndrome(후천성 면역결핍 증후군)** — HIV 감염 ≠ 에이즈. **면역 붕괴 후 합병증 단계**가 에이즈
- 타입: **HIV-1**(전 세계, 병원성↑) / **HIV-2**(주로 서아프리카, 병원성↓)
- **수용체 = CD4**, **보조수용체 = CCR5 또는 CXCR4**(케모카인 수용체) → **둘 다 결합해야** 침투
- 외피 당단백 **gp160 → gp120 + gp41**로 절단
  - **gp120** = CD4 + 보조수용체(CCR5/CXCR4)에 결합
  - **gp41** = 바이러스 외피–세포막 **융합(fusion peptide)**. 약품미생물학에선 gp120에 초점
- **케모카인 분류** (시스테인 모티프 기준)

| 종류 | 모티프 | 수용체 예 |
|---|---|---|
| C (XC) | C 하나 | XCR1 |
| **CC** | C 연속 | **CCR1~10 (5번 = CCR5)** |
| **CXC** | C–X–C | **CXCR1~7 (4번 = CXCR4)** |
| CX3C | C–XXX–C | CX3CR1 |

  - 케모카인 = 작은 사이토카인, **주화성(chemotaxis)** 유도 → 'chemotactic cytokine'
- 전파: **STI(성접촉)** 주 경로 + 체액 접촉
- 경과: 초기(발열·두통·무기력·발진·**구강 칸디다증**) → **provirus로 8~10년 잠복** 동안 **CD4+ 세포(보조 T세포, 대식세포 등) 점차 감소** → 바닥 수준 → 면역 붕괴 → 합병증 = **AIDS**
  - 그래프: 빨강=바이러스 수(초기 급증→감소→서서히 증가), 파랑=CD4+ 수(10년간 감소)
- **기회감염·합병증** (기말 출제 범위 = 앞 슬라이드 수준)
  - 칸디다증(*Candida albicans*, 자낭균류 Ascomycota), 헤르페스·**CMV**, 폐렴, CNS(운동실조·치매·뇌종양), 암(**카포시 육종**, 구강암, 직장/대장암)
- 백신 없음 / 진단: 바이러스 지놈 카피수, **CD4+ 수 카운팅** 등 / 치료제 = **다음 시간**

### 한 줄 암기
- 그룹6=RNA 레트로, 그룹7=DNA HBV / 공통=역전사
- gag=구조, pol=효소(PR·RT·IN), env=외피
- RT = RNA 의존 DNA 중합효소 / IN = provirus 삽입 / PR = 폴리단백질 절단 (3효소 모두 바이러스제)
- HTLV = HTLV-1 · ATLL · HAM/TSP · STI · AZT+IFN-α(오프라벨)
- HIV 수용체 CD4 + 보조수용체 **CCR5/CXCR4** / gp120 결합, gp41 융합
- CCR**5**, CXCR**4** (숫자까지) / 잠복 8~10년 → CD4↓ → AIDS

- 04:56 기억할 family는 **Retroviridae** 하나. 통상 레트로바이러스라 부르는 애들.
- 05:22 'retro'는 복고풍처럼 **거꾸로(backward)** → transcription을 거꾸로 감.
- 05:47 센트럴 도그마(DNA→RNA→단백질)를 역행: RNA에서 DNA를 만드는 과정 포함.

### [07:02 ~ 12:30] 유전자 발현 과정 및 구조 유전자 (gag, pol, env)
- 07:02 (+)ssRNA → gene expression에서 **(−)ssDNA**(역전사) 생성.
- 07:15 positive 다음엔 negative, negative 다음엔 positive로 계속 교대(상보적).
- 07:28 (−)ssDNA를 주형으로 (+)DNA를 만들어 **dsDNA**가 됨.

- 08:15 유전자 3그룹: **gag, pol, env**.
  - gag: viral capsid 등 **구조 단백질**

  - env: **envelope 단백질**
- 08:47 각 지놈 파트가 **polyprotein**(Gag / Gag-Pol / Env polyprotein)을 만듦.
- 09:16 보통은 1유전자→1단백질인데, 레트로·코로나 등 일부는 **polyprotein** 형태.
- 09:41 연결부를 **protease**가 잘라 single protein으로 만듦.
- 10:05 protease가 작동 못 하면 기능 단백질이 안 만들어져 복제 불가 → protease가 매우 중요.
- 10:37 (참고) MA=Matrix(외피 아래 단백질층), CA=Capsid, NC=Nucleoprotein(RNA 안정화) — 구조 단백질.

### [12:30 ~ 16:32] 레트로바이러스의 생활사 및 주요 효소
- 12:30 생활사는 인트로덕션과 대동소이. (+)ssRNA → (−)ssDNA 과정이 **역전사**.
- 13:01 이를 매개하는 **reverse transcriptase**는 숙주에 없고 **바이러스가 직접 만듦**(viral RT).
- 13:28 RT의 다른 이름(참고·국시) = **RNA-dependent DNA polymerase**.
- 13:44 'RNA-dependent' = 주형이 RNA. 즉 RNA를 주형으로 DNA를 만드는 중합효소 = reverse transcriptase.
- 14:22 (−)ssDNA 주형으로 (+)DNA 한 가닥 더 → dsDNA.
- 14:38 dsDNA는 숙주 지놈과 같은 형태 → 숙주 세포 특정 부위에 끼어들어감.
- 15:02 그 과정이 **integration**, 매개 효소가 **integrase(IN)**.
- 15:20 integrase도 숙주엔 없음 → 바이러스가 만듦(viral integrase).
- 15:46 integration된 형태 = **provirus**.
- 15:56 **protease**도 바이러스가 만듦 → polyprotein을 기능 단백질로 자름.

### [39:57 ~ 46:36] HIV 임상·기회감염·마무리
- 39:57 HIV도 **STI**. 주 경로 성접촉 + 체액 접촉.
- 40:20 초기 증상: 발열·무기력·두통·발진, **구강 칸디다증** 등.
- 40:46 Oral candidiasis = *Candida albicans*(진균)에 의한 구강 염증.
- 41:18 자낭균류(Ascomycota)의 병원성 효모 *Candida albicans* → 구강 칸디다증.
- 41:59 **provirus로 8~10년 잠복**, 그동안 **CD4+ 세포 수 감소**.
- 42:20 CD4+ 세포 = **보조 T세포** 대표, 대식세포·단핵구·수지상세포 일부도.
- 42:44 10년쯤 바닥 수준 → 면역 붕괴 → 다른 감염 유입 → 합병증 = **AIDS**.
- 43:07 **기회감염**: 칸디다증, 헤르페스·**CMV**, 폐렴, CNS(운동실조·치매·뇌종양), 암(**카포시 육종**, 구강암, 직장/대장암).
- 44:17 그래프: 빨강=바이러스 카피수(초기 급증→감소→서서히 증가), 파랑=CD4+ 수(10년 감소) → 바닥에서 합병증(AIDS).
- 45:10 **기말 출제는 앞 슬라이드 수준**, 뒤의 큰 표는 국시용(기말엔 안 냄).
- 45:50 백신 없음. 진단: 바이러스 카피수, CD4+ 수 카운팅 등.
- 46:11 **치료제가 중요 → 내일 이어서.** 내일 마무리되면 바로 항생제로.
- 46:24 (수업 종료)
