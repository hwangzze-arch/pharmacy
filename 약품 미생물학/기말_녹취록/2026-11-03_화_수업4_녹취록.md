|---|---|---|---|
| **오셀타미비르(타미플루)**, 자나미비르, 페라미비르 | **NA (뉴라미니다아제)** | 자손 바이러스 **방출(release)** | 현재 표준 치료제 |
| **아만타딘, 리만타딘** | **M2 이온 채널** (양성자 채널) | 바이러스 내부 산성화 → **탈외피(uncoating)·유전체 방출** | **전부 내성 → WHO 사용 중지 권고** |
| **발록사비르 (baloxavir)** | **PA** (cap-dependent **endonuclease**) | **캡 스내칭(cap snatching)** → 전사 개시 | 신규 |
| **파비피라비르 (favipiravir)** | **RdRp = PB1** | RNA **중합** | 신규 |
| **잉가비린 (ingavirin)** | **NP (핵단백질)** | NP가 RNA에 결합 못 함 → RNA 불안정 | 신규 |
| **우미페노비르 (umifenovir)** | **HA2** | **막 융합(membrane fusion)** | 신규 |

### ⭐ 8개 분절과 단백질 (A·B형 8분절, C형 7분절)

| 분절 | 단백질 | 역할 |
|---|---|---|
| 1 | **PB2** (Polymerase Basic 2) | 중합효소 복합체 · **숙주 mRNA의 5′-cap 인지** |
| 2 | **PB1** (Polymerase Basic 1) | 중합효소 복합체 · **실제 RNA 중합(RdRp)** ← 파비피라비르 |
| 3 | **PA** (Polymerase Acidic) | 중합효소 복합체 · **엔도뉴클레아제**(cap에서 10~13 nt 잘라냄) ← 발록사비르 |
| 4 | **HA** (헤마글루티닌) | HA1 = **시알산 수용체 결합** / HA2 = **막 융합** ← 우미페노비르 |
| 5 | **NP** (핵단백질) | 불안정한 단일가닥 RNA에 붙어 **안정화** ← 잉가비린 |
| 6 | **NA** (뉴라미니다아제) | 시알산을 잘라 **자손 바이러스 방출** ← 타미플루 |
| 7 | **M** (M1, M2) | 기질 단백질 · **M2 = 이온 채널** ← 아만타딘 |
| 8 | **NS** | 비구조 단백질 |

- 암기: **"PB2·PB1·PA / HA / NP / NA / M / NS"** = 중합효소 3총사 → 붙고(HA) → 감싸고(NP) → 떠나고(NA) → 틀(M) → 비구조(NS)

### 1. 인플루엔자 타입
- **D형**: 최근 추가, **소**만 감염, 인수공통 X → 배제
- **C형**: 사람·돼지·개, 사람에선 **산발적**, 병원성·중요도 낮음
- **A·B형**: 겨울 독감의 주원인. **가장 대표 = A형** (다양한 동물 감염 + 과거 팬데믹 원인)
- **A형 아형**: HA·NA의 항원 특이성으로 분류 → **H1~H18 × N1~N11** (예: H1N1, H3N2, H5N1). 모든 조합이 자연계에 있는 건 아님
- **B형**: 아형 없이 **계열(lineage) 2개 — 야마가타(Yamagata) / 빅토리아(Victoria)**

### 2. 숙주와 계절 독감
- **A형 자연숙주 = 야생 물새(waterfowl)**: 기러기, 청둥오리, 가창오리 → **철새 도래지(stopover site)** 에서 가금류(닭·오리)에 전파 → 조류독감(AI) → 드물게 동물→사람 (사람 간 전파는 제한적/없음)
- **B형 숙주**: 사람, **물개(seal)**, **페럿(ferret)**
- 증상: **고열**, 합병증 **폐렴** / 치명률 **약 0.1%** (주로 65세 이상, 폐렴)
- **현재 계절 독감 원인 = B형 + A형 H1N1 + A형 H3N2** (현재 H1N1은 2009 신종플루의 자손)
- **철새 이동 경로(flyway)** 는 정해져 있음(전 세계 8~11개). 한국은 **서태평양 + 동아시아-오스트레일리아** 2개가 겹쳐 철새가 많음(천수만). 여름에 북극에서 번식 → 겨울에 남하
- **A형의 공통 조상 = 조류 인플루엔자** → 숙주 적응(host adaptation)으로 말·개·돼지·사람 인플루엔자가 생김 (정설)

### 3. 팬데믹 역사

| 연도 | 이름 | 아형 | 발생 기전 |
|---|---|---|---|
| **1918~19** | **스페인 독감** | **H1N1** | **이례적으로 순수 조류독감이 직접 사람에게** → 사람 간 전파 |
| 1957~58 | 아시아 독감 | **H2N2** | 조류 + 사람 → **대변이** |
| 1968~69 | 홍콩 독감 | **H3N2** | 조류 + 사람 → **대변이** |
| **2009** | 신종 인플루엔자 | **H1N1** | **조류 + 사람 + 돼지** → **대변이** |

- 스페인 독감: 치명률 **10~20%**, 사망자 **5,000만~1억 명**. 스페인 기원이 아니라 1차대전 중 **중립국 스페인만 보도가 자유로워서** 붙은 이름 (국내 기록 '서반아 독감')
- 비교: 대표 팬데믹 세균 = 콜레라균, 천연두 = variola virus, 호흡기 팬데믹 바이러스 = **인플루엔자 A**

### 4. 항원 소변이 vs 대변이
- **소변이 (antigenic drift)** = **점돌연변이** 축적. RNA 바이러스라 **교정 기능(proofreading)이 없어서** 변이가 잘 생김
- **대변이 (antigenic shift)** = **분절 유전체** 때문. 서로 다른 바이러스 2종 이상이 한 세포에 동시 감염 → **분절 교환(재편성, reassortment)** → 완전히 새로운 바이러스
- **돼지 = 혼합 용기(mixing vessel)**: 호흡기 상피에 **조류형 + 사람형 수용체가 모두** 충분히 있음 (+ 돼지 인플루엔자 감수성)

### 5. 고병원성 조류인플루엔자

| 계열 | 예 | 사람 감염 | 사람 간 전파 | 사람 치명률 |
|---|---|---|---|---|
| **H5** | H5N1 → 최근 H5N6, H5N8 | O (동물→사람) | **X** (아직 숙주 적응 안 됨) | **50~60%** |
| **H7** | H7N9, H7N2 (중국 동해안·상하이) | O | **제한적이지만 O** | **약 20%** |

### 6. 방역과 백신
- **동물(가금류)**: 이동 제한 + **살처분** / 반려동물(개·고양이)은 백신, 고가 동물(말)은 백신·대증요법
- **한국은 고병원성 AI 가금류 백신 금지** (중국·멕시코 등은 사용) / **저병원성 H9N2(산란율만 떨어짐)는 닭 백신 허용**
  - 이유 = **트로이 목마 효과(Trojan effect)**: 백신 맞은 닭이 감염돼도 증상이 가벼워 멀쩡해 보임 → 이동 제한이 안 걸리고 닭·계란·사람을 통해 전국 확산
- **사람**: 1차 방어 = **백신**. 대부분 **근육주사 불활화(사)백신**, 일부 **비강 분무 약독화 생백신**
- **3가 → 4가 → 다시 3가**
  - 3가: A형 2종(H1N1, H3N2) + B형 1종 → 미국이 고른 B 계열이 유라시아에서 안 맞는 일이 반복
  - 4가: B형 야마가타 + 빅토리아 둘 다 포함
  - **2020년 3월 이후 북반구에서 야마가타 계열이 사라짐 → 빅토리아만 넣은 3가로 다시 전환**
- **백신주 선정**: WHO가 매년 **3~4월**(남반구·호주 유행 참고)에 예측·선정 → 제약사가 **부화란(약 10일 배양 유정란)** 또는 **세포주**에서 배양 → **9월 말~10월 초 출시**. 반년 전 예측이라 **미스매치** 시 효과 저하('물백신' 논란)

### 7. 항바이러스제 기전 자세히
- **NA 억제제**: 자손 바이러스의 HA가 세포 표면 시알산에 붙잡혀 있는 걸 NA가 잘라야 나갈 수 있음 → 이를 차단
- **M2 차단제 (아만타딘·리만타딘)**: 세포내이입 → **엔도좀** 형성 → 엔도좀 막의 양성자 채널로 H⁺가 들어와 **엔도좀 산성화** → 바이러스 외피의 **M2 채널로 H⁺가 바이러스 안으로** → 내부 산성화로 RNP(중합효소 복합체 + RNA)와 NP 등이 분리 → **유전체가 세포질로 방출(uncoating)**. 이 M2를 통한 H⁺ 이동을 차단. 최근 10여 년 유행 바이러스가 **모두 내성 → 사용 안 함**
- **발록사비르**: 숙주 mRNA의 **5′-cap**을 훔쳐야(cap snatching) 바이러스 mRNA를 번역할 수 있음. **PB2가 cap을 인지**하고 **PA가 10~13 nt 길이로 잘라냄(엔도뉴클레아제)** → 발록사비르는 **PA 엔도뉴클레아제 차단**
- **파비피라비르**: 표에는 'RdRp'로 표기, 실제 중합 기능은 **PB1** → PB1의 RNA 중합 차단
- **잉가비린**: **NP**를 막아 NP가 RNA에 결합하지 못하게 함 → 바이러스 RNA 불안정
- **우미페노비르**: HA 전구체 **HA0 → HA1 + HA2**로 절단. HA1 = 시알산 결합, **HA2 = 바이러스 외피와 엔도좀 막의 융합** → 우미페노비르는 **HA2 막 융합 차단**

### 한 줄 암기
- 타미플루 = NA = 방출 / 아만타딘 = M2 = 탈외피(지금은 안 씀)
- **발록사비르 = PA(캡 자르기)** / **파비피라비르 = PB1(중합)** / **잉가비린 = NP** / **우미페노비르 = HA2(융합)**
- PB2 = cap 인지, PA = cap 절단, PB1 = 중합
- 1918 H1N1(조류 직접) · 1957 H2N2 · 1968 H3N2 · 2009 H1N1(조류+사람+돼지)
- 돼지 = mixing vessel / 한국 고병원성 AI 백신 금지 = 트로이 목마 효과
- 현재 백신 = 3가(H1N1 + H3N2 + B 빅토리아), 야마가타는 2020년 이후 소멸

## 녹취록 원문 (사용자 제공)

### 1. 인플루엔자 바이러스의 타입(A, B, C, D) 및 분절 유전체 구조 (00:00 ~ 08:25)

**[00:00 ~ 01:44] 수업 전 출석 체크** (수업 시작 전 학생 호명 및 출석 확인)

**[01:45 ~ 03:45] 인플루엔자 타입 A, B, C, D의 특징**
지난 시간에 이어서 인플루엔자(오소믹소비리데, Orthomyxoviridae)를 보겠습니다. 오소믹소비리데는 인플루엔자다라고 봐도 무방할 정도로 인플루엔자가 메이저한 멤버들입니다. 타입은 크게 A, B, C, D 네 가지로 나뉩니다.
- 타입 D: 최근에 포함된 것으로 소(Bovine)에게 감염하는 애들이고 인수공통감염병이 아니기 때문에 일단 배제합니다.
- 타입 A, B, C: 모두 사람 감염(인수공통 포함)이 가능한데, 타입 C는 사람에게 산발적(Sporadic)으로 나타나고 병원성이나 중요도가 상당히 떨어집니다.
- 따라서 대표적인 것은 인플루엔자 A와 B이며, 겨울철 독감을 일으키는 주원인도 A와 B입니다. 그중에서도 가장 대표적인 메이저 멤버는 인플루엔자 A(Type A)입니다. 왜냐하면 인플루엔자 A는 사람을 포함한 다양한 동물 종에 감염하는 특성이 있고, 과거에 팬데믹(Pandemic)을 일으켰던 대표적인 바이러스가 바로 인플루엔자 타입 A이기 때문입니다.

**[03:46 ~ 08:25] 8개 분절(Segment) 유전체 구성과 아형(Subtype) 분류**
인플루엔자의 유전체(Genome)는 7~8개의 분절(Segment)로 되어 있는데, 타입 C가 7개의 분절로 되어 있고, 타입 A와 B는 8개의 분절로 되어 있습니다. 8개의 분절(1번~8번)은 다음과 같이 나뉩니다.
- 1번 ~ 3번 분절 (PB2, PB1, PA): P는 중합효소(Polymerase)의 약자이며, 각각 Polymerase Basic 2(PB2), Polymerase Basic 1(PB1), Polymerase Acidic(PA)의 약자입니다. 이 세 개가 모여서 중합효소 복합체(Polymerase complex)를 이룹니다.
- 4번 분절 (HA): 헤마글루티닌(Hemagglutinin, HA 또는 H)
- 5번 분절 (NP): 뉴클레오캡시드 단백질(Nucleoprotein, NP)
- 6번 분절 (NA): 뉴라미니다아제(Neuraminidase, NA 또는 N)
- 7번 분절 (M): 기질 단백질(Matrix protein, M1, M2)
- 8번 분절 (NS): 비구조 단백질(Non-structural protein, NS)

인플루엔자 타입 A의 아형(Subtype) 분류: 인플루엔자 타입 A는 표면 단백질인 HA와 NA의 항원 특이성(항원-항체 반응의 특이성)을 가지고 세부적인 아형(Subtype)으로 분류합니다. 현재까지 18개의 HA(H1~H18)와 11개의 NA(N1~N11) 서브타입으로 나뉩니다. 우리가 흔히 듣는 H1N1, H3N2, H5N1 같은 명칭은 이 HA의 타입 넘버와 NA의 서브타입 넘버의 조합에 의해 만들어진 것입니다(자연계에 산술적인 모든 조합이 다 존재하는 것은 아니며 특정 조합만 분리됨).

### 2. 숙주 범위와 철새 이동 경로 및 계절성 독감 (08:26 ~ 17:15)

**[08:26 ~ 11:35] 타입별 감염 숙주와 리니지(Lineage) 분류**
- 인플루엔자 A의 숙주: 사람을 포함한 다양한 동물 종에 감염하며, 자연 숙주(Natural host)는 조류(Bird), 그중에서도 기러기, 청둥오리, 가창오리 같은 물새류(Waterfowl)입니다. 이 야생 물새류(철새)가 이동하다가 중간에 쉬고 먹이를 먹는 구역인 철새 도래지(Stopover site)에 들렀을 때 농장의 가금류(닭, 오리 등)와 접촉하면서 바이러스를 전파시킵니다. 이로 인해 가금류 농장에서 고병원성 또는 저병원성 조류인플루엔자(AI)가 발생하고, 경우에 따라 사람과 접촉하면 고병원성 조류인플루엔자가 사람에게도 전파(Animal-to-human transmission)될 수 있습니다(다만 아직까지 사람 간 전파는 제한적이거나 일어나지 않음).
- 인플루엔자 B의 숙주 및 분류: 사람, 물개(Seal), 페럿(Ferret, 족제비과 동물) 등 제한된 동물 종에만 감염합니다. 인플루엔자 B는 A처럼 서브타입(H, N)으로 분류하지 않고, 이과·문과 나누듯이 야마가타(Yamagata)와 빅토리아(Victoria)라는 2개의 계열(Lineage, 리니지)로만 분류합니다.
- 인플루엔자 C의 숙주: 사람, 돼지, 개에만 감염하며, 사람에게서도 산발적으로만 나타나고 병원성이 낮습니다.

**[11:36 ~ 17:15] 임상 증상, 유행 아형, 철새의 이동 경로(Flyway)와 숙주 적응**
- 임상 증상 및 유행 주: 인플루엔자에 감염되면 가장 전형적인 특징이 고열을 동반한 발열 반응이며, 합병증으로 폐렴(Pneumonia)으로 진행되기도 합니다. 치명률은 약 0.1% 전후인데, 주로 65세 이상의 고령층에서 폐렴에 의해 사망하는 케이스들이 발생합니다. 현시점에서 겨울철 계절성 독감을 일으키는 것은 인플루엔자 B와 인플루엔자 A의 서브타입 중 H1N1, H3N2 두 가지뿐입니다(해마다 또는 같은 해의 월별로 번갈아 가며 유행함). 이 중 현재 유행하는 H1N1은 2009년 신종 인플루엔자 팬데믹을 일으켰던 바이러스의 자손들이 계절성 독감으로 편입된 것입니다.
- 철새 이동 경로(Flyway)와 숙주 적응(Host adaptation): 철새들은 매년 정해진 경로로만 이동하는데 이를 플라이웨이(Flyway)라고 합니다(전 세계적으로 8~11개 존재). 우리나라는 독특하게 서태평양(West Pacific) 플라이웨이와 동아시아-오스트레일리아(East Asia-Australasia) 플라이웨이 두 개가 중첩되는 위치에 있어서 철새가 굉장히 많이 찾아오는 나라입니다(천수만 등). 시베리아나 북극 쪽은 천적이 거의 없어서 철새들이 여름에 북극 쪽으로 올라가 산란하고 새끼를 길러 성체가 되면, 추워지는 겨울철에 먹이 활동을 위해 남하합니다(어떤 철새는 북극에서 칠레 남극 쪽까지 한 번도 안 쉬고 날아가기도 함).
- 조류인플루엔자의 기원: 인플루엔자 A의 원래 공통 조상(Origin)은 조류인플루엔자입니다. 철새가 이동하며 다양한 동물과 접촉하는 과정에서 숙주 적응(Host adaptation)을 거치며 말 인플루엔자, 개 인플루엔자, 돼지 인플루엔자 등이 만들어졌고, 아주 오래전에 사람에게도 들어와 적응하면서 현재의 계절성 사람 인플루엔자가 형성되었다는 것이 정설입니다.

### 3. 인플루엔자 팬데믹의 역사와 항원 대변이(Antigenic Shift) (17:16 ~ 26:45)

**[17:16 ~ 20:55] 역사상 주요 팬데믹과 스페인 독감(Spanish Flu)**
과거 팬데믹을 일으켰던 대표적인 세균이 콜레라균(Vibrio cholerae), 천연두를 일으켰던 바이러스가 베리올라 바이러스(Variola virus)라면, 호흡기 바이러스 중 가장 대표적인 팬데믹 바이러스는 인플루엔자 타입 A입니다.
- 지난 20세기의 3대 인플루엔자 팬데믹:
  1. 1918~1919년 스페인 독감 (Spanish flu, H1N1)
  2. 1957~1958년 아시아 독감 (Asian flu, H2N2)
  3. 1968~1969년 홍콩 독감 (Hong Kong flu, H3N2)
- 21세기의 인플루엔자 팬데믹: 2009년 신종 인플루엔자 팬데믹 (H1N1)

이 중 가장 악명이 높았던 것은 1918년 스페인 독감(H1N1)입니다. 치명률이 10~20%로 추정되며, 전 세계적으로 감염자가 아니라 사망자 추정 인원만 최소 5,000만 명에서 최대 1억 명에 달했습니다. 우리나라도 당시 일제강점기 신문 기사를 보면 '서반아(스페인) 독감'에 걸려 동네 지나가는 개도 죽었다는 기사가 나올 만큼 심각했습니다. 스페인 독감이라 불린 이유는 스페인에서 처음 시작되어서가 아니라, 당시 1차 세계대전 참전국들은 언론 보도 제한이 걸려 있었는데 중립국이었던 스페인에서만 언론 보도가 자유롭게 계속 나오다 보니 사람들이 스페인 독감이라 부르게 된 것입니다.

**[20:56 ~ 24:30] 항원 소변이(Antigenic Drift) vs 항원 대변이(Antigenic Shift)와 돼지(Mixing Vessel)**
인플루엔자 바이러스의 변이 기전에는 두 가지 용어가 있습니다.
1. 항원 소변이 (Antigenic drift): 우리가 흔히 알고 있는 돌연변이(Mutation, 점돌연변이 등)입니다. 인플루엔자는 RNA 바이러스이기 때문에 교정 기작(Proofreading)이 없어서 DNA 바이러스보다 돌연변이에 의한 변이체(Variant)를 매우 잘 만들어냅니다.
2. 항원 대변이 (Antigenic shift): 유전체가 분절(Segment)로 되어 있기 때문에 일어나는 현상입니다. 서로 다른 두 종류 이상의 바이러스가 하나의 숙주 세포에 동시 감염했을 때, 유전체 분절(Segment)끼리 서로 교환(재편성, Reassortment)되어 완전히 새로운 바이러스가 만들어지는 현상입니다.

역대 팬데믹의 발생 기전과 돼지의 역할:
- 1918년 스페인 독감(H1N1): 매우 이례적(Unusual)으로 순수한 조류인플루엔자가 다이렉트로 사람에게 들어와 사람 대 사람 감염을 일으키며 급격히 퍼진 케이스입니다.
- 1957년 아시아 독감 & 1968년 홍콩 독감: 조류 인플루엔자와 사람 인플루엔자가 하나의 숙주에 들어가 항원 대변이(Antigenic shift)를 일으켜 만들어진 신변종 바이러스가 사람 집단에서 유행한 케이스입니다.
- 2009년 신종 인플루엔자(H1N1): 조류 + 사람 + 돼지 인플루엔자 세 가지가 하나의 숙주에 들어가 항원 대변이(Antigenic shift)를 일으켜 유행한 케이스입니다.
- 혼합 용기 (Mixing vessel)로서의 돼지(Pig): 돼지는 호흡기 상피세포에 조류 인플루엔자에 대한 수용체(Receptor)와 사람 인플루엔자에 대한 수용체가 모두 충분히 발현되어 있고, 당연히 돼지 인플루엔자에 대한 감수성도 있습니다. 그러다 보니 조류와 사람 인플루엔자가 동시에 용이하게 감염하여 분절을 섞을 수 있는 대표적인 동물 종이 바로 돼지이며, 그래서 돼지를 인플루엔자의 믹싱 베슬(Mixing vessel, 혼합통)이라고 부릅니다.

**[24:31 ~ 26:45] 고병원성 조류인플루엔자 (H5 계열 vs H7 계열)**
고병원성 조류인플루엔자는 크게 H5 계열과 H7 계열 두 가지 그룹이 있습니다.
- H5 계열 (H5N1, H5N6, H5N8 등): 오랫동안 H5N1이 주도하다가 최근에는 H5N6, H5N8 등으로 조금씩 바뀌어 유행하고 있습니다. 감염된 조류와 사람이 접촉하면 사람 감염(Animal-to-human)이 가능하며, 사람 감염 시 치명률이 50~60%에 달합니다. 다행히 아직까지는 숙주 적응이 안 되어 있어서 사람 간 전파(Human-to-human transmission)는 일어나지 않습니다.
- H7 계열 (H7N9, H7N2 등): 주로 중국의 동해안(상하이 인근 등 우리나라와 가까운 지역)에서 많이 발생합니다. H7N9 등은 사람 감염이 일어날 뿐만 아니라 제한적이나마 사람 간 전파(Human-to-human transmission)가 발생하며, 치명률도 약 20%로 상당히 높아서 주의가 필요한 고병원성 조류인플루엔자입니다.

### 4. 동물 및 인체 인플루엔자 방역과 백신 (26:46 ~ 35:15)

**[26:46 ~ 30:10] 동물 인플루엔자의 통제: 살처분과 트로이 목마 효과(Trojan Effect)**
동물(가금류)에서 고병원성 조류인플루엔자가 발생했을 때의 기본 통제 방법은 이동 제한과 살처분(땅에 파묻는 매장)입니다. 예외적으로 개나 고양이 같은 반려동물은 백신을 쓰고, 말(Horse)처럼 매우 고가인 동물은 백신이나 대증요법(보존 치료, Allopathy)을 쓰기도 합니다.

고병원성 조류인플루엔자에 대한 닭·오리 백신도 개발은 되어 있고 중국, 멕시코 등 일부 국가에서는 쓰기도 하지만, 우리나라는 고병원성 조류인플루엔자에 대해 가금류 백신 사용을 금지하고 있습니다(단, 산란율만 떨어뜨리고 위험하지 않은 H9N2 같은 저병원성 조류인플루엔자에 대해서는 우리나라도 닭 백신을 허용함).
- 고병원성 AI 백신을 금지하는 이유 (트로이 목마 효과, Trojan effect): 백신이 감염 자체를 100% 막아주면 좋겠지만, 백신을 맞은 닭이 고병원성 바이러스에 감염되었을 때 백신 효과 때문에 죽지 않고 임상 증상만 가벼워져서 겉으로 보기에 멀쩡해 보이는 현상이 나타납니다. 증상이 안 보이니 농장에 이동 제한이 걸리지 않고, 감염된 닭과 계란, 사람이 전국으로 이동하면서 바이러스가 쫙 퍼지게 됩니다. 이처럼 트로이 목마 효과(Trojan effect)를 나타낼 수 있기 때문에 우리나라는 고병원성 AI 백신을 금지하고 살처분 정책을 씁니다.

**[30:11 ~ 35:15] 인체 인플루엔자 백신: 3가 백신 vs 4가 백신 및 백신주 미스매치**
사람에 대한 일차적인 통제 방법(Primary control method)은 백신(Vaccine)입니다. 대부분 근육주사로 맞는 불활화 백신(사백신, Inactivated vaccine)이 가장 대표적이며, 일부 코에 뿌리는(비강 접종) 생약독화 백신(Live attenuated vaccine)도 있습니다.
- 3가 백신(Trivalent)과 4가 백신(Quadrivalent)의 역사:
  - 과거에는 인플루엔자 A형 2종(H1N1, H3N2) + 인플루엔자 B형 1종(야마가타 또는 빅토리아 중 택 1)을 넣은 3가 백신을 썼습니다.
  - 그런데 WHO에서 백신주를 선정할 때 입김이 가장 센 미국이 아메리카 대륙에서 유행할 가능성이 높은 B형 리니지를 선택하면, 유라시아 대륙에서는 백신을 맞았는데도 다른 B형 리니지가 유행하는 일이 반복되었습니다. 유라시아 국가들의 항의로 아예 B형 두 가지(야마가타, 빅토리아)를 모두 넣어 총 4가지를 방어하는 4가 백신(Quadrivalent)을 쓰게 되었습니다.
  - 최신 동향 (3가 백신으로의 전환): 그런데 2020년 3월 이후로 북반구에서 B형 야마가타(Yamagata) 리니지가 유행을 아예 안 하고 사라졌습니다. 굳이 유행하지 않는 야마가타를 넣을 필요가 없어서 최근에는 B형 빅토리아(Victoria) 리니지만 넣어 다시 전체가 3가 백신으로 전환되었습니다.
- 백신 제조 과정과 미스매치(Mismatch): 사백신을 만들려면 부화란(열흘 정도 배양해 배아/Embryo가 형성된 유정란)이나 세포주(Cell line)에 바이러스를 접종해 대량 배양해야 하므로 제조 시간이 오래 걸립니다. 따라서 WHO에서 매년 3~4월경에 최근 유행 상황과 남반구(호주) 유행 상황을 종합해 그해 겨울 유행할 백신주를 미리 예측하여 선정하고, 4월경 각 제약사로 보냅니다. 제약사들이 그때부터 열심히 만들어서 9월 말~10월 초에 출시합니다. 이처럼 반년 전에 미리 예측해서 만들다 보니 실제 겨울에 유행하는 바이러스와 예측이 틀리는 백신주 미스매치(Mismatch)가 발생할 수 있고, 이 경우 백신 효과가 떨어져 흔히 말하는 '물백신' 논란이 생기기도 합니다.

### 5. 항바이러스제(Antiviral Drugs)의 작용 기전 총정리 (35:16 ~ 44:17) ★국시 핵심

인플루엔자 항바이러스제는 약사 국가고시에 가장 잘 나오는 파트이므로 각 약물의 이름과 타겟 기전을 정확히 연결해 기억하셔야 합니다.

**[35:16 ~ 39:15] 전통적인 항바이러스제 2종: NA 억제제 vs M2 이온 채널 차단제**
1. 뉴라미니다아제 억제제 (Neuraminidase inhibitor):
   - 약물: 오셀타미비르(Oseltamivir, 상품명: 타미플루), 자나미비르(Zanamivir), 페라미비르(Peramivir) 등.
   - 기전: 자손 바이러스(Progeny virus)가 세포 밖으로 나갈 때 HA가 시알산(Sialic acid)에 붙잡혀 있는 것을 잘라주는 효소가 뉴라미니다아제(NA)인데, 이를 블로킹하여 감염의 마지막 단계인 바이러스 방출(Release)을 억제합니다. 현재 임상에서 가장 흔히 쓰는 표준 치료제입니다.
2. M2 이온 채널 차단제 (M2 ion channel blocker):
   - 약물: 아만타딘(Amantadine), 리만타딘(Rimantadine).
   - 기전 (탈외피/Uncoating 및 유전체 방출 억제): 인플루엔자 외피에는 HA, NA 외에 M2 이온 채널(양성자 채널)이 있습니다. 바이러스가 숙주 세포에 결합해 세포내이입(Endocytosis)되면 엔도좀(Endosome)이라는 주머니가 형성됩니다. 먼저 엔도좀 막의 양성자 채널을 통해 세포질의 양성자(H⁺, Proton)가 엔도좀 안으로 들어와 엔도좀 내부가 산성화(Acidification)되고, 이어서 바이러스 외피에 있는 M2 이온 채널을 통해 양성자(H⁺)가 바이러스 입자 내부로 한 번 더 들어옵니다. 이렇게 바이러스 내부가 산성화되어야 바이러스 RNP(중합효소 복합체 + RNA 유전체)와 결합해 있던 NP(뉴클레오캡시드 단백질) 등이 분리되면서 바이러스 유전체(Genome)가 세포질로 방출(Release/Uncoating)될 수 있습니다. 아만타딘과 리만타딘은 바로 이 M2 이온 채널을 통한 양성자(H⁺) 이동을 차단하여 바이러스 유전체가 세포질로 방출되는 것을 막습니다.
   - 현재 사용 여부: 최근 10여 년 동안 유행하는 모든 인플루엔자 바이러스가 아만타딘과 리만타딘에 대해 내성(Resistance)을 가지고 있어서, WHO에서 더 이상 쓰지 말라고 권고하여 현재 임상적으로는 사용하지 않습니다.

**[39:16 ~ 44:17] 신규 항바이러스제 4종의 세부 타겟 기전 (출제 유력 포인트)**
오셀타미비르(타미플루)에 대한 내성 문제에 대비해 제약사들이 추가 상용화한 약물들이며, 교재에도 언급되어 있어 시험 문제를 꼬아낼 때 기전과 약물명을 매칭하는 문제로 출제될 가능성이 매우 높습니다.
1. 발록사비르 (Baloxavir) - PA (Cap-dependent endonuclease) 억제제:
   - 기전 (Cap snatching 억제): 진핵세포(숙주 세포)의 mRNA는 5' 말단에 캡(5'-Cap) 구조가 있고 3' 말단에 Poly(A) 꼬리가 있습니다. 인플루엔자 바이러스도 자신의 단백질을 번역(Translation)하려면 이 5'-Cap이 필요한데 스스로 만들지 못해서 숙주 mRNA의 캡을 훔쳐 옵니다. 이를 캡 스내칭(Cap snatching)이라고 합니다.
   - 이때 중합효소 복합체(PB2, PB1, PA) 중에서 PB2는 숙주의 5'-Cap을 인지(결합)하는 역할을 하고, PA는 캡으로부터 안쪽으로 10~13 뉴클레오타이드(nt) 길이를 딱 끊어내는 엔도뉴클레아제(Endonuclease) 활성을 가집니다.
   - 발록사비르(Baloxavir)는 바로 이 PA의 엔도뉴클레아제(Endonuclease) 활성을 블로킹하여 캡 스내칭(전사 개시)을 억제하는 약물입니다.
2. 파비피라비르 (Favipiravir) - RdRp (PB1) 억제제:
   - 기전: 표에는 타겟이 RdRp(RNA-dependent RNA polymerase, RNA 의존성 RNA 중합효소)로 되어 있는데, 인플루엔자의 중합효소 복합체(PB2, PB1, PA) 중에서 실제로 RNA 사슬을 중합(Polymerase)하는 메이저 효소 기능을 가진 것은 PB1입니다. 즉, 파비피라비르는 PB1(RdRp)의 RNA 중합 기능을 블로킹하는 약물입니다.
3. 잉가비린 (Ingavirin) - NP (Nucleoprotein) 억제제:
   - 기전: 5번 분절이 암호화하는 NP(Nucleoprotein, 핵단백질)는 불안정한 단일가닥(Single-strand) RNA 유전체에 결합하여 바이러스 RNA를 안정화시키는 단백질입니다. 잉가비린은 이 NP를 블로킹하여 NP가 RNA에 결합하지 못하게 함으로써 바이러스 RNA 자체를 불안정하게 만드는 기전을 가집니다.
4. 우미페노비르 (Umifenovir) - HA2 (Membrane fusion) 억제제:
   - 기전: 헤마글루티닌 전구체(HA0)는 절단되어 HA1과 HA2 두 부분으로 나뉩니다. 여기서 HA1은 숙주 세포의 시알산(Sialic acid) 수용체와 결합하는 부위이고, HA2는 바이러스 외피에 박혀 있다가 숙주 세포막(엔도좀 막)과 바이러스 외피(Envelope)가 서로 융합하도록 만드는 막 융합 단백질(Membrane fusion protein) 역할을 합니다. 우미페노비르는 바로 이 HA2에 의한 막 융합(Membrane fusion) 과정을 블로킹하는 약물입니다.
