### 1. 녹농균(*Pseudomonas aeruginosa*)과 아미노페니실린의 한계 (슬라이드 (1) 13쪽)
- 아미노페니실린: 아미노기 → 수용성↑ → 포린 통과 → 그람 음성 스펙트럼 확대. **하지만 녹농균에는 효과가 떨어짐**
- 항생제 내성 대표 세균 2개(**ESKAPE** 멤버이기도 함): **녹농균(*Pseudomonas*)**, **장알균(*Enterococcus*)** → 항생제 파트에서 계속 등장
- 녹농균이 β-락탐에 잘 안 듣는 이유 (여러 요인이 겹침)

| 이유 | 내용 |
|---|---|
| **포린 투과성 낮음** | 그람 음성균 포린 중에서도 녹농균 포린이 특히 투과성이 낮음 |
| **유도성 내성(inducible resistance)** | 안 만들던 β-락타메이스를 만들게 됨 / 효소로 항생물질을 변형(modification)해 활성↓ |
| **PBP 친화성 낮음** | 녹농균·장알균의 PBP는 β-락탐에 대한 친화성이 다른 세균보다 낮음 |
| **유출 펌프(efflux pump)** 🎯 | 항생물질이 **표적에 작용하기 전에 세포 밖으로 내보내는** 펌프. 많은 세균이 갖지만 **녹농균이 특히 활성 높음** (슬라이드에 밑줄) |

- 녹농균 특성: **병원감염균(nosocomial)** + **기회감염균(opportunistic)**, 기저질환 입원 환자 → 전신 염증 → **패혈증(sepsis)**(균혈증 → 여러 장기 염증)의 대표 원인균, **다제내성(MDR)** 대표
- 아미노페니실린은 여전히 **β-락타메이스에 약함** → **PRSA·MRSA에 잘 안 들음**

### 2. 항녹농균 페니실린 (antipseudomonal penicillins, 슬라이드 (1) 14쪽) ★

| 그룹 | 약 | 이름 유래 (구조) |
|---|---|---|
| **카복시페니실린** (카복실기 -COOH) | **카베니실린** | **카복실기** + 페니실린 |
| | **티카실린** | **티오펜**(S 포함, **불포화** 5원환) + 카복실기 + 페니실린 |
| **우레이도페니실린** (우레이도기) | **아즐로실린** | **아졸**(N 2개 5원환 = 다이아졸에서 '아졸'만) + 페니실린 |
| | **메즐로실린** | **메틸설포닐**(CH₃-SO₂-) + 아졸 + 페니실린 |
| | **피페라실린** | **피페라진**(N 2개, **포화** 6원환) + 페니실린 |

- 녹농균에 듣는 이유 (교수님 설명): 카복실기·우레이도기를 붙이면
  1. 녹농균 **PBP에 대한 친화성↑**
  2. 전하(charge)를 띠어서 녹농균 **포린 투과↑**
  - ※ efflux pump를 막아 주는 건 **아님** [23:51]
- 하지만 여전히 **β-락타메이스에 약함** (β-락타메이스를 만드는 세균엔 잘 안 들음)

**구조 문제 대비 — 고리 이름 규칙**

| 이름 | 뜻 |
|---|---|
| **티아졸리딘** | S + N, **포화 5원환** (페니실린 옆 고리) |
| **페남(penam)** | **β-락탐 + 티아졸리딘** = 페니실린 핵심 구조 (*Penicillium* + **-am** = 포화) |
| 페넴(penem) | 5원환에 이중결합이 있으면 |
| **티오펜** | S 포함, **불포화**(이중결합) 5원환 → 티카실린 |
| **아졸** | N 포함 5원환 (+ N·S·O 중 하나 더). N 3개 = 트라이아졸, N 4개 = 테트라졸 |
| **피페라진** | N 2개, **포화 6원환** → 피페라실린 |
| **아진(azine)** | N 포함 **6원환** |
| **티아진** | S + N **6원환** |

### 3. β-락타메이스 억제제 (슬라이드 (1) 15~16쪽)
- 정의: **β-락탐 고리는 있지만 항균 활성은 (거의) 없음** → β-락탐 구조를 **흉내(mimic)**
- β-락타메이스가 억제제와 **비가역적으로 결합** → β-락탐 항생제 대신 싸워 줌 ("나 대신 싸우는 애")
- β-락탐 항생제와 **병용(조합)** — 아무 조합이 아니라 **특정 조합**에서 시너지가 가장 높음 → 그 조합으로 시판

| 억제제 | 짝 항생제 (괄호는 상품명, 교수님: "흐리게 해 놓은 건 브랜드 네임") | 이름 유래 |
|---|---|---|
| **설박탐** | **암피실린** (Unasyn) | **설포닐기** + 박탐(=β-락탐) |
| **타조박탐** | **피페라실린** (Zosyn) | **트라이아졸**(N 3개 5원환) + 박탐 |
| **클라불라네이트** (클라불란산) | **아목시실린** (Augmentin) 또는 **티카실린** (Timentin) | 구조 아님 → ***Streptomyces clavuligerus***(방선균)의 대사산물이라서 |

- **활성을 회복(restore)시킬 뿐, 새로 더해 주지 않음** 🎯
  - 예: 원래 10 → β-락타메이스 때문에 5 → 억제제 병용 → 다시 10
  - 원래 녹농균에 안 듣는 항생제는 억제제를 써도 녹농균에 안 들음
- 모든 β-락타메이스를 다 막지는 못함 → 세균은 계속 돌연변이 → 새 억제제 계속 개발 중

### 4. 세팔로스포린 도입 (슬라이드 (2) 2~3쪽)
- 분류 복습: 세포벽 합성 저해제 = β-락탐 / 비β-락탐 → β-락탐 = **클래시컬**(페니실린 + **세팔로스포린**) / 논클래시컬
- 페니실린 계열 = "**페남** 계열"이라고 부르기도 함

| | 페니실린 | 세팔로스포린 |
|---|---|---|
| 핵심 구조 | **페남** = β-락탐 + **티아졸리딘**(포화 5원환) | **세펨(cephem)** = β-락탐 + **다이하이드로티아진**(S+N **6원환**, 이중결합 1개) |
| 이름 | *Penicillium* + **-am**(포화) | *Cephalosporium* + **-em**(이중결합 1개) |
| 생산 곰팡이 | *Penicillium* (자낭균류) | ***Cephalosporium*(옛 이름) = *Acremonium*(지금 이름)** (자낭균류) |

- 다이하이드로티아진: **1,3-티아진**(이중결합 2개)이 β-락탐과 융합되며 이중결합 1개를 잃고 수소 2개(dihydro)가 붙음
- **천연 세팔로스포린 3개: 세팔로스포린 P, N, C** → 이를 바탕으로 반합성한 게 **1~5세대**
- **세대 구분 기준 = 스펙트럼**. 1~3세대는 거의 개발 끝, 4·5세대는 진행 중
- **세파마이신(cephamycin)** = 2세대 중 특정 세펨류 (자세한 건 다음에)

**세팔로스포린 공통 특징** (슬라이드 (2) 3쪽)
- 페니실린과 **교차 알레르기(cross-allergenicity) < 10%** → 페니실린 알레르기 10명 중 1명은 세팔로스포린에도 반응 가능
- 페니실린보다 **β-락타메이스에 더 강함**(덜 깨짐) → 병원에서 많이 처방되는 이유 중 하나
- **장알균(enterococci)엔 거의 무효 (일부 예외)**
