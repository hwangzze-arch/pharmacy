## 시험 대비 핵심 정리

### ⭐ 교수님 출제 힌트
- HIV 기회감염 질병은 **각 질병 슬라이드에 있는 것 + 앞 슬라이드 수준**만 기말 (뒤 큰 표는 국시용)
- 칵테일 요법 조합을 고르라는 **국시 기출**이 있었음 (교수님도 조합은 외우기 어렵다 하심)
- 교수님: "**내가 국시 출제 들어가면 우리 수업한 것만 낸다**" → 수업에서 집어준 대표 약물 위주

### 1. 항-HIV 치료제 (5그룹) + 약물 접미사 규칙

| 그룹 | 작용 | 대표 약 |
|---|---|---|
| **NRTI** (뉴클레오사이드+RT억제) | 역전사 억제 | **AZT(=지도부딘=Retrovir)**, **라미부딘(3TC)**, **테노포비어** |
| **NNRTI** (논뉴클레오사이드+RT억제) | 역전사 억제 | (대표 딱히 없음) |
| **PI** (프로테이스 억제) | 단백질 절단 억제 | **리토나비어**, **로피나비어** |
| **부착/융합 억제** | gp120 결합·gp41 융합 억제 | — |
| **인테그레이스 억제** | 통합 억제 | — |

- **접미사 규칙(중요)**: **-부딘(-vudine) = 뉴클레오사이드 아날로그** / **-포비어(-fovir) = 뉴클레오타이드 아날로그**
- **리토나비어 = 듀얼 기능**: 원래 HIV PI, 팍스로비드(=니르마트렐비르+리토나비어, 코로나19약)에선 **PK 인핸서**로 **CYP3A4 억제** → 약물이 간에서 빨리 대사돼 빠져나가는 걸 막아 약효 지속
- **로피나비어**: 2002~03 **사스(SARS)** 때 언급된 PI
- HIV 트로피즘 용어: 옛 M-tropic/T-tropic → 지금은 **보조수용체 기준 R5-tropic(CCR5) / X4-tropic(CXCR4)**
- HIV 치료제는 아직 완치 불가 → **칵테일 요법(기전 다른 약 혼합)**

### 2. 그룹7 — B형 간염 바이러스 (HBV, Hepadnaviridae)
- 과명 **Hepadna** = **hepa**(간) + **dna**(DNA 지놈) → 그룹6(레트로)과 달리 **DNA 바이러스**지만 **역전사함**
- **외피 O**, **정이십면체 캡시드**
- **데인 입자(Dane particle)** = 캡시드+지놈 있는 **완전체, 감염성 O** / **HBsAg 입자** = 껍데기만, 지놈 없음 = **감염성 X** → "쭉정이" → **백신 항원으로 사용**(과거 보균자 혈액에서 분리 → 현재 재조합 단백질)
- **HBV의 DNA 폴리머레이스 자체가 역전사 활성 보유** ("샴푸+린스 올인원"). 레트로는 RT가 별도 효소
- 지놈 = **부분 이중가닥 원형 DNA (partially dsDNA)**: 전장(full-length) 가닥 = **(−)sense**, 상보 가닥 = **(+)sense가 50~60%만** 커버(나머지 40~50% 단일가닥)
- 복제: (−)DNA → **(+) pregenomic RNA**(= mRNA 역할) → **역전사** → (−)DNA → (+)DNA 일부 → 다시 부분 dsDNA 지놈
  - 역전사하므로 **항-HIV 역전사효소 억제제가 HBV에도 적용됨**
- 만성화율: **성인 5~10% < 소아 30~50% < 영아 80~90%** (어릴수록 면역 미성숙 → 만성↑)
- 급성엔 치료제 없음, 노출 1주 내·신생아엔 **면역글로불린(항체)** 효과
- **만성 B형 간염 치료제 5종**: 라미부딘 → 아데포비어 → 텔비부딘 → 엔테카비어 → 테노포비어

| 약 | 종류 | 현황 |
|---|---|---|
| 라미부딘 (lamivudine) | 뉴클레오사이드 | 옛 표준, 내성으로 안 씀 |
| 아데포비어 (adefovir) | 뉴클레오타이드 | **신독성(nephrotoxicity)**으로 안 씀 |
| 텔비부딘 (telbivudine) | 뉴클레오사이드 | 내성으로 안 씀 |
| **엔테카비어 (entecavir)** | 뉴클레오사이드 | **현재 표준** |
| **테노포비어 (tenofovir)** | 뉴클레오타이드 | **현재 표준** |

- ⭐ **HIV와 B형 간염 둘 다** 임상 적응증 = **라미부딘 + 테노포비어** ("라테") / 나머지는 HBV만
- (팜시클로비어는 **빼라**고 하심)

### 3. 항생제 개론 — 작용 기전 5분류 (교수님 순서)
1. **세포벽 합성 저해 (cell wall synthesis inhibitor)**
2. **세포막 기능 파괴 (cell membrane function)**
3. **단백질 합성 저해 (protein synthesis)**
4. **핵산 합성 저해 (nucleic acid synthesis)**
5. **항대사물질 (antimetabolite)**
- 교과서는 구조 기준이지만 **교수님은 작용 기전 순서로** 진행 (①부터)

### 4. 세포벽 합성 저해제 → 베타-락탐
- 세포벽 저해제 = **베타-락탐 vs 비(非)베타-락탐**
- **락탐 화학 정의** (유기화학 연결)
  - **에스터** = 산 + 알코올 (물 빠짐), -COO-
  - **락톤(lactone)** = **고리형 에스터(cyclic ester)**
  - **락탐(lactam)** = **락톤의 질소 유사체** = **고리형 아마이드(cyclic amide)**: 에스터의 O가 **N으로 치환**(-CONH-, 카보닐+질소=아마이드)
  - 고리 크기별: 삼각형=**α-락탐**, **사각형=β-락탐**, 오각형=γ-락탐, 육각형=δ-락탐

| 베타-락탐 | 2차 고리 | 예 |
|---|---|---|
| **클래시컬** | 페니실린=**오각형** / 세팔로스포린=**육각형** | -cillin, cef-/ceph- |
| **논클래시컬** | 베타-락탐만/약간 변형 | **카바페넴(-penem), 모노박탐** |

- **명명법**: 끝 **-실린(-cillin)·-페넴(-penem)**, 앞 **세프(cef-/ceph-)** (전부는 아님)
- **작용기전 = 세포벽 합성 저해, 엄밀히는 교차결합(cross-linking) 저해**
  - 펩티도글리칸 = **NAM + NAG** 이당류, 둘은 **글리코시딕 결합**. NAM에 **펜타펩타이드** → 층간 **교차결합**으로 겹겹이 쌓임
  - **PBP(페니실린 결합 단백질)**: 2도메인 — **TG(트랜스글리코실레이즈)**=글리코시딕 결합 / **TP(트랜스펩티데이즈)**=교차결합
  - **페니실린은 TP 도메인에 결합 → 교차결합 저해** (PBP 종류에 따라 TG·TP 둘 다 or TP만)
- **내성 기전**: ① **베타-락타메이즈(β-lactamase)**로 베타-락탐 링 파괴 → 항균력 상실 ② **PBP 변형/신규 생성** ③ 펌프 배출 등
- (참고) **tabtoxinine-β-lactam** = 베타-락탐 링은 있지만 **항생제 아님**, 식물 독소(글루타민 합성효소 억제)

### 한 줄 암기
- -부딘=뉴클레오사이드 / -포비어=뉴클레오타이드
- HIV+HBV 겸용 = **라테(라미부딘·테노포비어)** / HBV 현재 표준 = **엔테카비어·테노포비어**
- 데인 입자=감염성 O / HBsAg=감염성 X(백신)
- HBV = DNA지만 역전사 / 부분 dsDNA / 영아 만성 80~90%
- 항생제 5기전: 세포벽·세포막·단백질·핵산·항대사
- 락탐 = 고리형 아마이드, β=사각형 / 클래시컬=페니실린(5각)·세팔로(6각), 논클래시컬=카바페넴·모노박탐
- 베타-락탐 = 교차결합(TP) 저해 / 내성 = β-락타메이즈, PBP 변형

- 23:43 **팜시클로비어는 빼기**. **아데포비어(-포비어=뉴클레오타이드)**.
