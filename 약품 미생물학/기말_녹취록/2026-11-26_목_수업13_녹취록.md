### 1. 50S 저해제 공통 — 클로람페니콜 기전 (슬라이드 (4) 13쪽)
- 30S 저해제(아미노글리코사이드·테트라사이클린)는 **30S의 16S rRNA**에 붙어 50S 결합을 막음
- 50S 저해제는 **50S의 23S rRNA**에 붙어 **펩티딜 전달효소(펩타이드 결합 형성, rRNA가 효소)를 억제** → 폴리펩타이드 X
- 부수: **펩티딜 tRNA가 너무 일찍 떨어짐(premature dissociation)**, 리보솜 이동(translocation) 방해
- **내성** (30S 저해제와 대동소이): ① 표적(50S rRNA) 변형 ② **효소로 약 변형**(클로람페니콜 아세틸전달효소) ③ 유입 감소 — 클로람페니콜은 **단순 확산**으로 들어오므로 막 조성을 바꿔 유입↓

### 2. 매크롤라이드 (50S, 슬라이드 (4) 14~18쪽)

| 항목 | 내용 |
|---|---|
| 이름 | **macro(큰) + lactone(고리형 에스터)** = 큰 락톤 고리 |
| 구조 | 큰 **락톤 고리** + **디옥시당(deoxy sugar)** 1개 이상 (에리스로마이신은 당 2개) |
| 천연 | **에리스로마이신** ← ***Streptomyces*** (*S. erythreus*: erythr- = 빨강, 집락이 붉어서) |
| 반합성 | **클래리스로마이신 · 디리스로마이신 · 아지스로마이신 · 스피라마이신 · 조사마이신** |
| 이름 규칙 | 대부분 **-thromycin** / 예외: **스피라마이신**(나선형 방사) · **조사마이신**(일본 지명) |
| 케톨라이드 | 에리스로마이신 유도체: 아래쪽 당(**클라디노스**)을 **케토기**로 바꿈 → **텔리스로마이신** |
| 스펙트럼 | **페니실린과 비슷하되 그람(−) 쪽으로 약간 더 넓음**(moderate) |
| 쓰임 🎯 | **호흡기 감염**(*S. pneumoniae* 등), **외래 환자** 처방에 자주 |
| 정균/살균 | **정균** (STT LCM의 M) |
| 부작용 | **위장관**(설사 등) · **간독성** · **심독성(QT 간격 연장)** |
| 내성 | 많이 써서 **폐렴구균(*S. pneumoniae*) 내성↑** / 주로 **23S rRNA의 전사 후 메틸화**(신경 안 써도 됨) |

- 전사 후 변형(참고): 리보스 메틸화 · 사이토신 5번 메틸화 · **슈도유리딜화**(유라실 3·6번 축 회전)

### 3. 링코사마이드 (50S, 슬라이드 (4) 19~20쪽)

| 항목 | 내용 |
|---|---|
| 이름 | **링코마이신**(Lincoln) + **아마이드** |
| 천연 | **링코마이신** ← ***Streptomyces*** (*S. lincolnensis*: 미국 네브래스카 **링컨** 시에서 분리) — 지금은 주로 **동물** 감염에 |
| 반합성 | **클린다마이신** = **Cl** + 링코마이신 (OH 대신 Cl) — 장 흡수↑, 독성↓, **사람에게 주로** |
| 스펙트럼 | 매크롤라이드와 비슷(그람(+) + 일부 그람(−)) |

| 부작용 | **가벼움**: 설사 · 피부 발진 |
| 기전·내성 | 매크롤라이드와 같음 |
