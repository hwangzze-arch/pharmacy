## 시험 대비 핵심 정리 (녹취록에서 뽑음)

### 교수님 공지·출제 관련
- 다음 시험 전까지 진도를 쭉 뺄 예정 (바이러스 빨리 끝내고 항생제)
- 이번 범위에서 볼 패밀리: **파라믹소, 오르토믹소, 번야, (랍도)** → 슬라이드에서 진하게 표시된 것 위주
- **필로(에볼라)·아레나(출혈열)** 는 올해는 안 하고 내년부터 포함 예정. 교과서 개정판에 일부 들어가 있으니 "한번 쭉 읽어보면 충분" (국시 문제은행에는 없는 걸로 기억)
- **분류 개정**: 서브패밀리 Pneumovirinae → **패밀리 Pneumoviridae로 승격**(뉴모 = 폐렴을 잘 일으킴). 새 서브패밀리 이름(Avulavirinae, Orthoparamyxovirinae, Metaparamyxovirinae, Rubulavirinae)은 **외울 필요 없음**
- 시험엔 **옛날 이름을 병기**하는 게 관례 → 옛 이름(Rubulavirus, Morbillivirus, Respirovirus 등)으로 기억해도 됨. 바이러스 **이름**을 기억할 것
- NDV는 국시 출제 가능성 "거의 제로"지만 상식으로 기억

### 용어
- **myxo = mucus(점액)** → 점막으로 된 호흡기 → 믹소바이러스 = 호흡기 바이러스
- **ortho = standard(표준)**: 오르토믹소(인플루엔자) = 호흡기 감염의 표준 그룹 / **para = beyond(옆, 다른)**: 파라믹소 = 비슷하지만 다른 그룹
- 파라믹소는 모두 **외피(enveloped)**

### 뉴캐슬병 바이러스 (NDV)
- **조류** 바이러스, 자연숙주 = **야생 철새** (철새 분변에서 가장 많이 분리, 그다음 인플루엔자)
- **가금류**(닭·집오리)에서 고병원성: **치사율 90%** (고병원성 조류독감 H5N1은 가금류 ~100%)
- 증상: 호흡기 + **신경 증상**(보행장애 ataxia, 발작, 고개가 뒤로 젖혀짐) → 고병원성 조류독감과 매우 비슷
- **1926년 영국 뉴캐슬**에서 처음 분리
- 조류독감과 구별점: **인수공통이지만 사람에선 가벼운 결막염·독감 유사 증상** (H5N1은 사람 치사율 50~60%)
- 백신: **사람용 없음, 가금류용 있음** / 치료제 없음 (생물무기·항암제 이야기는 무시해도 됨)

### 헨니파바이러스 (Hendra + Nipah = Henipa)
- 영화 「컨테이전(2011)」의 소재 = **니파**
- **자연숙주 = 박쥐(과일박쥐)** / **중간숙주: 니파 = 돼지, 헨드라 = 말**
- 전파: **호흡기**(코로나처럼) + **중추신경 침습** → 호흡기 증상 + 구토(위장관) → **뇌염**(헨드라는 뇌염·수막염)으로 사망
- 니파 **평균 치명률 74.5% (최대 100%)**, 말레이시아·싱가포르 등 **동남아** / 헨드라는 사례 적고 **호주**
- 니파 별명: **mile cough**(1마일 밖에서도 들리는 기침), **barking pig syndrome**(돼지가 짖듯 기침)
- **BSL-4**(생물안전 4등급) 바이러스, 국내 BSL-4는 질병관리청에만 있고 본격 가동 전
- **백신·치료제 없음**, 호흡기 전파 → 유행 시 매우 위험

### 홍역 (Measles virus, 옛 genus Morbillivirus; morbilli = measles)
- **기초감염재생산수 R0 = 12~18** → 알려진 바이러스 중 **가장 전파력이 강함** (인플루엔자 R0는 녹취상 "12"로 들리나 오인식 가능성, 코로나19 초기 2~3)
- **공기 전파(에어로졸·비말핵, airborne)** → 2 m 거리두기에 해당 안 됨, 수십 m까지 퍼짐
  - 비말 = 침방울(약 2 m 낙하) / 비말핵 = 아주 작은 입자로 공기 흐름을 타고 이동
- 제1병 = 홍역 (제5병 = 전염성 홍반, 앞 파보바이러스 파트와 연결)
- 증상: 호흡기 → **전신 발진(measles rash: maculopapular, erythematous = 반구진성, 홍반성)**
- **Koplik spot**: 발진 **2~3일 전** 입 안에 **푸른빛 도는 흰 점** → 임상 진단에 사용 (1800년대 말 Koplik이 보고)
- 합병증: 눈 감염 → **실명**, **폐렴(사망 원인으로 많음)**, **뇌염**
- 주로 어린이, 단 어릴 때 감염·백신 없이 **성인이 되어 걸리면 더 심함** (A형 간염도 같은 특성)
- 치사율 **3~6%**(백신 덕분에 낮아진 값, 백신 전엔 25~50%로 추정)
- **치료제 없음 / MMR 백신(홍역·볼거리·풍진, 3가 약독화 생백신)**. 세균의 3가 백신 = DTP와 비교
- 대학 1~2학년(약 20세)에 **항체가가 떨어져** 집단생활 중 유행 → 이 연령에 추가 접종 주장도 있음

### 사람 파라인플루엔자 바이러스 (hPIV) 1~4형
- **인플루엔자가 아님!** 증상이 비슷해서 붙은 이름. **감기(common cold) 바이러스** 중 하나
- 유전적으로 **1·3형 = Respirovirus**, **2·4형 = Rubulavirus** (홀수/짝수로 기억)
- 임상적으로 묶으면:
  - **1형 = 크룹(croup)의 대표 원인** (심한 기침 → 호흡곤란)
  - **2형 = 크룹 + 상·하기도 감염**
  - **3형 = 세기관지염(bronchiolitis, 쌕쌕거리는 호흡) + 폐렴** (RSV도 세기관지염을 일으킴)
  - **4형 = 경미한 호흡기 증상, 드묾**
- 주로 어린이 / **백신·치료제 없음** (감기 바이러스는 수지타산이 안 맞아 개발 안 함)
- 센다이 바이러스(쥐 파라인플루엔자 1형)는 **몰라도 됨**

### 볼거리 (Mumps virus, 옛 genus Rubulavirus; 현재 mumps orthorubulavirus)
- **이하선염** = 귀밑샘(parotid gland)의 염증. 침샘 3개(이하선·설하선·악하선) 중 침을 가장 많이 분비하는 게 이하선
- 전파: **호흡기** → 가벼운 호흡기 증상 → **이하선 부종**
- 합병증: **수막염·뇌염, 고환염(orchitis, 남아), 청력장애(난청), 임신 초기 초감염 시 자연유산**
- **이환율(morbidity)은 높고 치사율(mortality)은 0.001%로 매우 낮음** → "아프긴 한데 죽진 않는다"
- **R0 = 5~7**
- 치료제 없음(대증·보존 치료), **MMR 백신**
- 옛 이름 "**항아리 손님**" (부어오른 모양이 항아리 같아서)

### 뉴모바이러스과 (Pneumoviridae, 승격): 사람 RSV · 메타뉴모바이러스
- 둘은 **쌍둥이처럼 비슷**. 메타뉴모는 **2001년 네덜란드**에서 처음 인지 → 그 전엔 모두 RSV로 여겨짐
- 넓게 보면 감기 바이러스지만 **영유아(특히 생후 2~3개월 ~ 돌)와 65세 이상 노인**에서 **세기관지염·폐렴**을 잘 일으킴
- **syncytial = 세포융합(syncytia)**: 여러 숙주세포가 하나로 합쳐 핵이 여러 개인 거대세포 → RSV의 전형적 **CPE**(세포변성효과)
- **백신 없음**
- 치료제: **리바비린(ribavirin)** — 뉴클레오사이드 유사체
  - 공식 적응증 = **RSV와 C형 간염(HCV)** (+일부 출혈열 바이러스: 라싸 등, 한타에도 효과가 있다고 알려짐)
  - 중증 RSV(심한 기관지 폐렴)에 **흡입** 형태로 사용
- 예방: **팔리비주맙(palivizumab)** 등 **항체 치료제를 예방 목적**으로 사용 (산후조리원 유행 시 등). 단, 일반적 의미의 **백신은 없음**

### 암기 포인트 한 줄씩
- 자연숙주: NDV = 야생 철새 / 니파·헨드라 = 박쥐 (중간숙주 돼지·말)
- 사람 백신: NDV ✕(가금류용 ○) / 니파 ✕ / 홍역 ○(MMR) / hPIV ✕ / 볼거리 ○(MMR) / RSV ✕(예방 항체 팔리비주맙)
- 치료제: RSV만 ○(리바비린), 나머지 ✕
- R0: 홍역 12~18(최고) > 볼거리 5~7 > 코로나19 초기 2~3
- 크룹 = hPIV 1(·2) / 세기관지염 = hPIV 3 · RSV
