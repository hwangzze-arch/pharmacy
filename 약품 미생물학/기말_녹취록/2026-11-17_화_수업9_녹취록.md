### 4. 논클래시컬 β-락탐: 카바페넴 (슬라이드 (3) 2~4쪽)
- 클래시컬 = 페니실린 + 세팔로스포린 / **논클래시컬 = 카바페넴 · 모노박탐**
- 이름: **carba = C**(1번 S가 **C로 치환**) + **penem**(5원환에 **이중결합 1개**)
- 핵심 구조 = **β-락탐 + 피롤린(pyrroline)**: N 1개 + 이중결합 1개 5원환, **S 없음**
- 옆 고리가 β-락탐을 보호 → **대부분의 β-락타메이스에 강함**
- **천연 카바페넴 = 티에나마이신(thienamycin)** ← ***Streptomyces cattleya*** (방선균) 🎯
  - **방선균(actinomycetes)** = 가지처럼 뻗어 자라는 균 통칭 ≠ 그람 양성 속 *Actinomyces* (헷갈리지 말 것)
  - 티에나 = 끊어진 **티오펜** 모양 + -mycin(항생물질)
- **broad spectrum**: 구조가 **콤팩트(작음)** → 그람(−) **포린 통과 쉬움** → 그람 +/− 모두, **녹농균·장알균 O**, **MRSA X**
- 반합성: **이미페넴 · 메로페넴 · 얼타페넴 · 도리페넴 · 파니페넴 · 비아페넴** → 모두 **-penem**
- **이미페넴 + 실라스타틴(cilastatin) 반드시 병용**: 이미페넴이 신장의 **dihydropeptidase**에 가수분해 → **신독성** 대사산물 → 실라스타틴 = 그 효소 억제제
- **얼타페넴**: broad지만 **녹농균·장알균 X**. 장점 = **하루 1회** 투여(PK 좋음). 근육주사 시 통증 → **리도카인**(국소마취제)과 함께
- 부작용: β-락탐과 비슷 / 페니실린과 **교차 과민반응 1~50%** (세팔로스포린 <10%보다 높음)
