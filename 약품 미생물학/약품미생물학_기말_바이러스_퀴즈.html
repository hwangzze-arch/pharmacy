이 자료 공부법: 읽지 말고 풀어라

읽기만 하면 왜 안 되나

  • 여러 번 읽으면 글자가 익숙해져서 '아는 것 같은 착각'이 든다. 정작 보기를 가리면 안 떠오름
  • 시험은 보기 ①~⑪를 주고 떠올려 고르는 형식. 읽기로는 이 능력이 안 길러짐
  • 중간 7/45는 몰라서가 아니라 인출(떠올리기) 연습이 부족했을 가능성이 큼

그래서 이렇게: 인출 연습 3단계

  • 손으로 푼다. 해설은 가리고, 보기에서 지정 개수만큼 직접 골라 답한다. (눈으로만 X)
  • 바로 채점. 맞은 것·틀린 것을 표시. 틀린 건 왜 틀렸는지 해설을 한 줄로 읽는다.
  • 틀린 것만 다시. 맞은 문제는 넘기고, 틀린 문항만 다음 회독에서 다시 푼다. 3번 연속 맞으면 졸업.

읽기 2~3회독보다 세트 7개를 풀고 → 채점 → 틀린 것만 다시 돌리는 게 점수에 직결된다. 아래 실전 세트가 회독과 연속 정답을 자동으로 기록해 줘요.

01 · V-1 · Paramyxo · Pneumo

파라믹소바이러스과 · 뉴모(RSV)

파라믹소바이러스과 공통

  • myxo=점액(호흡기), para=beyond(오르토믹소 옆 다른 그룹)
  • 외피 O, 비분절 (−)ssRNA (← 인플루엔자는 분절!)
  • 분류 개정: 서브패밀리 Pneumovirinae → 패밀리 Pneumoviridae로 승격 (뉴모=폐렴)
  • 새 서브패밀리 이름(Avula-, Ortho-, Meta-, Rubula-)은 외울 필요 없음 → 바이러스 '이름'을 외우기
  • 옛 속↔바이러스: Morbilli=홍역, Rubula=볼거리·파라인플루 2·4, Respiro=파라인플루 1·3

뉴캐슬병 바이러스 (NDV): 국시 가능성 거의 0, 상식

  • 자연숙주 = 야생 철새 (철새 분변에서 가장 많이 분리, 그다음 인플루엔자)
  • 가금류에서 치사율 90% (고병원성 조류독감 H5N1은 ~100%)
  • 증상: 호흡기 + 신경(보행장애·발작·고개 젖힘) → 고병원성 AI와 유사
  • 1926년 영국 뉴캐슬에서 분리
  • 인수공통이나 사람은 가벼운 결막염·독감 유사 (H5N1 사람 치사율 50~60%와 대비)
  • 백신: 사람용 X, 가금류용 O / 치료제 X

헨니파(니파·헨드라) · 홍역 · 파라인플루엔자 · 볼거리

바이러스숙주·전파핵심 증상백신치료제
니파 (헨니파)자연숙주 박쥐 → 중간숙주 돼지 → 사람, 호흡기뇌염(치명률 74.5%, 최대 100%), 동남아, BSL-4, 별명 'barking pig'XX
헨드라 (헨니파)박쥐 → 중간숙주 말 → 사람, 호흡기뇌염·수막염(~70%), 호주XX

홍역 꼭 기억

  • 어릴 때 안 걸리고 성인이 처음 걸리면 더 심함 녹취 (A형 간염과 같은 특성)
  • 치사율 3~6%(백신 전 25~50%)
  • 대학 1~2학년 항체 저하 → 집단생활 중 유행

MMR = 3가지 (모두 생백신)

  • Measles 홍역(파라믹소)
  • Mumps 볼거리(파라믹소)
  • Rubella 풍진(토가, 중간범위)

RSV / 메타뉴모: 쌍둥이 (뉴모바이러스과)

  • 둘 다 넓게 보면 감기 바이러스, 영유아(생후 2~3개월~돌)·65세↑에서 세기관지염·폐렴
  • 메타뉴모는 2001 네덜란드에서 첫 인지 → 그 전엔 다 RSV로 봄
  • syncytial=세포융합(syncytia): F 단백질로 숙주세포 융합 → 거대세포 = 전형적 CPE
  • 백신 없음

리바비린 (ribavirin) 녹취

  • 뉴클레오사이드 유사체
  • 공식 적응증 = RSV + C형 간염(HCV) (+ 일부 출혈열: 라싸, 한타는 효과 보고)
  • 중증 RSV(심한 기관지폐렴)엔 흡입 형태 사용
  • 보기에 리바비린 대상으로 한타바이러스 있으면 맞는 것으로 녹취 출제

RSV 예방 = 팔리비주맙(palivizumab) 등 항체(예방 목적) · 치료 = 리바비린 · 백신은 없음

02 · V-2 · Rhabdo · Bunya

랍도(광견병) · 번야(한타)

광견병 (Rhabdoviridae) 출제 국시 빈출

  • rhabdo=막대 → 총알 모양, 캡시드 나선형(정이십면체 아님), 외피 O
  • 신경친화성: 중추신경계 복제. 감염동물 침(물림)으로 전파(인수공통)
  • 임상 2형: 광폭형(대뇌변연계) / 마비형(신피질)
  • 초기 flu-like(인플루엔자 '유사', 인플루엔자 아님!) 녹취 출제 → 공포→공수병, 환각·마비
  • 진단: Negri 소체(감염세포 세포질 봉입체)
  • 잠복기 ~4주로 길어, 물린 뒤 백신이 치료가 됨 녹취 출제 (백신 후 항체 1주 80~90%, 2주 최대) · 사백신, 치료제 X(면역글로불린만)

한타바이러스 (Bunyaviridae → Hantaviridae)

  • 분절 암기 ABO(Arena·Bunya·Ortho) 녹취, 번야=3분절(L·M·S). 대문자 B에서 기둥 빼면 3
  • 매개체=절지동물 또는 설치류 / 한타 자연숙주=매개체 = 등줄쥐(Apodemus agrarius), 소변·배설물 분말 흡입·물림
  • 유라시아=신증후군출혈열(HFRS): 발열·출혈(혈소판↓)·신장(단백뇨)·빈혈
  • 아메리카=한타 폐증후군(HPS): 호흡곤란·심혈관 쇼크
  • 치사율 과거 20~40% → 현재 ~7%
  • 1976 이호왕, 한탄강 분리 / 백신 한타박스(사백신, 한국·중국) / 리바비린

타입 · 아형

  • D형=소만, 인수공통 X / C형=사람·돼지·개, 산발·경미 / A·B형이 겨울 독감 주원인, 대표=A형
  • A형 아형 = HA(H1~18) × NA(N1~11) 조합 (예 H1N1·H3N2·H5N1)
  • B형 = 숙주 사람·물개·페럿, 아형 없이 계열 2개: 야마가타 / 빅토리아
  • A형 자연숙주 = 야생 물새, A형 공통조상 = 조류 인플루엔자
  • 현재 계절 독감 = B형 + A형 H1N1·H3N2

소변이 vs 대변이

  • 소변이(drift) = 점돌연변이 축적(RNA라 교정 없음) → 매년 계절 유행 → 매년 백신
  • 대변이(shift) = 분절 재편성(reassortment) → 완전 신종 → 팬데믹 (A형만)
  • 돼지=혼합용기(mixing vessel): 조류형+사람형 수용체 모두 보유

레트로바이러스(HIV) 한 바퀴 + 약이 막는 곳

"retro = 거꾸로": 보통은 DNA→RNA인데, 이들은 RNA→DNA (역전사효소 = RNA 의존 DNA 중합효소)

HTLV (Deltaretrovirus)

  • HTLV-1이 중요 → ATLL(성인 T세포 백혈병/림프종), HAM/TSP(탈수초)
  • HAM/TSP는 길랑-바레(자가면역)와 달리 바이러스 매개 녹취
  • STI(성접촉)·체액·모유 / 대부분 무증상, ~5% 발병, 30~50년 잠복, ATLL 발병 시 1년 내 사망
  • 일본 남부·카리브·아프리카·미국 남동부
  • 백신 X, 오프라벨 AZT+IFN-α

구조와 생활사 (녹취 보충)

  • 외피 O / 유전체 = (+)ssRNA 2개(dimer) → dsDNA처럼 보이나 상보결합 X
  • 발현: (+)ssRNA → (−)ssDNA → (±)dsDNA → (+)mRNA → 단백질 (부호가 계속 교대)
  • 구조단백질: gag → MA(matrix)·CA(capsid)·NC(RNA 안정화) / env → SU(바깥)·TM(막관통)
  • 폴리단백질(Gag/Gag-Pol/Env)로 만들어짐 → 프로테이스가 못 자르면 복제 불가 녹취
  • 생활사: 부착 → 침투·탈외피 → 역전사 → dsDNA → 통합(provirus) → 복제 → 조립·방출
