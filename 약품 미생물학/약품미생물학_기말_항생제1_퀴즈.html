03 · 개론

β-락탐의 작용 기전과 내성

작용 기전 — 교차결합(cross-linking) 저해

  • 펩티도글리칸 = NAM + NAG(글리코시딕 결합) 반복, NAM에 펜타펩타이드
  • 펩타이드끼리 교차결합 → 그물처럼 겹겹이 쌓임
  • 교차결합을 매개 = PBP(페니실린 결합 단백질)
  • PBP 2도메인: TG(트랜스글리코실레이즈) = 글리코시딕 결합 / TP(트랜스펩티데이즈) = 교차결합
  • 교수님: 페니실린은 TP에 결합 → 교차결합 저해 (TP가 메이저)

세포벽 차이 → 그람 음성은 왜 어려운가

  • 그람 양성 = 두꺼운 펩티도글리칸이 바깥에 노출
  • 그람 음성 = 외막 + 페리플라즈믹 공간에 얇은 펩티도글리칸
  • → 그람 음성은 외막의 포린을 통과해야 표적에 닿음

내성 기전 (슬라이드)

  • ① β-락타메이스: β-락탐 고리를 깨뜨림 → 항균력 상실
  • ② PBP 변형 · 새 PBP 생성 → 결합 못 함
  • (+ 펌프 등)

참고

  • tabtoxinine-β-lactam: β-락탐 고리는 있지만 항생제 아님(식물 독소)
  • ⚠ 슬라이드 6쪽은 PBP 옆에 (transglycosylase)라고 적혀 있음 — 교수님 설명은 TP

펩티도글리칸을 이루는 당 2개와 이를 교차결합으로 엮는 단백질은?

NAM + NAG, 교차결합 매개 = PBP(페니실린 결합 단백질)

β-락탐 내성 기전 2가지(슬라이드)는?

β-락타메이스(고리 파괴), PBP 변형·새 PBP 생성

특징내용

MRSA 무효거의 모든 β-락탐

MRSA는 어떻게 생겼나 녹취

  • 플레밍 페니실린 → 2차 대전 후 산업화 → "신의 선물"
  • 황색포도알균(피부 정상세균총, 인구 ~20%)이 β-락타메이스를 만들게 돌연변이
  • → PRSA (penicillin-resistant S. aureus)
  • → 반합성 메티실린(첫 반합성 페니실린) 개발
  • → 또 돌연변이 → MRSA (methicillin-resistant) = 내성균의 상징

반합성(semisynthetic) = 천연물 구조 일부를 바꿈  vs  전합성(totally synthetic) = 단순 화학물질부터 여러 단계로 만듦

05 · 페니실린

페니실린 계열 공통 특징 + 포린

페니실린 공통

  • 반감기 매우 짧음(< 2시간) → 하루 여러 번 투여
  • 과민반응 (β-락탐 공통)
  • 장 흡수 불량 → 경구 복용 시 설사
  • 그람 양성에 잘 듣고, 그람 음성엔 없거나 매우 제한적
  • (참고) 소변에 활성 유지 → 일부 요로감염에 사용

스펙트럼 · 포린

  • broad spectrum = 다양한 세균 / narrow = 특정 그룹만
  • 그람 음성 외막의 포린 통과 조건: 크기가 작을수록, 수용성이 높을수록 (포린 안은 수용액)
  • 페니실린은 대체로 포린보다 커서 통과 어려움

한계 = 짧은 반감기 + 좁은 그람 음성 스펙트럼 → 이를 보완하려고 반합성 페니실린을 계속 개발

06 · 페니실린

천연 페니실린 G·V + 지속형

천연 페니실린 = 곰팡이 대사산물

  • Penicillium notatum(옛 이름) = P. chrysogenum(지금 이름)
  • Penicillium = 자낭균류(Ascomycota), 진균 중 가장 큰 그룹 (Candida albicans도)
  • 핵심 구조 = β-락탐 + 티아졸리딘(S·N, 포화 5원환) = 페남

G와 V의 화학명과 투여 경로는? G를 먹지 않는 이유는?

G = 벤질페니실린, 비경구(IM·IV) / V = 페녹시메틸페니실린, 경구(식전). G는 위산 불안정 + 장 흡수 안 됨

프로카인과 벤자틴은 각각 무엇이고 어떻게 지속시키나?

프로카인 = 국소마취제(깊은 근육주사 → 서서히 방출), 벤자틴 = 다이아민(페니실린과 상호작용·안정화 → 서서히 방출)

녹농균 = 병원감염 · 기회감염균, 패혈증·다제내성(MDR) 대표 · 내성 대표 2개 = 녹농균 · 장알균(ESKAPE)

가리고 답하기

아미노기를 붙이면 왜 그람 음성균에 잘 듣게 되나?

아미노기 → 수용성↑ → 그람 음성 외막 포린 통과↑

녹농균이 β-락탐에 잘 안 듣는 이유 4가지는? efflux pump란?

포린 투과성↓, 유도성 내성, PBP 친화성↓, efflux pump(항생물질을 표적에 작용하기 전에 밖으로 내보내는 펌프)

항녹농균 페니실린 5종 ★ (구조 문제 확정)

왜 녹농균에 듣나

  • 카복실·우레이도기 → 녹농균 PBP 친화성↑
  • 전하(charge) → 녹농균 포린 투과↑
  • efflux pump를 막는 건 아님
  • 여전히 β-락타메이스에 약함
  • 출제 기말: 구조 + 보기 ~20개 → 항녹농균 고르기

가리고 답하기

카복시페니실린 2개, 우레이도페니실린 3개는?

카복시 = 카베니실린·티카실린 / 우레이도 = 아즐로실린·메즐로실린·피페라실린

티오펜·아졸·피페라진은 각각 어느 약의 이름 유래?

티오펜 = 티카실린, 아졸 = 아즐로실린(메즐로실린은 메틸설포닐+아졸), 피페라진 = 피페라실린

10 · 억제제

β-락타메이스 억제제 3종

정의 · 작동

  • β-락탐 고리는 있지만 항균 활성은 (거의) 없음 → β-락탐을 흉내(mimic)
  • β-락타메이스와 비가역적으로 결합 → 항생제 대신 싸워 줌
  • β-락탐 항생제와 특정 조합으로 병용 (아무 조합 X)
  • 녹취 활성을 회복(restore)만, 새로 더하지 않음 → 원래 녹농균에 안 듣는 약은 억제제를 써도 안 들음
  • 모든 β-락타메이스를 막지는 못함 → 새 억제제 개발 중

설박탐·타조박탐·클라불라네이트의 짝 항생제는?

설박탐-암피실린, 타조박탐-피페라실린, 클라불라네이트-아목시실린·티카실린

억제제를 쓰면 원래 녹농균에 안 듣던 약이 듣게 되나? 왜?

안 됨 — 억제제는 원래 활성을 회복(restore)시킬 뿐 새로 더하지 않음
