# 약품미생물학 기말고사 학습 계획

- 수업: 월·화·목 각 1시간 (주 3시간, 3학점)
- 기말고사 기간: **2026-12-14(월) ~ 12-18(금)**
- 시험 형식(중간고사 기준): 보기 ①~⑪ 세트 × 약 5세트, 문항마다 지정된 개수만큼 고르기, 45문항 × 1점, 서술형 없음
- 범위: 중간고사 이후 (`Viruses_2026.pdf` 120쪽~ + **항생제(antibiotics)** + 추가 강의자료)
  - 10/27 공지: 목요일에 바이러스 마무리 → 바로 항생제. 항생제도 같은 형식으로 출제, "굉장히 헷갈린다"고 하심
  - **항생제는 화학 구조(구조식)를 주고 무슨 약/계열인지 맞히는 문제도 나온다고 함** (사용자 전달, 녹음에는 미확인)
    → 항생제 학습자료에 반드시 포함: 핵심 골격 그림 → 계열·약 이름 맞히기, 구조↔이름 양방향 카드, 구조를 보기로 주는 세트형 문제

## 학습자료 작성 시점 (사용자 결정, 10/29)

- ✅ **11/10 바이러스 진도 완료** → 바이러스 파트 학습자료 작성 가능 (120쪽~끝: 파라믹소·뉴모·랍도·번야·오르토믹소·레트로·HBV)
- ✅ **바이러스 학습자료 최종본 (11/11)**
  - `약품미생물학_기말_바이러스_학습자료.pdf` (31쪽, 삼성노트): 공부법 → 범위 → 요약 13쪽(페이지별 셀프테스트, 🎯 교수님 강조·★ 출제 유력 표시) → 세트 7개 37문항(문제 → 바로 해설) → 암기 공식 → 종합표
  - `약품미생물학_기말_바이러스_퀴즈.html` (브라우저): 같은 37문항 자동 채점·연속 3회 정답 졸업·틀린 문항만 다시·암기 모드
  - 기준: 슬라이드 120~160쪽 + 녹취록 수업2~6 대조, **수업에서 다룬 내용만** (교수님: "국시 출제 들어가면 수업한 것만 낸다")
  - 퀴즈 문제 데이터는 PDF 소스(`build_통합본/f_virus.py`)에서 자동 생성 → 문항 수정 시 둘 다 같이 바뀜
- 그 뒤 항생제는 진도에 맞춰 주간 단위로 작성
