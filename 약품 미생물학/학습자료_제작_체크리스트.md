# 약품미생물학 기말 학습자료 제작 체크리스트

바이러스 자료를 만들며 나온 오류(정답 오류 4, 문항 결함 7, 범위 밖 내용, 확인 안 한 주장)를
처음부터 막기 위한 순서. 항생제부터 이 순서대로 만든다.

## 0. 원칙

- **수업에서 다룬 것만** 넣는다. 교수님: "국시 출제 들어가면 우리 수업한 것만 낸다."
  슬라이드에만 있고 수업에서 언급 안 한 세부(수치·분류표 등)는 넣지 않는다.
- **확인하지 않은 말은 하지 않는다.** "다 들어갔다", "🎯·★로 표시했다" 같은 말은 파일에서 직접 찾아본 뒤에만 한다.

## 1. 재료

- 녹취록: `기말_녹취록/받아쓰기_프롬프트.md`의 프롬프트로 받아쓴 원문
  (요약·정리본이 아니라 받아쓰기 원문이어야 함)
- 녹취록의 `확인 필요` 목록을 먼저 본다. 수치·약 이름이 슬라이드와 다르면 표시하고 넘어간다.

## 2. 사실 목록 먼저 (요약·문제보다 앞)

`기말_사실목록_<주제>.md`에 시험에 나올 사실을 한 줄씩 뽑는다.

| 사실 | 출처 | 강조 | 비고 |
|---|---|---|---|
| 페니실린은 PBP의 TP 도메인에 결합 → 교차결합 저해 | 수업6 08:11 | 🎯 | |

- 출처 = `수업N mm:ss` 또는 `슬라이드 Antibiotics(n) p.쪽`. 출처 없는 사실은 쓰지 않는다.
- 강조: 🎯 = 교수님이 수업에서 직접 짚음 / ★ = 교수님이 "시험·국시에 나온다, 출제 가능성 높다"고 말함 (녹취 원문 근거)
- 녹취와 슬라이드 수치가 다르면 비고에 둘 다 적는다.

## 3. 요약 페이지

- 사실 목록에 있는 사실만 쓴다.
- 🎯·★는 사실 목록의 강조 칸 그대로 붙인다(새로 판단하지 않음).
- 페이지마다 맨 아래 "가리고 답하기" 2~3문항 = 그 페이지 내용으로 답할 수 있는 것만.

## 4. 세트 문제 출제 규칙

실제 시험 형식: 보기 ①~⑪ 한 세트 + 문항마다 지정 개수 고르기.

- [ ] **조건은 문제 문장에 다 쓴다.** 세트 제목은 조건이 아니다. (MMR 문항: "파라믹소에 속하면서"가 문장에 없으면 풍진도 정답)
- [ ] **문장이 답을 알려주지 않는다.** 정답 짝·형 번호·보기 번호를 문제에 쓰지 않는다. (4-2, 1-3 사례)
- [ ] **전제가 사실이다.** 문장에 깔린 전제를 사실 목록과 대조한다. ("A형에만 있는 HA·NA" → B형도 있음, 3-5 사례)
- [ ] **범위 안이다.** 정답은 기말 수업 내용. 중간 범위 항목은 오답 보기로만 쓰고, 해설에 "중간 범위"라고 적는다.
- [ ] **"모두" 문항: 해설에서 보기 11개를 전부 O/X로 판정한다.** 의도한 정답만 보지 말 것 (풍진·NP·HA 놓친 사례).
  → `check_sets.py --strict`가 빠진 보기를 잡는다.
- [ ] 개수 지정 문항: 문장의 개수("1개", "(2개)") = 정답 수.
- [ ] 해설 각 줄은 사실 목록의 사실로 근거를 댈 수 있다.

## 5. 검사관 검토 (다 쓴 뒤 따로 한 번)

문항마다 출제자가 아니라 **이의 제기하는 학생** 입장에서 읽는다.

- 정답이 하나 더 될 수 있는 보기가 있나?
- 정답이 틀렸다고 주장할 근거가 녹취·슬라이드에 있나?
- 문장만 보고 내용을 몰라도 답을 고를 수 있나?

## 6. 자동 검사 (빌드할 때마다)

```bash
cd "약품 미생물학/build_통합본"
python3 build.py <모드>                                     # out.html
python3 check_sets.py . <모듈> --strict                      # 개수·정답-해설 번호·'모두' 11개 판정 → "문제 0건"
python3 sync_quiz.py . "../<퀴즈>.html"                      # 퀴즈 문제 데이터를 PDF 소스에서 생성
node render.js "../<학습자료>.pdf"                            # "flagged 0"
```

- 퀴즈: 브라우저에서 전 문항 정답 선택 → "정답", 오답 선택 → "오답" 확인. 페이지 오류 0.
- PDF: 모든 쪽 같은 배율(겹침·넘침 없음), 전체 쪽 썸네일로 눈 확인.
- 표지: 목차 쪽 번호·문항 수·요약 쪽 수가 실제와 같은지.

## 7. 전달할 때

검사 결과를 같이 보고한다: 몇 문항을 무엇으로 확인했는지, 걸린 것과 고친 것, 남겨둔 판단(예: 중간 범위 오답 보기).
