이 자료 공부법: 읽지 말고 풀어라

읽기만 하면 왜 안 되나

  • 여러 번 읽으면 글자가 익숙해져서 '아는 것 같은 착각'이 든다
  • 시험은 보기 ①~⑪를 주고 떠올려 고르는 형식. 읽기로는 이 능력이 안 길러짐
  • 항생제는 이름이 비슷해서 특히 헷갈림 → 이름 유래(구조)로 묶어 외우기

그래서 이렇게: 인출 연습 3단계

  • 손으로 푼다. 해설은 가리고, 보기에서 지정 개수만큼 직접 고른다.
  • 바로 채점. 틀린 건 왜 틀렸는지 해설을 한 줄로 읽는다.
  • 틀린 것만 다시. 3번 연속 맞으면 졸업.

교수님: 기말에 구조 ~20개 중 세파마이신을 고르는 문제가 나온다. 세트 4·5는 구조만 보고 고르기 — 7α-메톡시와 1번 원자(S/O)를 찾자.

02 · 도입

세팔로스포린 도입 — 세펨 구조 · 천연 · 세대

세펨(cephem) = 세팔로스포린 핵심 구조

  • β-락탐 + 6원환(S·N, 이중결합 1개) = 다이하이드로티아진
  • 1,3-티아진(이중결합 2개) → β-락탐과 융합하며 이중결합 1개 잃고 H 2개(dihydro)
  • 세펨 = Cephalosporium + -em(이중결합 1개) / 페남 = Penicillium + -am(포화)
  • 세펨류 = 세팔로스포린 + 세파마이신 · 페니실린과 함께 클래시컬 β-락탐

천연 · 세대

반합성천연 구조로 만든 것이 1~5세대
세대 기준스펙트럼. 1~3세대 거의 개발 끝, 4·5세대 진행 중

세펨과 페남의 차이(고리 크기·이중결합)는?

세펨 = β-락탐 + 6원환(이중결합 1개, -em) / 페남 = β-락탐 + 5원환(포화, -am)

천연 세팔로스포린 3개와 생산 곰팡이의 옛 이름·지금 이름은?

세팔로스포린 P·N·C / Cephalosporium(옛) = Acremonium(지금)

03 · 공통

세팔로스포린 공통 특징 + 세대별 한눈에

공통 특징 (슬라이드)

  • 페니실린과 교차 알레르기 < 10% (페니실린 알레르기 10명 중 1명꼴)
  • 페니실린보다 β-락타메이스에 강함(덜 깨짐) → 병원에서 많이 처방
  • 장알균엔 거의 무효 (예외: 5세대 일부)

교수님 요약 — "마구잡이로 외우지 말고" 녹취

  • 1세대 = 페니실린과 비슷 + β-락타메이스에 조금 강함
  • 2세대 = 그람(−) 확장, 그람(+) 약간↓
  • 3세대 = 그람(−) 더 확장 → wide
  • 4·5세대 = 골고루 broad

2세대그람(−) 확장XX

5세대broad세프타롤린 X · 세프토비프롤 O일부 OO

페니실린과의 교차 알레르기 비율은? β-락타메이스엔 페니실린보다 강한가?

10% 미만 / 페니실린보다 강함(덜 깨짐)

녹농균에 처음 듣는 세대는? (예외 1개 포함) 장알균은?

3세대 세프타지딤(예외) → 4세대부터 O / 장알균은 5세대 일부만

04 · 1세대

1세대 — 페니실린급 + 수술 전 예방

1세대 (이름은 흐리게 = 외울 필요 X)

  • 세팔로틴 · 세팔로리딘 · 세파졸린 · 세팔렉신
  • 스펙트럼 = 페니실린과 비슷: 그람(+) 주로, 그람(−) 제한적(약간 확장)
  • 페니실린보다 β-락타메이스에 강함 → PRSA O, MRSA X
  • 녹농균·장알균 X

외과 수술 예방 = surgical antibiotic prophylaxis 녹취

  • 대표 = 세파졸린, 수술 약 1시간 전 투여
  • 피부 정상세균총(황색포도알균) 오염 대비
  • 이유: 그람(+) 스펙트럼 · 저렴 · 부작용 적음
  • → 1세대도 지금도 쓴다 (세대별로 목적에 맞게)

가리고 답하기

1세대 스펙트럼은 무엇과 비슷한가? PRSA·MRSA엔?

페니실린과 비슷(그람(+) 주로) / PRSA O, MRSA X

수술 전 예방에 쓰는 대표 약과 그 이유 3가지는?

세파졸린 — 그람(+) 스펙트럼, 저렴, 부작용 적음

05 · 2세대

2세대 + 세파마이신 ★ (구조 문제 예고)

2세대

  • 세파만돌 · 세푸록심 · 세포니시드 · 세파클로 · 세프프로질 (흐리게)
  • 1세대보다 그람(−) 확장, 그람(+) 약간↓ (그람(+)는 1세대·페니실린으로 커버)
  • β-락타메이스 저항 1세대보다 더
  • 녹농균·장알균 X

세파마이신 = 2세대 중 2개 출제

  • 세폭시틴 · 세포테탄 ("까맣게 둔 거, 기억하셔야")
  • 구조: 세펨의 7α 위치에 메톡시기(-OCH₃) (S = 1번)
  • 메톡시 = 메틸 + O (R-O-CH₃), 옥시메틸이라고도
  • 출제 기말: 구조 ~20개 중 세파마이신 고르기 / 국시: 구조를 말로

가리고 답하기

2세대는 1세대보다 무엇이 좋아지고 무엇이 약해졌나?

그람(−) 확장·β-락타메이스 저항↑ / 그람(+) 약간 감소

세파마이신 2개와 구조적 특징은?

세폭시틴·세포테탄 — 7α 위치에 메톡시기

06 · 옥사세펨

옥사세펨 ★ — 세파마이신 + 1번 S→O

옥사세펨 (oxacephem) 출제

  • 7α-메톡시 (세파마이신과 공통)
  • + 1번 S → O 치환 ("1-oxa")
  • 활성 = 3세대 세팔로스포린과 비슷 (3세대로 보기도 함)
  • 모살락탐(= 라타목세프, 현재 미사용) · 플로목세프

7α-메톡시 + 1번 S가 O로 치환

옥사세펨 2개와 활성이 비슷한 세대는?

모살락탐(라타목세프)·플로목세프 / 3세대

07 · 3세대

3세대 — wide spectrum · BBB

3세대

  • 세포탁심 · 세프트리악손 · 세프타지딤 · 세프디니어
  • 2세대보다 그람(−) 더 확장, 그람(+) 감소
  • → wide spectrum = narrow와 broad 사이 (broad라고도 하지만 정확히는 wide) 녹취
  • 세프타지딤만 녹농균 O (3세대 예외) · 장알균 X

BBB 통과 → CNS 감염

  • 세포탁심 · 세프트리악손 · 세프타지딤
  • 뇌수막염 등 뇌 세균 감염 치료에 사용

(용어) enteric GNR = Gram-negative rod 중 장내세균목(E. coli·Salmonella·Shigella)

가리고 답하기

wide spectrum이란? 3세대 중 녹농균에 듣는 것은?

narrow와 broad 사이(그람 +/− 둘 다, broad까진 아님) / 세프타지딤

BBB를 통과하는 3세대 3개는?

세포탁심·세프트리악손·세프타지딤

08 · 4·5세대

4세대 · 5세대 ★ — 이름 기억

4세대 출제

  • 세피롬 · 세페핌
  • broad (그람 +/− 골고루)
  • 녹농균 O, 장알균 X

5세대 (지금까지 2개뿐) 출제

  • 세프타롤린 · 세프토비프롤

4세대 2개, 5세대 2개는?

4세대 세피롬·세페핌 / 5세대 세프타롤린·세프토비프롤

5세대 중 녹농균에 듣는 것과 안 듣는 것은? MRSA엔?

세프토비프롤 O, 세프타롤린 X / 5세대는 MRSA O
