# 기말 마스터 노트 공용 표지 (2026-2)

기말 마스터 노트 5개의 표지를 한 디자인으로 통일한 도구예요. 2026-11-12 확정.

## 디자인
- **배치:** 가는 선과 넓은 여백
  - 윗줄: 과목 코드 · 영문 과목명 / 학기
  - 왼쪽: 과목명 → 영문 → 범위 제목 → 흐름 한 줄
  - 오른쪽: 장 번호 → 파트 목차 (시작 쪽 포함)
  - 아랫줄: 숫자 최대 4개 + 파일 코드
- **글꼴**
  - 과목명·제목: Noto Sans KR 800
  - 장 번호·숫자·영문: Inter Tight 800
  - 코드: IBM Plex Mono
- **과목 색과 인덱스 탭:** 탭은 오른쪽 끝에 붙고, 과목마다 높이가 고정이에요.

- **쓰지 않기로 한 것 (거절됨):** 모눈 배경, 유리 질감 일러스트, Outfit 숫자 글꼴, 얇은 숫자, 색 면 패널

## 적용 대상
| id | 파일 | 방식 |
|---|---|---|
| `orgo22` | `유기화학/CH22_기말대비_마스터요약.pdf` | toc |
| `orgo23` | `유기화학/CH23_기말대비_마스터요약.pdf` | toc |
| `phys` | `인체생리학/인체생리학_기말_8-10장_마스터요약_개념문제.pdf` | replace |
| `micro` | `약품 미생물학/약품미생물학_기말_바이러스_학습자료.pdf` | replace |
| `bio` | `약품생화학/Chap19_20_시험대비 요약노트(TB추가).pdf` | toc |

- **replace:** 옛 1쪽(표지)을 새 표지로 바꿔요. 전체 쪽수는 그대로예요.
- **toc:** 옛 1쪽은 '색 패널 + 목차'예요. 목차를 살리려고 새 표지를 맨 앞에 넣고, 옛 1쪽의 색 패널 자리만 새 디자인 띠로 덮어요. 그래서 전체 쪽수가 1 늘어나요. 새 표지에는 쪽 번호가 없어서, 목차와 꼬리말에 찍힌 쪽 번호는 그대로 맞아요.
- **CH22 변형본은 제외:** `CH22_기말대비_마스터요약_삼성노트.pdf`, `CH22_기말대비_핵심판.pdf`, `CH22_단권화노트_직관QA총정리.pdf`는 적용하지 않아요 (사용자 요청).

## 실행
```bash
cd _공용/기말표지
python3 covers.py            # 5개 전부 적용
python3 covers.py phys       # 하나만
python3 covers.py --preview  # 미리보기.html + 기말표지_모음.pdf(표지 5장)
```
- **필요한 것:** pypdf, node, Playwright(Chromium), 인터넷 (Google Fonts에서 글꼴을 받아요)
- **다시 빌드한 뒤:** 과목 빌드로 PDF를 다시 만들면 예전 표지로 돌아가요. 빌드한 뒤에 `python3 covers.py <id>`를 한 번 더 돌리세요.
- **여러 번 돌려도 안전해요:** 같은 파일에 다시 돌려도 표지가 겹쳐 쌓이지 않아요. PDF 정보에 `/FinalCover` 표시를 남겨서 구분해요.
- **내용 수정:** 표지 내용(제목, 숫자, 목차 쪽수)은 `covers.py`의 `COVERS`에서 고쳐요.
- **새 과목 추가:** `COVERS`에 항목을 하나 추가해요. 1쪽이 표지뿐이면 `mode="replace"`를 쓰고, 1쪽이 '색 패널 + 목차'면 `mode="toc"`에 패널 폭(pt)을 `strip=`으로 적어요.

## 파일
- `cover.css`: 표지 스타일. cqw 단위라 16:10이든 A4 가로든 같은 비율로 그려져요.
- `covers.py`: 표지 데이터와 HTML 생성, PDF에 적용하는 코드
- `render.js`: HTML을 PDF로 바꾸는 렌더러 (Chromium)
- `미리보기.html`: 표지 5개를 한 화면에서 보는 파일
- `기말표지_모음.pdf`: 표지 5장 모음
