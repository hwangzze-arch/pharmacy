실험 1. 뷰렛의 검정 (Buret Calibration)

자료: 실험1 유인물 1–5쪽 + 첫 수업 녹취록(약 104분) 요약 · 정리일 2026-10-29

한 줄 요약 — 앞으로 4주간 적정에 쓸 뷰렛이 제조사가 말한 만큼(±0.1 mL) 정확한지를, 뷰렛에서 흘려보낸 물의 무게를 재서 밀도로 나눠 "진짜 부피"를 구한 뒤 눈금과 비교해 확인한 실험.

보정치 = (물 무게 ÷ 물의 밀도) − 뷰렛 눈금 = 실제 부피 − 읽은 부피

오늘 한 일 (순서)

  1. 뷰렛 준비: 세척·린싱, 스톱콕 조임 조절, 누출 확인
  2. 탈이온수 채우고 기포 제거 → 0.00 mL에 맞춤
  3. 빈 삼각플라스크 무게 측정
  4. 약 10 mL씩 한 방울씩 받아 눈금(0.01까지) + 무게 기록 → 50 mL까지
  5. 실제 부피·보정치 계산 → 검정곡선 (x: 눈금, y: 보정치)
  6. 뒷정리: 수돗물 → 탈이온수 헹굼 → 스톱콕 열고 거꾸로 걸어 자연건조

📌 공지사항 · 감점 포인트

  • 실험노트 제출: 목요일 실험 → 다음 주 월요일 저녁 6시까지, 401호(교수님 실험실) 앞 박스. 늦으면 감점. 채점 후 다음 실험 때 돌려줌.
  • 기말고사 있음: 실험한 내용에서만 출제. 실험에 성실히 참여하면 풀 수 있는 시험.
  • 복장: 실험복 필수, 단추 끝까지 잠글 것. 슬리퍼·반바지 절대 불가 (조교 체크 → 감점/퇴실 가능).
  • 휴대폰 사용 금지 (감점).
  • 적정 시 용액이 "주르륵" 흐르면 감점 — 반드시 똑, 똑, 똑 떨어지게.
  • 실험실은 냉방만 되고 난방이 안 됨 → 따뜻하게 입고 올 것. 에어컨 켜도 찬 바람만 나옴.

1. 실험실 안전 수칙 (유인물 1쪽)

이 실험 아무리 열심히 해도 노벨상 못 받는다. 그러니 제일 중요한 건 안전. 유리 초자를 써서 실제로 여러 번 깨졌다.
항목핵심 내용
보안경원칙은 "항상" 착용. 이 실험실은 특별히 위험한 시약이 없어 원하면 제공.
고무장갑시약·용매를 다룰 때 반드시. 독성물질은 2겹. (오늘은 물이라 불필요)
복장손·다리·발·몸통을 덮는 옷과 신발. 실험복 정확히 착용(단추 안 잠그면 걸려 넘어짐). 긴 머리는 묶기.
화학물질피펫을 입으로 빨지 말 것(Filler/Pipette aid 사용). 흡입·맛보기·피부접촉 금지. 눈에 들어가면 흐르는 물로 먼저 세척 후 알림. 실험실 내 취식·흡연 금지. 시약 정보는 Merck Index, 안전정보는 MSDS.
유리용기뜨거운지 찬지 눈으로 구분 안 됨 → 주의. 유리관을 고무마개에 끼울 땐 윤활제 + 타월로 손 보호. 베이면 깨끗한 타월로 압박 지혈 후 즉시 알림.
화재휘발성·가연성 용매(ether, acetone, methanol 등) 주의 — 열린 계에서 가열·휘산 금지, 감압농축기 사용. 소화기·안전샤워·화재경보기·비상구 위치 숙지 (화재 시 승강기 금지).
실험 준비검증되지 않은 실험 금지. 미심쩍으면 반드시 질문. 교수/조교 없이 혼자 실험 금지.
이 실험실의 위험 요인 정리 (교수님 설명)
  • Chemical있음 — 시약 사용 시 주의
  • Bio없음 — 생물 물질 안 씀
  • Physical많음 — 특히 유리 초자 파손
  • Fire전기 장비 누전 가능성. 학기 마지막에 알코올류 가연성 용매 사용 예정.

2. 실험노트 작성 요령 (유인물 2쪽)

좋은 실험노트란 "그 분야의 통상적 지식을 가진 사람이 내 노트만 보고 내 실험을 재현할 수 있는 노트"다. 나라에 따라 실험노트 날짜가 발명일(특허)이 되기도 한다.

들어가야 할 항목

  1. 실험일자 — 노트 쓴 날이 아니라 실험한 날
  2. 실험자 서명 — 매 페이지 (페이지가 떨어져 나갈 수 있으므로)
  3. 증인 서명 — 원칙상 필요하지만 이 수업에선 생략
  4. 제목
  5. 목적 — 간단하게
  6. 절차 — 자기 말로 간단히, 실제 한 대로 과거형
  7. 실험결과 — 가장 중요. 표(Table I…)·그림(Figure 1…)에 번호·제목, 색·온도·무게 변화 등 관찰 모두
  8. 고찰 및 결론 — 결과를 해석·비교, 논리적 판단. 감상문 X

형식 규칙 (어기면 감점)

  • 볼펜으로만 (연필·지우개·수정액·화이트 금지)
  • 틀리면 두 줄 긋고 서명, 지우지 말 것
  • 페이지에 남는 여백 → 사선 + "여백" 표시 (조작 방지)
  • 출력물(표·그래프) 부착 → 4면 모두 풀/테이프, 노트와 종이에 걸쳐 간인(서명)
  • 노트 번호 부여 (예: 분석학실험 No.1) + 일련 페이지 번호
  • 노트는 아무 노트나 OK (문방구 노트)
  • 서론은 핸드아웃 정리로 충분, 참고문헌 불필요

3. 왜 뷰렛을 "검정"하나? — 목적과 원리

목적 (유인물): 부피측정용 유리기구에 대해 제작자의 허용오차 범위 내에서 실제로 정확한 부피 측정이 이루어지는지 검정한다.

원리: 증류수를 담은 뷰렛에서 일정 눈금만큼 물을 흘려보내 그 질량을 저울로 재고, 그 온도에서의 밀도로 나눠 실제 용량을 계산한다.

뷰렛 윗부분에 제조사가 보증하는 정확도가 적혀 있다 — 20 °C 기준 ±0.1 mL (또는 ±0.08). 즉 20.35를 정확히 읽어도 참값은 20.35 ± 0.1. "제조사가 진짜 이렇게 정확하다고?" — 그걸 의심하고 확인하는 것이 검정(calibration)이다. 적정은 간단하지만 엄청나게 정확한 정량법인데, 뷰렛이 틀리면 완전히 헛고생.

왜 무게로 부피를 알 수 있나?

밀도 ρ = 질량 m / 부피 V  ⟹  V실제 = m물 / ρ물(수온)

저울은 뷰렛 눈금보다 훨씬 정밀하다(0.001 g 단위). 물은 밀도가 온도별로 정확히 알려져 있으므로(유인물 5쪽 Table 1.2, 19.0–26.0 °C) "무게 → 부피"로 바꾸면 진짜 나간 부피를 알 수 있다. 오늘 수온은 약 19 °C → ρ = 0.99842 g/mL (교수님은 "약 0.998"로 설명).

T (°C)19.020.021.022.023.025.0
ρ (g/mL)0.998420.998210.998000.997780.997550.99705

→ 온도가 오를수록 밀도가 작아진다. 그래서 수온을 꼭 재서 기록해야 한다(노트에 "수온 __ °C, ρ = ____ g/mL" 명시).

보정치(Correction)의 정의 — 부호 주의!

보정치 = 실제 부피(계산값) − 뷰렛 눈금(읽은 값)
  • 보정치 + : 눈금보다 실제로 더 많이 나갔다 → 눈금에 더해 줘야 함
  • 보정치 − : 눈금보다 실제로 덜 나갔다
  • 쓰는 법: 보정된 부피 = 읽은 눈금 + 보정치 (양수·음수 모두 그대로 더함)

4. 측용기(부피 측정 기구)의 종류 — TC vs TD

수용(受用) 측용기 · TC (To Contain)출용(出用) 측용기 · TD (To Deliver)
보증하는 것표선까지 채웠을 때 용기 안에 담긴 부피표선까지 채운 액체를 다른 용기로 옮겼을 때 나간 부피
대표 기구부피플라스크(volumetric flask), 수용 메스실린더뷰렛, 피펫, 출용 메스실린더
예시500 mL 부피플라스크: 500 ± 0.3 mL50 mL 뷰렛: 눈금마다 ±0.1 mL
잘못된 사용부피플라스크로 재서 따라 옮기기뷰렛에 부어 담긴 양을 재기, 거꾸로 흘리기

💡 이해 포인트: 뷰렛 속 실제 액체 양 vs 나간 양

벽에 액체가 조금 남기 때문에 뷰렛 안에 담겨 있던 양 > 실제로 나간 양. 제조사는 이걸 감안해 "나간 양"에 맞춰 눈금을 그렸다(TD). 그래서 뷰렛은 반드시 위에서 아래로 흘려보내는 용도로만 써야 눈금이 맞는다.

⚠ 비커·삼각플라스크 눈금은 믿지 말 것

라면 냄비 눈금처럼 참고용일 뿐 정확하지 않다. 비커 눈금으로 재서 옮기는 건 TC도 TD도 아님 → 정량에 쓰지 말 것. "눈금이 있다고 다 믿으면 안 된다."

측용기 취급 주의점 (유인물): ① 세척·헹굼 철저 ② 피펫을 입으로 사용 금지(Filler 사용), 유해 기체는 후드 안에서 ③ 수용/출용 구분 사용 ④ 측용기는 발열성 물질 사용·가열·가열건조 금지 (열로 유리가 팽창 → 부피가 변함).

5. 뷰렛 사용법 — 오늘의 핵심 실기

오늘 중요한 건 뷰렛을 사용하고 눈금을 읽는 것. 그걸 못 하면 오늘 실험은 의미가 없다.

① 세척과 린싱(rinsing)

  • 선배들이 깨끗이 씻어 놨을 거라고 믿으면 안 된다 — 기본.
  • 정석 세척: 시약은 폐액통에 먼저 버림 → 소량의 물로 헹굼 → 수돗물로 충분히 → 마지막에 탈이온수(세척병)로 2–3회 헹굼 → 실온 자연건조. (수돗물엔 전해질이 있어 마지막만 비싼 탈이온수로 헹구면 충분)
  • 말릴 시간이 없으면 → 사용할 용액으로 린싱 (소량 넣어 내벽을 적시고 버리기를 반복). 오늘은 용액이 탈이온수라 탈이온수로 헹구면 끝. 다음 주부터는 표준액으로 여러 번 린싱.
  • 절대 열로 말리지 말 것(오븐·드라이어 X).

② 스톱콕 조임 조절 · 누출 확인

  • 스톱콕 뒤쪽은 나사(스크류) → 완전히 분해해 세척 가능, 조임 조절 가능. 그냥 쓰지 말고 풀었다가 적당히 다시 조이기.
  • 너무 느슨 → 샌다. 너무 꽉 → 잘 안 돌아가고 깨지거나 손을 다침.
  • 왜 중요? 종말점에서는 한 방울로 성질이 급변 → 스톱콕을 빨리 잠그지 못하면 종말점을 넘겨 실험을 다시 해야 한다.
  • 누출 확인: 물을 채워 0.00 근처에 두고 잠시 놔뒀을 때 눈금이 내려가는지, 스톱콕에서 맺히는지 본다.

③ 기포 제거 ★ 제일 중요

액체가 지나는 관(특히 스톱콕 아래 끝부분)에 기포가 하나도 없어야 한다. 기포가 나중에 빠지면 그 부피만큼 눈금이 틀어진다. → 처음부터 끝까지 눈으로 확인, 기포가 있으면 밸브를 확 열어 밀어낸 뒤 다시 채운다. (유인물: 공기 방울은 반드시 제거한 후 사용)

④ 눈금 읽기 — 메니스커스 & 시차오차

{{PARALLAX}}
  • 물의 경계면은 아래로 오목한 반달 = 메니스커스 → 맨 아랫부분을 읽는다.
  • 시차오차(parallax error): 눈높이를 메니스커스에 맞춰야 함.
    아래에서 보면 과대, 위에서 보면 과소 평가.
  • 내 키를 맞추거나, 뷰렛을 스탠드에서 위아래로 옮겨 수평을 맞춘다.
  • 눈금 간격은 0.1 mL → 그 사이를 눈으로 10등분해서 소수 둘째 자리(0.01)까지 반드시 기록. (10.0 ✗ → 10.00 ✓)
  • 눈금선 두께(약 0.02 mL), 한 방울(약 0.05 mL)은 따로 고려하지 말고 정확히 읽기만.

⑤ 유출 속도

  • 적정한 유출 속도는 20 mL/min 이하 (50 mL 뷰렛에서 절반 내려가는 데 약 1분).
  • 시간 잴 필요 없이 "똑, 똑, 똑" 끊어서 떨어지게만 하면 자동으로 이 속도. 연속으로 주르륵 흐르면 → 감점. (빨리 흘리면 벽에 액체가 많이 남아 나간 양이 적어지고, 적정에선 종말점을 넘기기 쉬움)
  • 남은 액체를 뿌리지(털어내지) 않는다.

⑥ 저울 사용 (유인물 3쪽 요약)

  • 진동·바람·습기·직사광선·난방기 피하기, 수평 유지(기포 수평계).
  • 시료를 넣고 뺄 땐 저울을 정지 상태로, 접시 가운데에 놓기. Tare 기능 활용. 최대 칭량치 초과 금지.
  • 가열한 시료는 데시케이터에서 식힌 뒤. 청소할 때 물 사용 금지.
  • 교수님 팁: 여러 번 재야 하므로 처음 쓴 저울을 끝까지 같은 걸로 사용 (저울 간 차이 제거). 주변에 물 흘리면 닦기 → 오차 커짐.

시약 및 기구: buret (50 mL) & stand, buret holder, Erlenmeyer flask (100 mL), beaker (100 mL), washing bottle, chemical balance, 탈이온수

  1. 뷰렛을 준비한다 (세척 및 헹굼, 누출 점검).
  2. 뷰렛에 탈이온수를 채워 스탠드에 세우고 0 mL 표선에 눈금을 맞춘다. (꼭 0.00일 필요는 없지만 0.00에서 시작하면 "눈금 차" 계산이 필요 없어 편함)
  3. 탈이온수 10, 20, 30, 40, 50 mL를 삼각플라스크에 받아 각각 질량을 측정한다 (눈금·무게 모두 누적).
  4. 3번을 2회 반복하여, 측정 질량에서 추정된 부피와 실제 뷰렛 눈금의 편차(보정치)를 구해 눈금에 대해 도시 → 검정곡선.
  5. 실제 적정 때 검정곡선으로 측정치를 보정한다. 이때 시작 눈금과 최종 눈금 모두 보정.

✅ 해석 (고찰에 쓸 내용)

  • 모든 보정치가 −0.04 ~ +0.03 mL → 제조사 허용오차 ±0.1 mL 안에 들어옴 → 우리 뷰렛은 보증 정확도를 만족.
  • 보정치가 구간마다 +/−로 달라짐 → 뷰렛 관의 안지름이 완전히 균일하지 않기 때문(제조 공차) + 읽기·칭량의 우연오차.
  • ±0.1을 벗어나면? → 실험을 잘못했거나(기포, 시차, 흘림, 너무 빠른 유출) 뷰렛이 불량. 보통은 잘 나온다.

⚠ 노트 쓰기 전에 확인할 것

  • 녹취록에서 친구들은 ρ를 0.998로 계산해 30 mL 구간 29.98(+0.03), 50 mL 구간 49.97(−0.03)이라 했는데, 0.998로도 정확히는 29.99(+0.04)·49.98(−0.02), 표의 0.99842로는 위 표 값이 맞다. 노트에는 표에서 찾은 밀도와 그 값으로 계산한 결과를 쓰자.
  • 위 숫자는 녹취록(AI 전사)에 나온 값이라 전사 오류가 있을 수 있다. 실제 기록지/단톡방 사진의 값으로 교체할 것.
  • 유인물은 2회 반복을 요구한다. 오늘 1회만 했다면 고찰에 그 사실을 적고, 2회 했다면 두 번의 보정치를 평균해 그린다.
  • 저울이 0.001 g까지 표시됐다면 무게도 소수 셋째 자리까지 기록(유인물 예시처럼).

9. 기말 대비 핵심 체크 (Q&A)

Q1. 뷰렛 검정의 목적은?
제조사 허용오차(±0.1 mL) 범위 안에서 실제로 정확한 부피가 측정되는지 확인하고, 보정치(검정곡선)를 얻어 이후 적정값을 보정하기 위해.
Q2. 실제 부피는 어떻게 구하나?
흘려보낸 물의 질량을 저울로 재고, 측정 수온에서의 물의 밀도로 나눈다. V = m / ρ.
Q3. 보정치의 정의와 부호의 의미는?
보정치 = 실제 부피 − 눈금. +면 눈금보다 많이 나감, −면 적게 나감. 보정 부피 = 눈금 + 보정치.
Q4. 검정곡선의 x축, y축은?
x축 = 뷰렛 눈금(mL), y축 = 보정치(mL).
Q5. TC와 TD의 차이와 예는?
TC(수용): 용기 안에 담긴 부피 보증 — 부피플라스크. TD(출용): 옮겼을 때 나간 부피 보증 — 뷰렛, 피펫, 출용 메스실린더.
Q6. 뷰렛에 담긴 액체의 부피와 실제 나간 부피 중 어느 것이 큰가?
담긴 부피가 더 크다(벽에 남는 액체). 눈금은 나간 부피 기준으로 그려져 있다.
Q7. 뷰렛 눈금은 어디까지 읽나? 메니스커스는 어디를 읽나?
소수 둘째 자리(0.01 mL)까지. 메니스커스의 맨 아랫부분을 눈높이를 맞춰 읽는다.
Q8. 시차오차: 아래에서 보면? 위에서 보면?
아래에서 보면 과대평가, 위에서 보면 과소평가.
Q9. 적절한 유출 속도는?
20 mL/min 이하 — 한 방울씩 끊어서 떨어지게.
Q10. 한 방울의 부피와 눈금선의 두께는 대략?
한 방울 ≈ 0.05 mL, 눈금선 두께 ≈ 0.02 mL.
Q11. 측용기를 가열 건조하면 안 되는 이유는?
열로 유리가 팽창·변형되어 부피(눈금)가 달라질 수 있기 때문. 실온 자연건조.
Q12. 시간이 없어 뷰렛을 말릴 수 없을 때는?
사용할 용액(표준액)으로 여러 번 린싱해 내벽의 물을 대체한다.
Q13. 왜 기포를 꼭 빼야 하나?
관 속 기포가 적정 중 빠져나가면 그 부피만큼 눈금이 실제 유출량과 달라지기 때문.
Q14. 적정 후 실제 용출 부피 계산 시 보정은 어디에?
시작 눈금과 최종 눈금 모두 각각 보정한 뒤 뺀다. (예: 29.40 − 8.28 = 21.12 mL)
Q15. 물의 밀도는 온도가 오르면?
작아진다 (19 °C 0.99842 → 25 °C 0.99705 g/mL). 그래서 수온 측정이 필요.
Q16. 이번 학기 적정 4종은?
중화 적정, 침전 적정, 킬레이트(EDTA) 적정, 산화환원 적정.
