# 분석학실험 노트 제작 파일

`실험1_마스터요약/`은 `분석학실험_실험1_뷰렛의 검정_마스터노트.pdf`의 원본이야.
디자인은 `의약품 분석학/_제작파일/중간고사_마스터요약`과 같아 (표지 · 개념 페이지 💡📖📐✍️🧠 · 문제 페이지 왼쪽 문제/풀이칸, 오른쪽 정답·해설).
다음 실험도 이 폴더를 복사해서 `c10…c40_*.py` 내용만 바꾸면 같은 양식으로 만들 수 있어.

- `build.py` 디자인(CSS)·페이지 틀 / `c00_front.py` 표지·공지·한 장 요약 / `c10…c40_*.py` PART별 내용(`t="c"` 개념, `t="q"` 문제) / `c90_final.py` 혼동 쌍·체크리스트
- `svgs.py` 직접 그린 그림(검정곡선·시차오차·흐름도)과 우리 조 데이터, `img/` 유인물 사진에서 잘라 낸 그림

```sh
cd "분석학실험/_제작파일/실험1_마스터요약"
python3 build.py
NODE_PATH=$(npm root -g) node render.js "$PWD/../../분석학실험_실험1_뷰렛의 검정_마스터노트.pdf"
```
필요: Python 3, Node + playwright(Chromium), 한글 폰트 Noto Sans KR(또는 Pretendard).
