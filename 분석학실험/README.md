## 실험노트 작성 규칙 (교수님 피드백 누적)
- 페이지 번호는 1권 전체에 이어서, 서명은 머리말/꼬리말에 매 페이지, 부착물엔 노트 번호·부착 페이지 + 겹치게 간인
- 큰 빈 공간만 빗금 한 줄, 그래프는 엑셀
- 원리 최소 반 페이지, 방법은 실제로 한 대로(탈이온수, 제공된 시약, 실제 칭량값, 생략한 단계)
- 규정도계수는 소수 셋째 자리까지만, 직접 구한 f 사용
- 고찰: 결과가 이상하면 원인 · 대책 · 개선 방안
- (실험 3 채점 후) **표정과 적정을 구분하여 기재** — 방법·결과를 [표준액 조제/표정]과 [시료 적정]으로 나눠 쓰기
